# Direction 4 literature survey: latent action models

**Corpus cutoff: 3 November 2026.** This survey covers 24 full-text papers published or posted 2023–2026. Every included source was downloaded into this directory as one full-text file per paper under **papers_d4/** (arXiv HTML for HTML sources; complete PDF for PDF sources). The entries below were checked against the method, training, experiment, ablation, limitation, and appendix text, not just abstracts. HTML papers are cited by section/subsection; PDFs also have page numbers. “Not reported” means the paper does not state a value clearly enough to support one.

This is a literature survey, not a claim that every method is a strict inverse-model LAM. The selected works include action-token video generation, robot policies, controllable world models, object/factor-centric methods and critical evaluations because each bears directly on whether a compact latent can carry the causal action effect. Distinctions matter: an action-conditioned world model is not necessarily a reusable robot-action decoder; a latent useful for visual prediction is not necessarily minimal, physically meaningful, or executable.

## Main takeaways

1. An inverse model trained only to explain frame changes does not know which changes were caused by the agent. It may encode camera motion, the moving bottle, background video, another agent, or task-independent dynamics. Pixel reconstruction and a narrow bottleneck do not guarantee control-grounded latents; LAOM finds a bottleneck can preferentially retain easy-to-predict distractors.
2. There is no one right latent geometry. Discrete tokens make planning and prediction tractable in some settings, but can discard action detail or collapse; continuous latents better retain fine motion but can absorb appearance and incidental dynamics. The 2026 design study finds regularizer strength, integration into the policy, data and benchmark matter more than a universal VQ-versus-VAE answer.
3. The strongest recurring improvement is to make the action effect explicit: supervised action or action-similarity targets, embodiment-conditioned native-action projectors, agent/object masks or features, and a forward model that must predict the next controllable state from the latent. Unsupervised IDM–FDM reconstruction alone is not a guarantee.
4. For our case, first establish that a direct action-conditioned model can predict the robot-caused transition. Then test a small continuous latent against it. The 84 demos already contain action labels, so use them to ground the latent and decoder. Keep latent capacity modest, split by trajectory, and test action swaps at a fixed starting state.
5. “Robot agnostic” should be a measured transfer property, not an assumption. LAMs can align movement semantics across human and robot videos, but precise mapping to 54-dimensional joint chunks still needs embodiment-specific decoding and enough coverage. The newest cross-embodiment studies expose that gap rather than eliminating it.

## Per-paper notes

### 1. LAPO / Learning to Act Without Actions (Schmidt & Jiang, ICLR 2024)

[Full paper](https://arxiv.org/abs/2312.10812). The core pipeline has an inverse dynamics model (IDM) infer a quantized code from adjacent observations and a forward dynamics model (FDM) reconstruct the next observation from the current observation plus code. It is trained with pixel MSE and a VQ bottleneck; history context is provided to the IDM. The appendix specifies a 128-dimensional pre-quantization action split into eight latents (two codebooks by four latents, vocabulary 64, 16-dimensional token embeddings), with a one-frame transition. A behavior-cloning policy predicts codes; a separately supervised decoder maps codes to real actions, or online PPO can use the latent policy (Sec. 4.1–4.3, App. A.4, p. 17). On Procgen, pretraining uses 8M action-free frames from expert-policy trajectories across 16 games; the IDM/policy uses four-channel IMPALA-style encoders and the FDM is an approximately 8M-parameter ResNet U-Net. The reported latent decoder uses only 200–256 labeled examples. Appendix/compute details report millions of PPO updates, not a robot-scale hardware recipe. Quantization reduces FDM reconstruction error but improves downstream control; partial observability fragments one physical behavior into several codes, and delayed effects are not recoverable until visible. It is a useful discrete baseline, not evidence that pixel reconstruction alone removes distractors.

### 2. Genie: Generative Interactive Environments (Bruce et al., 2024)

[Full paper](https://arxiv.org/abs/2402.15391). Genie factors a video tokenizer, latent action model and autoregressive dynamics model. The LAM uses the frame history and next frame, outputs eight categorical codes with 32-dimensional embeddings and codebook size eight, and reconstructs the next frame from history plus code (Sec. 2.1). Training is self-supervised on video, with no physical robot-action decoder; the generated interface is abstract button-like control. The paper reports 55M 16-second videos at 10 fps (filtered to 6.8M clips / about 30k hours), with about 130k RT-1 demonstrations and 209k real-robot episodes included as video rather than action supervision. Models include a 300M LAM and a 10.1B main dynamics model; the reported large run uses 256 TPUv5p for 125k steps (Sec. 2, App. F). The robot-video model is not grounded to executable robot actions. Their controllability probes compare action-conditioned prediction with randomized actions and show visual-token choices can affect controllability (Sec. 3.3). Limits include slow generation, hallucinated futures and imperfect long-horizon consistency; Genie is a valuable action-conditioned world-model exemplar but its learned codes do not solve our action mapping.

### 3. LAPA: Latent Action Pretraining From Videos (Ye et al., ICLR 2025; LAQ-style design)

[Full paper](https://arxiv.org/abs/2410.11758). LAPA learns discrete latent action tokens with an ST transformer and VQ-VAE using noise-substitution quantization. The IDM sees a current/future frame pair; the decoder predicts the future pixels from the current frame and quantized code, with a stop-gradient current patch embedding to reduce shortcuts (Sec. 3, App. A–B). The robot setup uses a roughly 0.6-second gap (three frames at 5 Hz); Something-Something V2 human clips use a longer, approximately 2.4-second gap, and the paper reports degradation when the gap is too large for its model. The robot representation uses four tokens with vocabulary eight per token. A VLM first predicts these tokens; for robot action fine-tuning, the latent head is replaced with an action head and real action labels are needed. The paper also describes fitting a small latent-to-action mapper; 100 labels were insufficient for one UniPi 7D control setup. Training uses 220k human videos plus Bridge/Open-X robot data; the Open-X LAPA training estimate is 8 H100s for 34 hours (272 H100-hours; Sec. 4.6). LAPA shows broad video can improve object/task generalization, but the paper calls out camera-motion contamination and sensitivity to frame spacing (App. E). It is an important quantized-pretraining baseline; it does not establish that human motion codes decode to our joint controls.

### 4. LAOM: Latent Action Learning Requires Supervision in the Presence of Distractors (Nikulin et al., 2025)

[Full paper](https://arxiv.org/abs/2502.00379). This controlled failure analysis reproduces LAPO with three stacked frames, then removes VQ, uses a uniformly sampled multi-step endpoint k from 1–10, raises continuous latent width from 128 to 8192, removes pixel reconstruction in favor of latent temporal consistency, and adds random shift/rotation/perspective augmentation. The representation uses ResNet observation features and MLP IDM/FDM; the target is stop-gradient or EMA encoded future features (Secs. 3–4, Apps. D–F). The FDM predicts compact next-state features rather than RGB; removing reconstruction does not make the codes control-minimal. The action decoder is a two-layer 256-hidden-unit MLP. On four Distracting Control Suite tasks, they collect 5,000 trajectories per task, 1,000 transitions each, rendered at 64×64 with 60 dynamic background videos, camera shake and agent-color change; one H100 in bf16 is reported (App. C–D). Pure LAOM improves linear action probe quality eightfold and downstream performance up to 2× over LAPO, but still underfits the task and stores distractors. Adding action labels during LAM training—reusing the same labels later used for decoding—gets normalized return 0.44 with 2.5% of transitions labeled; reducing latent width 8192→64 then loses 16%, versus 63% without supervision (Secs. 5–7). This is unusually direct evidence for using our 84 robot labels in training, not only at the last decoder stage. The authors caution DCS distractors may not fully match web-video noise and the cross-embodiment benefit did not exceed BC on the few labels.

### 5. IGOR: Image-GOal Representations as Atomic Control Units (Chen et al., 2024)

[Full paper](https://arxiv.org/abs/2411.00785). IGOR encodes a current image and an image-goal into four VQ tokens (codebook 32, embedding width 128) using an ST transformer over frozen DINOv2 features; its FDM predicts the goal representation from the initial image plus code, which makes the code carry goal displacement (Sec. 2, App. A). It deliberately selects frame intervals with visible movement: too small is ambiguous; too large is hard to model. The paper does not give one universal frame gap. A foundation world model predicts video conditioned on latent actions; a language policy plans subtask-level latent actions, while a low-level RT-1-style policy turns these into 7D robot chunks (the latent itself is not a direct joint-action decoder). Pretraining mixes about 0.8M robot trajectories with 2.0M filtered human-video clips; camera motion estimation removes about 40% of open-world clips, and remaining footage is stabilized. LAM training is 140k steps, batch 512, Adam at 1.5e-4 (App. A). Human-derived actions can produce robot-like motion in generated videos and nearest latent neighbors correlate with RT-1 actions, especially translation. Crucial limitation: the authors explicitly cannot separate agent-caused change from other agents or camera shake; they filter/stabilize and exclude other agents, and list object segmentation and multi-agent modeling as future work (Sec. 5). This is promising for high-level task-centric transitions, less so for reliable mapping into our 54D chunks without a decoder.

### 6. DynaMo: In-Domain Dynamics Pretraining for Visuo-Motor Control (Cui et al., 2024)

[Full paper](https://arxiv.org/abs/2409.12192). DynaMo is included because it uses latent-action-like conditioning for visual dynamics pretraining, but its objective is primarily a representation-learning/world-model objective rather than a complete reusable latent action interface. A causal transformer IDM infers a continuous latent sequence from an observation window and an FDM predicts the next embedding; cosine prediction, covariance regularization and stop-gradient/EMA avoid collapse instead of pixel reconstruction (Sec. 3). Width is benchmark-specific: reported examples include 64 for Franka kitchen, 16 for block pushing, 8 for Push-T, 32 for LIBERO and 64 for xArm (App. B). Frame context also varies by environment. The next embedding does not receive the full future RGB image, but no physical action decoder is supplied as a general interface; downstream robot policies are trained on visual state and action labels. In real settings the xArm data has 65 demonstrations over five tasks, four camera views at 30 Hz, with 10 Hz rollout; the study also evaluates Allegro and simulation. Results improve real xArm success by 20 percentage points and Allegro by 43 points relative to the best baseline (Sec. 5). This is relevant to our world-model feature target and compute feasibility, but not evidence that an unsupervised z alone is executable or robot-agnostic.

### 7. AdaWorld: Learning Adaptable World Models with Latent Actions (Gao et al., 2025)

[Full paper](https://arxiv.org/abs/2503.18938). AdaWorld uses a continuous 32D VAE latent action from a pair of current/future frames, with a small KL coefficient (β=2×10⁻⁴); two learnable action tokens interact with 16×16 patch features in a spatiotemporal transformer. The decoder reconstructs future pixels from the current frame plus z, so the future target is not fed to the FDM (Sec. 2.1). The paper uses about a 0.1-second interval at 10 Hz. A diffusion world model based on Stable Video Diffusion (about 1.5B parameters) predicts future video; the 500M LAM is trained on 256×256 data. The training recipe reports 200k LAM steps at batch 960 and 80k world-model steps at batch 64, using 16 A100s (Sec. 3, App.). Data mixes robot and human videos, including Open-X and Something-Something, plus games; filtering removes static, nonconsecutive and low-quality clips. For transfer, the paper proposes clustering pseudo-actions to options or collecting a small set of native actions and learning an action interface; it is not a physical robot deployment demonstration. Limitations include slow/non-real-time generation, drift, limited novel scene generation and failures under abrupt view change (Sec. 4.2). Useful for adaptable world-model design, expensive for shared H20 and not an immediate dual-arm decoder.

### 8. CLAM: Continuous Latent Action Models for Robot Learning from Unlabeled Demonstrations (Liang et al., 2025)

[Full paper](https://arxiv.org/abs/2505.04999). CLAM specifically avoids VQ: it learns a continuous 16D action, with context length two, an IDM and an FDM that predicts the single next observation (App. table 11; Sec. 3). Joint objectives include reconstruction and supervised action-decoder MSE on labeled transitions. Alternating labeled/unlabeled training makes z directly decodable, and a latent policy predicts z before a small decoder outputs real actions; hence the mapping is learned, not assumed. Experiments span DMControl, MetaWorld and WidowX. The robot data includes 50k play transitions at 5 Hz plus 30 expert demonstrations per task; labeled robot actions are 7D. WidowX observations use two fixed views, and policy action chunks cover five timesteps. The robot policy uses 20k updates, batch 256, reported at about two hours of training (Sec. 5, App.). CLAM reports roughly 2–3× success over the compared baselines on its tasks. The authors say control-space coverage still requires a diverse labeled action set; the human-hand/robot embodiment and camera-domain gaps are not solved (Sec. 8). This is a practical low-dimensional continuous baseline, though its tested action spaces and data are far from 54D bimanual control.

### 9. Moto: Latent Motion Token as the Bridging Language for Robot Manipulation from Videos (Chen et al., ICCV 2025)

[Full paper](https://arxiv.org/abs/2412.04445). Moto encodes a temporally subsampled adjacent frame pair using frozen ViT patch features, an M-former and eight query tokens. VQ uses vocabulary 128 and 32D token embeddings; a decoder reconstructs the next frame from the previous frame and quantized motion code. Pixel MSE plus codebook/commitment losses train the token (Sec. 3). Data sources use different frame separations—e.g. RT-1 is downsampled to three frames and human video uses Δt=6—so there is not one universal physical horizon. A GPT predicts motion tokens conditioned on language and the first frame. At robot fine-tuning, robot action queries share the transformer and an MLP action head predicts controls; Moto does not simply decode each z with an isolated latent-to-action MLP (Sec. 4). Pretraining uses 109k OXE videos and 73k labeled RT-1 trajectories, plus CALVIN and human videos; the LAM, GPT and fine-tuning stages are reported on 4, 8 and 4 40GB GPUs respectively, with 350k LAM updates and 10 GPT epochs (App.). Real experiments use 90 demos; 1% labeled fine-tuning reaches 52.5% success versus zero for the cited baseline. The paper treats scaling/general video data as future work; the camera and embodiment distribution remain important.

### 10. CoMo: Learning Continuous Latent Motion from Internet Videos for Scalable Robot Learning (Yang et al., 2025)

[Full paper](https://arxiv.org/abs/2505.17006). CoMo is continuous: eight learned query vectors, 16 dimensions each (128D total), with no VQ. A pretrained MAE ViT-L encodes frames; the IDM uses the current feature and a difference feature, D=F(t+n)−F(t), rather than the future feature itself. The FDM predicts the feature transition; MSE plus perceptual reconstruction trains motion, suppressing static appearance and direct copying of the future embedding (Sec. 3). Frame gaps vary by source: 10 for LIBERO/SAM-V/EgoVid, 5 for CALVIN and 20 for DROID. Robot action and latent motion heads train jointly in a diffusion policy; this gives a learned action head but not an independently verified universal z→54D map. The paper trains 50k steps at batch 256 (CALVIN 150k), AdamW 1e-4, on internet and robot mixtures. Human videos are tested with 20 robot demonstrations plus 20 human videos per task over three tasks. CoMo beats the cited discrete baseline on LIBERO (80.8 vs 73.6 average success) and reports 81.8 without LAM fine-tuning. It still trails action-label training (89.2), and increasing latent size can leak appearance; removing feature differences catastrophically leaks static content. Transfer from human motion remains imperfect (Secs. 4–5).

### 11. Object-Centric Latent Action Learning (Klepach et al., 2025)

[Full paper](https://arxiv.org/abs/2502.09680). This study replaces a monolithic image with VideoSAUR/DINOv2 object slots or slot-masked image inputs, then learns continuous LAPO-style transition codes. It does not quantize the LAM action. Image baseline uses a 1024D latent, three-frame stack and 10-frame future offset; slot variant uses an 8192D latent, one-frame stack and the same offset (Secs. 3–4, App.). Four or eight object slots are used by task; control-related slots are manually selected from masks, a material supervision/selection burden. The DCS tasks use 5k trajectories of 1k transitions each and 60 DAVIS backgrounds plus color and camera perturbations. Slot training is about 6h35 on an H100; complete OCP plus LAM runs take 9–14 hours (App.). Slot/mask variants reduce action-probe degradation under distractors from 5.3× to roughly 2.5–2.7× and improve downstream return by an average 2.6× over a distracted image LAM with 32–128 action-labeled trajectories. This offers a direct camera/object-centering option for our bottle/bin/grippers, but slots need reliable detection, manual selection can break under occlusion, and no robot or bimanual evaluation establishes transfer.

### 12. PlaySlot: Learning Inverse Latent Dynamics for Controllable Object-Centric Video Prediction and Planning (Villar-Corrales et al., 2025)

[Full paper](https://arxiv.org/abs/2502.07600). PlaySlot combines SAVi object slots with an inverse dynamics model from adjacent frame pairs and an object-centric forward model predicting next slot states. Its action code is hybrid: a discrete prototype plus continuous variation. Reported prototypes include 8×16D for ButtonPress, BlockPush and Sketchy, and 5×8D for GridShapes; three-layer MLP hidden size 128 maps z to physical actions, trained from a limited labeled set (Secs. 3–4). A policy predicts codes with BC. Data include 10k random ButtonPress sequences and 1k expert demonstrations; other simulated tasks and 394 real tabletop Sketchy videos of length 80 are also used. Slot parsing gives resilience to appearance changes but busy scenes and out-of-distribution object motion challenge masks. The world model’s accumulated errors can make imagination worse than direct action decoding; the paper shows a ButtonPress miss caused by chained prediction and decoder errors (Sec. 5). This separates the robot-action decoder from the world-model rollouts explicitly, a good design pattern; image/object slot quality and long-horizon error still need independent checks.

### 13. UniVLA: Learning to Act Anywhere with Task-Centric Latent Actions (Bu et al., 2025)

[Full paper](https://arxiv.org/abs/2505.06111). UniVLA first learns task-irrelevant visual-change tokens to avoid binding action codes to scene appearance, then freezes that codebook and learns task-centric tokens. A VQ-VAE and spatiotemporal transformer encode current/future DINOv2 features about one second apart; the decoder predicts future DINO features from current features plus code and has no full future target input, reducing a history shortcut. The policy emits four tokens, each from a 16-entry vocabulary, using a 7B Prismatic VLM. A 10.8M-parameter MHA/MLP action decoder maps latent tokens to joint/head action chunks; robot post-training uses LoRA. The total trainable parameter count is about 123M; reported pretraining uses 32 A100s for 30h (960 A100-hours) with Bridge/Open-X/GNM and Ego4D data (Secs. 3–5, App.). It reports gains across LIBERO, navigation and real robot tasks with one tenth the task data. Language annotation and task-centric supervision are part of the setup. Authors explicitly flag codebook/granularity constraints and say dual-arm hands require finer design. This is a useful task-conditioned discrete policy idea, not evidence for using four codes unchanged on our two arms.

### 14. GR00T N1: An Open Foundation Model for Generalist Humanoid Robots (NVIDIA, 2025)

[Full paper](https://arxiv.org/abs/2503.14734). The action-free video path uses an LAPA-like current/future VQ-VAE at a fixed horizon. The unified codebook is learned from mixed data, but the video action head consumes the continuous pre-quantization embedding; the paper does not clearly report the LAM embedding dimension or one fixed frame gap, so neither is inferred here. A separate flow-matching LAPA embodiment head maps video latents into robot actions, alongside native robot-action training (model/data and training sections; App.). The 2.2B generalist model is trained with a reported 50k H100 GPU-hours and up to 1024 GPUs. Data include teleoperated and DROID robot trajectories plus human videos and synthetic neural-video trajectories; the reported GR-1 bimanual action is 14D and predicted in chunks of 16, at 20 Hz. System 2 runs at 10 Hz, System 1 at 120 Hz, with a reported 63.9ms 16-action inference on L40. It is a costly embodiment-conditioned action-mapping example, not a low-compute recipe. The paper reports catastrophic forgetting: right-hand post-training loses a previously learned left-right handover behavior; short-horizon tabletop tasks and synthetic video physics are also limitations. Its 14D action scale does not directly match our 54D dual-arm interface.

### 15. villa-X: Enhancing Latent Action Modeling in Vision-Language-Action Models (Chen et al., 2025)

[Full paper](https://arxiv.org/abs/2507.23682). villa-X uses an 8-frame 224×224 video input, a 12-block spatiotemporal transformer and a 32-entry VQ codebook. The FDM predicts future visual reconstruction and robot proprioception/action-related state; human video has visual-only prediction, while robot data adds proprioceptive losses (Secs. 3–4, App.). Explicit embodiment ID and control frequency are included in proprioception. A two-expert ACT policy predicts latent diffusion steps and robot action diffusion steps; cross-attention conditions executable actions on latent actions, with masked attention to limit overreliance. Thus there is an explicit learned latent-to-action route. The appendix reports large distributed A100 training, 128 A100s for the LAM and 64 for policy stages; the described robot evaluations include 375 demonstrations for real gripper tasks and about 4,000 dexterous sequences across 13 categories. Some dataset counts in the paper are ambiguous/inconsistent, so they are not used here. It reports real robot tasks and dexterous manipulation but no convincing dual-arm transfer test. High compute and large action/state supervision make this more of a blueprint than a fit for our shared H20 budget.

### 16. WLA: Inter-environmental World Modeling for Continuous and Compositional Dynamics (Hayashi et al., 2025)

[Full paper](https://arxiv.org/abs/2503.09911). WLA is an adjacent continuous action/world-model framework rather than a standard endpoint-pair IDM. It represents transformations in a Lie group with continuous scale/rotation parameters and object-centric slots, sharing a structured action space over game and robot-like videos. A per-environment controller maps available native actions into group generators/parameters; when native action labels are absent it can still use an unstructured latent interface. The representation assumes a restricted commuting/abelian family of transformations (not arbitrary 54D joint control). Procgen uses 16 games; Phyre data are sampled at 1 fps for training and interpolated to 8 fps; the Android 1X world-model data include over 100 hours of robot video. It reports continuous and compositional control across environments (Secs. 3–6, App.). Assumptions include deterministic dynamics, a fixed number of transformations and commutativity. It demonstrates that an explicit geometry can aid transfer, but its scale/rotation algebra does not directly represent coupled dual-arm joint actions.

### 17. Learning Latent Action World Models in the Wild (Garrido et al., 2026)

[Full paper](https://arxiv.org/abs/2601.05230). This paper jointly studies LAM/world-model learning in frozen V-JEPA2 feature space using continuous 128D latent actions. The IDM encodes feature transitions from frame pairs; because the video tokenizer creates temporal patches, one latent transition corresponds to two source frames. The FDM predicts a future embedding from history plus z. Ablations compare vector quantization, variational noise and sparse/temporal regularization; discrete latents lose complex in-the-wild motion, while sparse/noisy continuous codes do better (Secs. 3–5). A large training run uses YouTubeTemporal-1B, 30k steps, batch 1024, about 12 hours on 64 H100s. Physical actions are mapped through a lightweight controller conditioned on past representation and native action: without the scene context, action projection often predicts no motion, since the action is camera-relative. The same latent can transfer visually between DROID manipulation and human/navigation scenes, but only if the moving agent is visible and the controller has context. Failures include invisible arms, poorly predicted scene entries, long-horizon drift and view change. This is an important warning that video-level robot agnosticism can coexist with embodiment-specific action decoding.

### 18. LAWA: Latent Action as Intention Enables Efficient Future Imagination for World Action Models (Li et al., 2026)

[Full paper](https://arxiv.org/abs/2608.24882). LAWA is a recent WAM design: a discrete action tokenizer is trained with future-frame reconstruction and a SAM2 mask prediction objective from a latent prompt to focus on hand/manipulator motion. The paper’s test-time policy uses continuous flow-matching latent actions as a relaxation of the discrete training codes; it does not snap denoised codes back to nearest VQ entries. In its structured attention mask, video future tokens cannot leak into latent-action or action branches. The source HTML does not state a reliable latent dimension, codebook size or universal input frame gap, so those are left unspecified. Robot and egocentric action-free videos are mixed, with sampling rates aligned and robot data at roughly 20%. It reports 65.6% RoboCasa success at 10% data, 80.8% full-data RoboCasa and 74.4% zero-shot LIBERO-Plus. A useful causal test replaces/noises only model-visible latent actions, reducing success from 80.8% to 52.2%; SAM masks also improve performance (Secs. 3–4). Real tests cover four tasks with 50 robot demos per task in the reported 25% setting. Strong evidence for an action-swap sensitivity audit and mask-conditioned training, but the paper’s compute/model footprint and the exact latent granularity are not transparently stated in the HTML, and a world-action model is not a 54D decoder.

### 19. LAC-WM: Latent Action-Conditioned World Models for Cross-Embodiment Transfer (2026)

[Full paper PDF](https://arxiv.org/abs/2610.10846). This October preprint uses frozen V-JEPA2 visual features, an IDM over consecutive embeddings, a continuous 512D latent, and a conditional FDM that predicts future visual features. Independent augmentations on IDM and FDM inputs reduce future-frame identity shortcuts. A motion decoder grounds the code to end-effector or human-hand displacement and camera motion; the latent is partitioned for end-effector and camera components. Training combines EgoDex human hand data, AgiBot bimanual and DROID Franka, about 50k trajectories each; 80k iterations, batch 512, with five-step action chunks. For an unseen robot, the recipe is LoRA adaptation of IDM/FDM plus a new two-layer MLP projector from native actions to z, then joint projector/FDM tuning. The paper reports up to +46.7% dexterous success and 92 vs 82 LIBERO, with positive scaling over embodiments; the PDF reports roughly four days on 64 H200 GPUs (Secs. 3–6, Apps.). It is one of the most direct architecture matches for separating motion from camera and adding an embodiment projector. It is far beyond our shared H20 budget, depends on motion labels and does not demonstrate physical hardware deployment; absolute dexterous success remains low.

### 20. LatentVLA (AAAI 2026)

[Official proceedings paper](https://doi.org/10.1609/aaai.v40i22.38926). This is a multi-view, language-conditioned continuous latent model, not a simple pairwise frame-only IDM. It uses a 512D continuous action with five-frame history (h=4), SigLIP-guided spatial attention, temporal encodings, next-image feature reconstruction and an action MLP supervised on robot actions. The future reconstruction FDM also receives encoder context; there is no explicit stop-gradient bottleneck preventing future detail from being coded, so action supervision is important grounding (pp. 2–5). A diffusion latent planner predicts 16-step sequences and a frozen action decoder emits real robot chunks. It trains on over 2.5M sequences from 52 sources; pretraining uses 112 A100-80GB GPUs for about a month, then 100k fine-tuning iterations (pp. 6–8). It directly evaluates 14D bimanual state/action and eight real tasks, reporting 63.8% mean success. Ablations show large drops when removing temporal encoding, language-guided attention, latent history or the continuous planner; failures include object occlusion and reflective surfaces (pp. 6–9). This is the closest evidence for bimanual structured latents, but the scale, multiple cameras and task conditioning differ sharply from our single-camera 84-demo regime.

### 21. What Matters for Latent Actions in Robot Learning (2026)

[Full paper PDF](https://arxiv.org/abs/2608.19613). This is the key systematic design and failure analysis: 41 choices are studied across LIBERO, LIBERO-Plus, RoboTwin2.0 (14D bimanual) and a Franka real robot. Baseline latent size is 64, with direct comparisons at smaller sizes; 32D is a practical cross-control option. A simple DINO feature-difference baseline scores about as well as more elaborate LAMs; in the paper’s average comparison LAPO is 0.7327, ΔDINO 0.7280, CoMo 0.7167 (Secs. 3–5, pp. 2–15). VAE, sparsity and SIGReg can perform similarly on LIBERO, while VQ-VAE is strongest on LIBERO-Plus zero-shot; the paper proposes VAE as a default and VQ when zero-shot generalization matters, with tuned coefficients β=1e−7, sparsity 1e−5, SIGReg 1e−3 and VQ 1. Proxy metrics are useful for screening but their ranking does not predict exact task performance; FDM reconstruction is more reliable than action linear probes, and comparisons should hold latent width constant. Policy co-training and action-head strategy materially matter. VLM latent fine-tuning improves Franka from 64.75 to 79.25. Experiments use 8 H200s. The paper recommends task-specific tuning; it does not establish a universal diagnostic threshold or prove that action-indifferent WMs are fixed by any one regularizer (Secs. 6–8 and appendix).

### 22. Action-Similarity Supervision for Cross-Embodiment Transfer in Latent Action Models (Alvarez et al., 2026)

[Full paper PDF](https://arxiv.org/abs/2609.19846). This is a direct test of action grounding across embodiment. The authors compare an AdaWorld VAE backbone (continuous 64D, H=1) with a LAOM backbone (continuous 1024D, future gap uniformly 1–10). They add a loss matching cosine similarities between normalized/flattened latent actions to similarities between labeled action chunks, allowing ±2 temporal shifts; λ=0.05 for LAOM (Sec. III, pp. 2–4). The policy predicts latent codes and a per-embodiment decoder produces padded joint actions; an end-effector delta target transfers better than joint-space coordinates. RoboTwin2 uses Aloha and dual Franka with three tasks each, 50 demos per task, same overhead/head cameras. Cross-embodiment transfer is zero-shot in task demos after training the decoder. Unsupervised LAOM transfer gets 36%, auxiliary action prediction 34%, similarity supervision 46%, end-effector delta 53%, and cross-embodiment pairs 61.3% transfer (69.3% in-domain); wrist cameras reduce transfer to 46% (Secs. IV–V, pp. 4–7). A new UR5 test with the fixed latent policy and new decoder achieves 0% over 300 trials; open-loop works partially on two tasks but not switch-turning (App. p. 9). The lesson: similarity supervision helps between related arms, but one cannot infer arbitrary robot-agnostic decoding from visual z.

### 23. FLAM: Factored Latent Action World Models (Wang et al., 2026)

[Full paper](https://arxiv.org/abs/2602.16229). FLAM factors the scene into slots and infers one latent action per factor, addressing the combinatorial growth when multiple entities move independently. A pretrained image tokenizer is a VQ-VAE with FSQ features; per-slot IDM/FDM predicts next factor features, with a VAE-style KL regularized action (β=2×10⁻⁴), rather than one monolithic action token (Secs. 3–4). Factor width totals 128 across K=4 slots (32 each), or K=16 for nuPlan; the transition input is an adjacent frame feature pair. Future information is the IDM target, while each FDM only sees the current factor plus its z; per-slot reconstruction encourages factor-specific predictions. There is no general robot action decoder; a small decoder trained with a limited set of labeled transitions supports Procgen policy learning. Experiments use MultiGrid, Procgen and nuPlan; factorization improves prediction and representation in multi-entity settings, with policies benefiting on Procgen (Secs. 5–6, App.). Factor count is important: too few factors merge entities; excessive slots are less harmful. It assumes slots correspond to independently acting entities and uses a frozen dataset-specific tokenizer; there is no bimanual robot test. For us, separate arm factors plus a shared interaction factor are plausible, but explicit coordination must be modeled rather than assumed independent.

### 24. OneLA: Learning Many Worlds from Latent Actions (October 2026)

[Full paper](https://arxiv.org/abs/2610.20160). This newest included work learns a shared continuous 32D action interface from 1.79M clips across games, navigation, driving, egocentric and robot video. The pairwise LAM is a 24-block ST transformer, width 1024, patch size 16, 16 heads, diagonal-Gaussian posterior, and a learned orthonormal motion dictionary; KL plus L1 sparsity (β=1e−6, λ=0.01) regularize the action. A decoder reconstructs the future frame from current frame plus z, so it has a direct next-frame conditional world-model target (Sec. 3.1, App. A). A frame-pair action is adjacent in the LAM; for the video tokenizer, four consecutive 32D codes are packed into each transition adapter. Native controls are mapped to the shared z through per-domain two-layer MLPs (input widths 8 keyboard, 6 driving, 14 AgiBot, 7 RT-1; 32D output), pretrained for 20k alignment iterations. LAM training is 50k steps, batch 640 on 16 GPUs; a frozen Wan2.2-TI2V-5B world model trains 6k updates, batch 16, on 16 GPUs (Secs. 3.2–3.5, App. A). Joint video plus latent-action prediction improves unlabeled-video world modeling; removing action conditions or action-prediction loss hurts (Sec. 4). Action-cycle transfer is mostly open-loop and future work explicitly calls for long-horizon closed-loop interaction. Strong shared-interface design, but not low-compute and not yet proof that the command MLP generalizes to a new arm without calibration.

## How to adopt this for our robot

### What the evidence means for this setting

Our action space is 54-dimensional, actions are issued in 10-step chunks at 15 Hz (about 0.67 s), and observations are from one fixed top RGB camera. There are 84 teleoperation demonstrations of grasp-bottle-place-in-bin. The current latent world model barely changes its value prediction when actions are swapped. This is an action-conditioning failure before it is a latent-size problem: a new latent model will not help unless its predicted transition and value depend on the transition-driving code.

The robot already supplies the scarce supervision LAOM says to use early. Use it to make action-effect semantics explicit, then test whether a compressed continuous code retains what the baseline action model predicts. Do not assume our 84 demos are enough to learn a 512D/8192D action space. The paired robot data is a better first source than web video because its camera geometry, object, arm visibility, task and action labels match the deployment setting.

### Recommended staged design

1. **Create an action-conditioned control baseline first.** Align each observation at t with the action chunk from t to t+10 and the observation at t+10. Train a simple state/action predictor for gripper pose, bottle pose, bottle-in-bin state and success value. Feed the real 54D action chunk and report shuffled-action performance. If that model also ignores the action, verify timestamp alignment, joint order, action normalization, gripper sign, action repeat and whether the camera sees the effect before adding a LAM. Split training/validation/test by full demonstration, not frame, to prevent nearly identical overlapping chunks leaking across splits.

2. **Try a compact continuous bottleneck on those same pairs.** A reasonable first comparison is a 16D joint latent and a factorized 8D left-arm + 8D right-arm latent. Keep the arm split faithful to the actual 54D action schema. Add a small shared 4–8D interaction code if a grasp or transfer requires coordinated motion. Compare against a 32D joint latent. For each, encode the (t,t+10) visual transition and train an action-conditioned FDM from current observation/features plus z to the t+10 state features; do not expose the future frame to the FDM. Use continuous values first because the label set is small and the action chunk has fine timing. Add a small VAE/KL or sparsity penalty only if the latent demonstrably copies appearance; evaluate VQ as a follow-up if discrete codes improve held-out transfer, not as an assumed fix.

3. **Use labels during latent learning, not just afterward.** Decode z to the 10-step native joint-action chunk using the existing teleop labels. A decoder can be two per-arm MLP heads with a shared trunk and cross-arm/current-state context, predicting time-structured chunks rather than flattening 540 independent numbers if the action format is per-joint per-step. Compare direct MSE/Huber action prediction with a similarity objective: normalize per-arm action chunks, compute chunk similarity in either joint delta or end-effector delta space, and align latent similarities to it. The latter follows Action-Similarity Supervision and can preserve “similar motion” across arms, while the decoder remains explicitly embodiment-specific. At 84 demos, use a small linear/MLP decoder and regularization; report per-task phase errors instead of adding a large policy head.

4. **Make the visual target action-relevant.** For the one top camera, use frozen or lightly tuned visual features and track/segment both grippers, bottle and bin. Predict gripper/object/bin geometry or feature deltas alongside any RGB feature target. Test raw pixels, DINO-style features and object/ROI features. Independent mild crops/color perturbations for IDM inputs and FDM targets can reduce identity shortcuts; do not augment so aggressively that the bottle/gripper location no longer matches the action. A fixed camera reduces view variation but does not eliminate arm occlusion, shadows, lighting changes or background correlations.

5. **Train the world model so z has a job.** Give the FDM current state/history and z, and require it to predict the next action-relevant state. Do not give the predictor the future RGB embedding or future action chunk. Include the action-decoder loss during LAM training. If history can already explain the next frame, evaluate the transition head with a fixed history and substituted z; keep history only as long as needed for partial observability. Add counterfactual paired supervision only where the swapped action changes the target outcome: a contrastive or ranking loss can require the valid z to predict the observed object displacement better than a z from a nearby starting state with a different action. Do not optimize a raw action-sensitivity norm alone, which could reward sensitivity to irrelevant pixels.

6. **Only after local success, add pretrained video.** Evaluate a frozen LAPA/CoMo/UniVLA/LAWA-style representation on the same 84 robot pairs and fit a small z→54D chunk decoder. Also try a LAM pretrained on robot video if available. Report the same mapping and swap metrics as the robot-only model. If using human video, first filter to visible hand/object interactions, normalize frame gap to roughly 0.67 s of visible motion, compensate egocentric camera motion, and use hand/object trajectory or task-relevant masks. Then fine-tune or align on the robot demos with action-similarity supervision. Human action can mean camera motion, contact change, tool motion or another person’s motion; visually similar human latent codes are not proof of a robot-executable movement. One embodiment alone cannot establish robot-agnosticity.

7. **Preserve coordinated bimanual semantics.** Compare one joint latent against two per-arm latents plus an optional shared interaction latent. Decode both arms together and give each head the other arm’s code/current pose. Evaluate left-only, right-only, coordinated and deliberately swapped-arm transitions. Do not force independent per-arm prediction if the task includes holding the bottle with one gripper while the other arm adjusts, or if collision avoidance couples both arms. A shared code can represent contact/coordination; separate codes can improve compositionality. Use this ablation to decide.

### Action-dependence evaluation and a value gate

Run these as a fixed evaluation set before and after each representation change:

- **Latent swap test:** Hold the starting image/state and world-model history fixed. Compare the correct z with a z swapped from a transition with a similar starting scene but a meaningfully different action. Also test zero z and left/right swaps. Measure the predicted gripper displacement, bottle displacement, bin entry probability and value. Report the effect size between correct and swapped codes, and compare the correctly conditioned prediction error with the unconditional model.
- **Matched action swap on native actions:** Repeat the same test using actual 54D chunks. This separates bad latent encoding from bad action wiring or an inherently action-insensitive FDM/value head.
- **Value gate:** On held-out demonstrations and success/failure or outcome labels, check that value for the correct transition is calibrated higher than for within-state shuffled actions that disrupt the bottle trajectory. Report pairwise ranking accuracy/AUROC and calibration; include tasks where an alternative action can also succeed so the gate does not penalize valid alternatives.
- **Action decoder:** Decode z to a 10-step chunk; report per-arm action error, end-effector displacement error, gripper open/close accuracy and open-loop success. Execute correct and shuffled decoded chunks only in the same safe evaluation protocol used for demos.
- **Generalization:** Hold out complete teleop episodes and vary object pose, starting bin/bottle positions and lighting if present. Report performance separately by grasp, lift, transport and release phase; an aggregate score can hide a representation that only captures the most frequent phase.
- **Ablation:** Compare direct action input, robot-only LAM, pretrained LAM plus small decoder, continuous versus VQ, joint versus factorized per-arm latents, RGB versus object/feature targets, and without/with similarity/action loss. Keep data splits and policy/world-model capacity fixed.

A practical pass condition is: real native action inputs must materially change predicted end-effector/object transitions; correct latent actions must outperform matched shuffled and zero latents on the same initial state; value ranking must distinguish successful from disrupting transitions on held-out demos; and the decoded code must reproduce the intended transition better than the unconditional baseline. Set numerical thresholds from the current direct-action baseline and sensor noise, not from another paper’s task.

### Compute, costs and risks

A 16–32D continuous encoder, small FDM and two action-decoder heads are a modest first experiment for shared H20s, but the literature does not report H20 timings for this exact setup. Start with offline cached visual features and short transitions. Full-resolution video diffusion models, giant VLMs and broad 512D latent world models are not necessary to test the core hypothesis. LAC-WM reports four days on 64 H200s; GR00T reports 50k H100 GPU-hours; Genie’s large run uses 256 TPUv5p. Those are not feasible analogues for a shared H20 allocation. Even moderate models can overfit because 84 trajectories are not 84 independent transition types; overlapping frame pairs do not multiply the effective number of demonstrations.

Main risks:

- **Frame alignment:** 10 steps equals about 0.67 s only if camera frames and action chunks have the expected clock alignment. Off-by-one or teleoperation latency can make a good action look unrelated to the observed transition.
- **Small-data leakage:** random frame splits inflate results; use trajectory-level splits and avoid evaluating near-duplicate overlapping pairs.
- **Partial visibility:** one top camera may occlude grippers or bottle during contact; image-only inference can be ambiguous about hidden joint motion.
- **Camera/distractor encoding:** an IDM can compress scene or camera changes because they explain frame differences. Camera invariance is not guaranteed by quantization, KL or a smaller dimension.
- **Decoder undercoverage:** 84 demonstrations may not cover all safe 54D chunks; a low error on observed action modes can still extrapolate dangerously.
- **Bimanual coupling:** separate latents can miss contact and coordination; a single shared latent can entangle arm-specific motion. Measure both.
- **Robot-agnostic claim:** action-similarity supervision supports transfer among related arms, but the cited UR5 result is 0%; a new robot still needs a calibrated low-level action map.
- **Outcome confounding:** if only successful demos are labeled, a value head may learn the demonstration’s visual state but not distinguish alternative actions. Add safe negative/shuffled pairs or action-conditioned prediction labels before trusting the value gate.

## Open questions for our project

1. Does the action-swap failure come from incorrect time alignment, action normalization, missing action token exposure, a history shortcut, or the value model objective?
2. What portion of each 10-step action chunk produces a visible change in the top camera, and is one fixed 0.67-second gap appropriate for approach, grasp, lift and placement alike?
3. Are 54 action dimensions joint positions, velocities, deltas, or target commands, and do both arms share the same scaling and gripper convention?
4. Can the bottle, both grippers and bin be tracked robustly enough to define an action-relevant FDM target despite occlusion?
5. Is a single 16D joint code sufficient, or does the task need two arm codes and a shared contact/coordination code?
6. With only robot videos from one embodiment, what does “robot-agnostic” mean operationally—similar actions across the two arms, or transfer to a different robot after learning one small action projector?
7. Will pretrained human/action-free video add useful grasp/transport semantics after camera compensation, or mostly add viewpoint and hand-motion nuisance?
8. Does the learned value change in response to valid action interventions and predict task outcome on held-out episodes, rather than simply matching action-conditioned image features?
