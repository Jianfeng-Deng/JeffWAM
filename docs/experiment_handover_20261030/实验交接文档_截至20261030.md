## 5. 实验路线与保留结论

### 5.1 LeWM短时动力学、回放与执行平滑

自建CPU LeWM、官方Cube初始化适配、本体速度/跟踪误差输入和单步预测，证明局部状态转移可学习。重叠融合、固定flow噪声和速度/加速度限制可改善部分抖动，但不能修复错误目标。

早期平滑视频中很多使用了真实反馈或未来记录命令，是动作条件预测/URDF回放，不能与自主策略闭环作同难度对比。

封存包位于 `/mnt/workspace/dengjianfeng/code/lewm_tianji_cpu/releases/`：`official_task_v1_20261024` 为官方初始化的动力学预测包；`best_tracking_h1_v1_20261024` 为封存时首动作跟踪基线，本体输入、无视觉/语言。二者均非已验证自主抓放策略。

### 5.2 手码、解码器与物理关节监督

逐指完全独立解码弱于共享交互；用户提出的“指内展开＋共享dense mixer”示范手码重建约0.047–0.050rad，与共享MLP接近，保留为压缩对照。示范手码重建好不代表策略预测手码正确。

加入解码后40D手关节位置和示范差分监督，差分改善较明确，位置收益不一致。后续匹配对照中直接54D优于24D压缩的短时手型，但这不证明54D已具备正确抓型或目标识别。

### 5.3 原生回归、本体反馈、SAM与LoRA

MSE/RMSE、绝对/当前q残差、24D/54D、q/q+dq、多视角等已测试。本体反馈与清晰动作定义比单纯把MSE换为RMSE更关键；三视角并未在当时协议中稳定改善。

SAM全图mask、action-only分支与原生视觉LoRA均有历史对照。分支有非零梯度/输出影响，但未稳定超过匹配raw基线。旧MuJoCo测试曾把训练soft mask换成黑背景RGB，并使用错误历史；修正后出现局部、阶段相关的正确响应。因此不能保留“mask分支完全无用/总是反向”的旧断言。

历史Qwen/VLM/DINO融合记录没有建立可靠语义泛化收益；当前均非推进路线。

### 5.4 终态目标与V-JEPA动作头对照

全量终态MSE run计划10k，在6k被用户停止，best为2k；9集宏平均10帧RMSE0.0602rad、hold0.0847rad。训练日志另一种汇总RMSE为0.0722rad，不可与宏平均混用。本轮配对flow未形成可比较checkpoint。

V-JEPA37/9、1000步、相同目标/监督匹配对照：

|---|---:|---:|---:|
| MSE | 0.07527 | 0.02485 | 0.07486 |
| Flow | 0.09093 | 0.03543 | 0.09097 |
| Hold | 0.10096 | — | — |

该协议下MSE胜出，不能外推为flow普遍无效。换成其他episode图像会退化，但空间token乱序只增加约0.00098rad；固定q/dq移瓶时动作修正弱。它说明存在视觉影响，尚无正确空间控制证据。

### 5.5 JEPA辅助预测、空间goal、运动加权与FK

动作条件残差预测与独立无动作模型：未来RMSE0.456966/0.457151，persistence0.457491；动作条件收益约0.041%，动作策略几乎相同。

后续已实现空间goal序列、标准化残差、限幅运动权重、未来实测q计算双腕FK监督。1000步未来RMSE0.457622，仍略差于persistence0.457491；未来腕部误差2.76cm，保持当前腕部1.99cm。中间层/探针对照尚未提供足以解决当前策略问题的证据；11.6cm定位探针误差不等于编码器绝对不含空间信息。

逆动力学暂缓。动作重构循环可能把动作隐写入latent，不能替代真实后果准确性。

### 5.6 显式状态转移与候选池

使用MuJoCo同状态执行示范、策略、hold、受限腕/手扰动，采集真实后果。显式状态MLP使用仿真oracle瓶位/接触等，与视觉模型不同。短时机器人运动较易预测，瓶子方向、抓持事件与候选区分不足。

部分早期手型/姿态规划能抓起瓶子，包含人工目标、waypoint或仿真oracle评分；不能当作神经动力学预测驱动的自主规划成功。正例集中、无入框标签、slip有效性和hold时域语义等仍限制事件评价。

### 5.7 全93集真实未来＋候选评分反馈闭环

真实未来run完成10k，best7.5k：动作chunk RMSE0.0681rad，hold0.1010；未来视觉RMSE0.4561，仅比persistence约好0.28%。q/dq预测有更明显收益。

该版本确实运行了“观测→LeWAM候选→预测未来token/q/dq→目标评分→执行一帧→新观测”的闭环；但价值标签为成功示范的归一化时间进度，不是抓放成功概率。

6次180步rollout均未入框。接触状态25帧分支的16个候选全部把瓶子推向远离框的方向；pairwise排序一致性约0.458。短时所有物体结果相同的测试中，零regret只是平局，不能证明会排序。

结论：闭环接口曾打通，候选质量、视觉物体后果与价值语义均未通过可靠任务验证。

### 5.8 真实下一帧latent预测

37/9、真实帧相邻转移10,939/2,370；best1900步，残差RMSE0.93475对hold1.02063，但正确动作相对hold的MSE收益仅约0.021%。

这是新建两层Transformer转移预测器，不是完整LeWAM MoT/flow动作生成实验。它学到部分短时视觉变化，但未证明动作后果预测。动作确实改变输出，不能把“误差不改善”写成“动作完全不影响输出”。

### 5.9 多尺度视觉重建与策略辅助

真实数据使用12×12×128适配latent，预测5/10/25帧并解码多尺度RGB。另用25×54小型交叉注意力策略比较动作监督/世界辅助，RMSE0.1396476/0.1397151rad，未见收益；该策略不是原生LeWAM MoT。

两项重要更正：batch内goal轮换2154对中2138对仍为同一episode目标，不能证明goal无效；用策略动作预测的未来对比专家动作产生的未来，混合动作差异和模型误差，不能当反事实准确性。

| 瓶位移RMSE / 零位移基线 | 2.35 / 2.58mm |
| 瓶位移方向余弦 / 候选差异余弦 | −0.361 / 0.038 |
| 审计批次加权RGB/特征latent梯度范数比 | 1.82 |

96像素手部改善，瓶子和框未超过persistence；预测仍模糊且候选间接近。验证无stable-hold与inside-bin正例。方向余弦对近零位移敏感，需要结合真实移动样本解释。action-off是同模型干预，不是独立无动作训练对照。

确切损失权重：

```text
latent token：0.2 + 1.5*hand + 3*bottle + 2*bin，再归一化均值1
RGB尺度12/24/48/96：0.10 / 0.15 / 0.25 / 0.50
每尺度区域：全图0.25、双手0.20、瓶0.35、框0.10、手瓶并集0.10
总目标中的RGB系数：0.25
```

没有独立手臂视觉mask；手臂像素进入全图项，关节进入本体监督。MuJoCo真实未来mask仅用于训练/评测损失，不能在在线评分时读取未知真实未来mask。

## 6. 当前结论的证据边界

1. **可保留：** 本体短时转移、动作监督与手型解码可学习；部分视觉输入确实影响输出；重建梯度已连接到预测latent。
2. **尚未建立：** 视觉变化引导正确动作、动作条件物体后果、候选池抓放覆盖、目标价值可靠排序、学习策略完整任务成功。
3. **不能成立：** 总loss下降等于规划改善、图像清晰等于物理准确、短期RMSE低等于会抓取、网络共享等于动力学与策略已协同。
4. **不能下普遍结论：** JEPA/LeWAM架构无效，或flow一定优于/劣于回归。现有run改变了多个结构、数据和预测定义，一些还是独立小模型。
5. **数据限制：** 真实成功示范可学模仿，但不能直接提供偏离状态/滑落/失败恢复标签；仿真转移当前正例覆盖不足。
6. **仿真限制：** 场景不必逐像素复现真实episode，仍须有效接触、合理初态、关节/坐标一致和可用观测。不能用场景误差解释全部视觉问题，也不能忽略无效初态。

## 7. 下一步技术路线（方案，未在本次文档整理中执行）

保持latent核心，集中比较：标准化未来latent残差回归，与动作条件latent residual flow。不要将动作flow头实验等同于未来latent flow实验。

- 条件：当前/短历史空间token、实测q/dq、实际可执行候选动作块；预测5/10/25帧未来残差。
- 监督：未来latent、多尺度RGB、瓶子运动、手瓶关系、持有/滑落、未来q/dq。RGB与物理监督施加在恢复的干净未来latent上，而非带噪状态/向量场。
- 继续冻结并固定同一解码器，确保两版公平；只用训练集统计量标准化，设置尺度下限。
- 数据覆盖真正接触、抬升、滑落和入框；同状态候选都记录各自真实执行后果，初态与episode隔离。
- 主要比较动作后果方向/幅度、事件与候选排序；RGB仅作辅助。Flow固定一组共享噪声跨候选比较，并汇总多次采样；不能以oracle best-of-N美化结果。
- 只有后果可区分且排序可靠后，才训练任务成功/可达性价值，接回候选选择与每帧反馈。奖励/价值不再使用单纯轨迹时间或当前/终态整图latent距离替代。
- 后续需要新目标布局/未参与设计的盲测集；当前9条dev不承担最终泛化验收。

Flow可以表达多种可能未来，但不会自动解决条件忽略、时间错配、错误标签或样本缺失；它通常仍用平方误差训练向量场。当前证据支持做集中对照，未支持直接替换为生产策略。
