依据来自机器人系FK，而不是未通过验收的投影或像素左右标签：H50中文零样本方向准确率左/右11.18%/19.16%，线性头为56.94%/44.49%，对比头56.05%/47.01%；两臂均满足旧run预写的“零样本≤25%且线性CI高于随机CI”判据。这表明冻结特征有运动信息，缺口主要在当前文本—时序表示的对齐路径；本轮小头已经修复一部分，不能把弱零样本结果解释为编码器完全缺乏运动信息。差分/复制句向量拼接不是SigLIP2原生训练目标，LoRA的必要性与收益仍需对照验证。

图像方面，橙带框代理AUROC0.888 [0.863,0.912]说明物体类别有粗定位信号；颜色互换仍有较高响应。左右夹爪的正确−互换AUROC差CI均跨0，可信且分离的双目标验证子集只有7parent；左右能力明确为**不可判定**，不拿它强行触发LoRA。尖端仅4个验证样本，锁头/尖端/整臂均不足以作精细穿带验收。
