## 1. 是否成立，以及必须推翻的论证

### 1.1 架构成立，成功保证不成立

条件为真实可得的当前/过去观测 C，学习 `pθ(A,W|C)`。A 是动作块，W 是未来图像在固定特征空间中的表示。一个 Transformer 处理不同模态 token，使用不同输入/输出投影和模态时间嵌入，核心 attention、FFN、norm 权重共享，数学和工程上均成立。“全共享”指核心共享，不是要求 54D 动作头和 768D 视觉头共用同一矩阵。

“端到端”应明确为：`L_A`、`L_W` 同时训练共享核心及在线视觉 LoRA；联合模式下动作能读世界隐藏状态，反向也不断开。固定目标编码器是监督坐标系，不是部署策略的第二个专家。它阻止目标和预测一起缩成常数，却**不保证**在线表示保留接触细节、不忽略图像、不发生多任务负迁移。LoRA 端到端适配不等于视觉塔所有权重都可训，不能宣传为全参数微调。

逐项裁决：

|Claude 提议|裁决|
|---|---|
|共享核心、双输出头|保留。全体 token 无条件双向改为“观测只读、生成块双向”。|
|独立 τ 自动覆盖四模式|不准确。连续采样到严格干净/严格缺失端点的概率为零；硬删除也不等于纯噪声。显式配训练模式。|
|干净未来逆动力学占主线|删除首轮此模式。最易形成特权未来捷径，当前又不部署 IDM。|
|冻结未来编码器、缺失未来不复制末帧|保留。冻结的是完整目标变换；真实缺失不能与“任务未完成”混淆。|
|视觉末层/LoRA 必然改善|不成立。选 LoRA 是降低适配风险的工程起点，不是 E66 的解药。|
|部署一定同时生成未来|推翻。只有动作质量或任务收益足以支付时延时才用 joint。|
|删 NULL 语言读取器仍可 P0 零步等价|错误。P0 的 NULL query 仍在读取视觉，见 §3。|
|Piper 无锚点|改为“没有上一已发命令锚点”；关节残差仍有当前实测 q 锚点，夹爪保留 signed absolute。|
|同一代码意味着同一统计/动作语义|错误。共享代码，显式机器人合同、独立统计和 checkpoint；首轮不做跨本体联合训练。|
|失败只补数据/视频，不允许停止主线|推翻。这会使假设不可证伪。可以停止本轮 WAM，继续使用已验证策略；不需退回梯度隔离来挽救名字。|

### 1.2 与 E66 的真实区别和不变风险

E66 不是今天提议的“同一 DiT 上 A/W 双向去噪”的精确复现。其 BC 和 WAM 都使用 DINOv2-B，末四块可训练；WAM 使用 E47 的 JEPA、像素重建、mask、IDM、rollout 等多目标。`implementation_v1/e66_train.py:140` 分派 BC loss / E47 compute_losses；`tools/e47_train.py:245–290,345–346` 展示目标和梯度路径。主要共享的是在线视觉表征及有关模块，而非所有动作/世界层同权的一块多模态 Transformer。

新的实质变化是：固定原始预训练目标代替随在线编码器更新的 EMA 目标；删多个非动作目标；联合随机流代替独立世界回归接口；A 能在部署读生成 W；统一缺失模态训练；空间/时域目标重新定义。这些不是仅改名字。**但共享参数接受非动作损失的风险完全保留，且现在共享范围更大。** 同步生成还会新增错误世界对动作的前向干扰。

E66 N64 两链前8步 BC/WAM 为 .574755/.633358、.583881/.629604，即约 +10.20%/+7.83%。这给出强负面先验，但没有分离到底是目标不相关、视觉漂移、优化预算、容量还是梯度方向导致。E73 dense holdout .530209 对 P0 .469663 约 +12.89%；其世界特征略优于 copy 不足以支持策略价值。E74 D0 的四动作均值 .470357 优于完整候选 oracle .474732，只否定该候选池的选择空间，不否定联合生成。

因此同时撤回两种过度断言：E76 的“只要共享就是 E66 换说法”；Claude 隐含的“换成联合 FM 就与 E66 本质无关”。正确说法是：**新的可检验假设，带着已有负迁移证据出发。**

### 1.3 主观概率，不是论文统计量

事件定义：同输入/容量 BC 对照上，真实记录动作前缀误差改善至少5%，对旧 P0 非劣界 +2%，且第二训练种子方向一致；仅指探索性离线表现，不是闭环成功率。下面是条件于现有数据、无额外机器人预训练、预算内训练的工程先验；误差至少 ±15 个百分点，不能用于功效分析。

### 3.1 图像从源帧到 SigLIP2

```text
原始 top RGB 480×640
  → 裁 rows [96,480)，保留完整640宽：384×640
  → LANCZOS 等比缩小：192×320 RGB uint8（存储）

```

### 3.2 命令历史440、锚点与动作标签

`tools/e71_common.py:14–17,31–43`：取 `action[t−8:t]`，每步54维，缺历史时用 q[t] 占位并标 invalid。历史特征为

`history[i]=(command[t−8+i]−q[t]) / sigma_q_anchor_action[offset0]`，随后乘 valid。

每步再拼1个 valid，**8×55=440**；多出的8维是有效位，既不是时间戳，也不是夹爪或额外动作。展平顺序为逐步 `[54值,valid]`，不是先432值再8标志。训练时10%历史整段 dropout；其余加0.003rad噪声后按同尺度归一化。dropout 不删除锚点。

`previous_anchor=h[-1]`，t>0 即最后真实已发命令 `action[t−1]`，t=0 回退 q[t]；`e72_train.py:25–28` 和 `e72_model.py:79–85` 覆盖基础类的 q_anchor。`e47_data.py:603–606` 的真实标签切片是 `action[t:t+32]`，之后 H2 重新按 previous_anchor 归一化：

`u_j=(action[t+j]−anchor−mu_a[j])/sigma_a[j]，j=0…31`。

`tools/e47_model.py:416–424` 反归一化输出。函数名、旧 cfg 的 measured-q 注释并非当前语义。没有平移标签，也不应新增平移。

### 3.3 geo66 是什么

每手33维，左右两手展平为66：

|分量|每手维数|含义|
|---|---:|---|
|palm_uv|2|掌心投影到320×192低分辨率坐标，再分别除320/192|
|roi_xyxy|4|经裁边的手部 ROI 框，除[320,192,320,192]|
|rot6d|6|经相机外参修正的旋转前两列表示|
|hand_q|20|该手关节，按训练 q mean/std 标准化|
|valid|1|关节输入合法、投影有效及历史有效的合并标志|

实现 `tools/e47_data.py:504–534`，无效手整组清零，非有限值清理。投影 `tools/e46_project.py:32–70`；历史接口 `:73–82` 根据既定标定 lag 取历史 q。P0 数据提供 `[q[t−1],q[t]]`（`e47_data.py:587–600,633–638`），配置 lag=1，因而 obs FK 使用 q[t−1]；首帧 invalid。这不是未来手位置，也不是物体/箱口几何，更不是接触力学。保留既有 lag 合同，不平移动作/监督标签。

额外纠正：P0 主策略的 q/dq state MLP 实际接收**原始 rad 和 rad/frame**，不是先按 mu_q/mu_dq 标准化；见 `e72_train.py:28`、`e47_train.py:117–140`、`e47_model.py:366–375`。训练统计用于动作、历史尺度、geo66 内手关节；`e72_model.py:99–102` 的 q 标准化属于辅助 subtask predictor。新架构可以显式标准化 q/dq，但这是变更，R0 不得悄悄改。

### 3.5 P0 不只是三层 flow

flow 确实是3层、width256、8头、FFN1024：`e47_model.py:304–327`。每层先 causal action self-attention，再独立 cross-attention，最后 conditional FFN；不是一个拼接序列的普通 self-attention block。P0 还有197视觉 token、3状态 token、历史 adapter、两个 NULL/hand query 的2层视觉 reader、fuse 和条件调制，最终 memory201 token（最后一个用于 FFN 调制）。

`e72_model.py:110–120` 虽强制 s=0，却保留 `null+hand` → readers(ctx.z) → fuse。**能删文本塔和 subtask predictor 的无效推理计算，不能删除视觉 reader/fuse/conditional modulation 并声称输出不变。** P0 训练还算 detach 视觉的0.1 subtask CE（`e72_train.py:30–56`），因此“纯BC”是有效动作路径/梯度意义的简称，历史实现并非只有一行 LA。

训练 LA 为54维等权MSE，时域4/2/1；不是 A7/B7/L20/R20四组等权损失。后者是评估 primary。τ 为 `sigmoid(N(0,1))`，τ=0噪声、1数据；`e72_train.py:37–41,158–165`。10步 Euler、四固定噪声47041…47044取动作均值；噪声还依赖原 row_index（`e66_eval.py:115–121`），R0不能重编号改变它。

## 4. 最终统一架构：一套核心，两种推理模式

### 4.1 固定规格和梯度合同

名称只保留 **E79 unified latent flow**。运行配置有 `robot=tianji|piper`、`objective=bc|joint`、`inference=joint|action_only`，不再以字母拼接命名不同架构。

- 核心：6层、width256、8头、FFN1024、Pre-LN、逐token norm；同层 O/A/W 共用 QKV、输出投影、FFN 和 norm，层与层不绑权。粗估核心4.7M，加输入/输出/条件约6M上下，实施时统计精确参数。
- 在线视觉：默认已有 DINOv2-B/14；末2个block Q/V rank8 LoRA，基础权重冻结，LoRA接收 LA/LW。目标塔是未适配的固定原始 DINO 副本。首轮不全量微调、不同视图共用视觉权重。
- 分模态输入投影和输出头必要且保留：A 54D或14D，W原生768D；动作流直接在归一化物理动作坐标中积分。没有动作 autoencoder、IDM 或强制正交变换。
- 当前观测 O 不加噪；token 含相机ID、空间坐标、原图 crop坐标、真实观测时间/年龄、有效位。A/W 有模态ID、各自流时钟和真实未来时距。流时钟不是物理时间。
- 一个 optimizer；两项loss梯度相加到同一核心/视觉LoRA；不 detach A/W hidden，不冻结“动作专家”，不做梯度投影式保护。目标缓存/统计及真实标签 stop-grad。
- 不生成未来 q/FK 作为主世界目标，避免用容易的伺服拟合遮蔽物体任务。无像素decoder、mask头、评分器、语言读取器、规划、部署教师。

6×256是有限容量起点，不能由64集推导唯一最优深宽。Piper先用同规模；若训练误差与BC均明显欠拟合且真实指标有改善，下一独立实验才允许6×384。现在直接12×768或1B级核心没有依据。LoRA主要控制优化自由度，**不消除视觉塔的前向成本，也不保证省去全部反向激活成本**。

### 4.2 注意力矩阵

行是 query，列是可读 key/value；1允许，0屏蔽。所有层保持相同规则，防止跨层偷渡。

```text
joint 模式       key O   key A   key W
query O            1       0       0
query A            1       1       1
query W            1       1       1

action_only       key O   key A       （W物理不实例化）
query O            1       0
query A            1       1
```

O内部可双向，因为所有观测均已在决策时刻可得；不同相机需提供采集时间偏移。A内部全块双向，W内部跨时距双向，A/W双向。未来动作在决策时刻是计划变量，允许彼此注意，不构成真实未来观测泄漏；也因此**不能再称 P0 的逐动作 causal flow**。

O不读A/W，既避免干净未来通过O污染 action_only，也使每层O的K/V可缓存。O的调制只能用固定观测条件，不使用 τA/τW、未来presence、全序列归一化或依赖生成分支的随机dropout。A/W各自注入本模态τ，对方时钟通过其token类型/嵌入可辨。部署eval模式缓存；训练期缓存不得切断梯度。

区分三种mask：任务模式选择的W缺失要从attention键、query更新和loss一起删除；当前已知的相机/ROI结构性无效也按相同规则屏蔽；**只是未来录像不够长则是目标不可用，不等于部署已知该时刻不存在**。后者不得把“还剩多少帧/真实终止标志”加入O或通过token数量泄漏。首轮沿用满长度P0窗口避免此问题。以后纳入短尾时，需要独立锁定缺目标的训练办法：例如固定长度、未标注W槽仅用纯噪声且LW=0，并训练同样随机缺目标模式；不能给不存在的真实W构造加噪标签，也不能复制末帧。未经这一验证不扩短尾。

注意：全A/W互读意味着短时 W8 可间接访问后缀动作或 W32。即使单条边限制 `W8←A[:8]`，多层仍可绕路。本版本诚实地称“完整轨迹条件的联合预测”，不宣称严格可干预的前缀因果动力学。若未来要 `do(A[:8])`，需另外验证前缀截断/分块图及数据干预覆盖，不能靠当前attention图保证。

### 4.3 图像、相机和 token 预算

**天机默认从192×320现有存储帧出发，不再拉成方形。** DINO-B/14 在下边补4像素、右边补2像素到196×322，得到14×23=322原生patch；padding采用边界复制并记录像素有效区域。空间池化/ROI采样按有效区域覆盖加权，补边不当物体区域。192×320原图没有被裁切/缩小，不凭上采样声称新增细节。原始patch经过encoder后再作有界压缩，避免把全部patch送入每次去噪。

[DINOv2官方位置插值实现](https://raw.githubusercontent.com/facebookresearch/dinov2/main/dinov2/models/vision_transformer.py)支持矩形patch网格。这说明实现可行，不是本任务性能保证。336×560上采样会变成960patch，增加成本且不增加原始像素信息，取消其默认地位。

天机每时刻：全图6×10池化60＋全图有效patch均值1＋左手/右手/物体工作区/箱口四个ROI各2×2=16，共77 token。两时刻t−4,t共154；q、dq+valid、geo66、history440分别映射1个token，共O=158。A=32。未来+8/+16/+32，每端点77，共W=231。**joint总421 token，action_only190 token。** 原生视觉编码器仍处理322patch；这些数不能混为视觉塔开销。

手框只由当前已知因果FK得到；物体工作区和箱口先人工在训练数据确定固定框。这里的“物体ROI”是搜索区域，**没有假装已经拥有可靠物体跟踪器**。同一次预测的当前/未来都用同一组框，不用未来q、未来检测结果、完整片段标签选框；显式携带框坐标，框失效则missing。全图保留，避免手离开框后全部丢失。固定区域若过大，2×2压缩会损失细线；R1真实可见性检查不过就先修输入，而非承诺这组token足够。

Piper每相机独立编码，再拼接带ID的token，不先横拼图、不平均腕视。顶视保留448×252（DINO18×32patch）；腕图采用已有保比例224×224（16×16patch）。每时刻顶视4×6+global=25；每腕全图4×4+global+固定细节ROI4×4=33；总91。两时刻t−6,t共182＋四状态/历史token=186，A=50，W=3×91=273，**joint509，action_only236**。腕ROI先从原始高分辨率图裁取再编码为224，因而每时刻是3全图+2ROI共5个视觉crop；若只在低分辨率特征图池化，不能声称保留了原生ROI细节。这个额外视觉成本计入预算。

Piper源帧格式/黑边处理采用E77已审计版本；每路实际时间戳、缺相机和重复帧有独立valid/age。首轮不加主动注视，未来要加则保持固定全局三视图并把gaze来源/crop/时间作为条件，不能把槽位编号当固定相机。天机始终仅顶视。

### 4.4 固定目标的选择与构造

**首选已有DINOv2-B，SigLIP2是一次受控备选，V-JEPA2是后续候选；不把V-JEPA2.1论文成绩冒充现有V-JEPA2-g的成绩。** 默认同一编码器家族的原始固定副本定义目标，在线副本加LoRA；最后只部署在线副本。

|候选|优点|限制与选择|
|---|---|---|
|DINOv2-B|已有权重，密集空间表征、矩形输入清楚、成本适中|无预训练动作动力学；未必区分接触/细线。默认试验起点，不是已证最优。|
|SigLIP2-B|P0有效视觉先验，亦有定位/密集任务能力|现有224模型是固定分辨率型，不是NaFlex；矩形位置插值是新适配，不自动继承可变形状训练。[论文§2.4](https://arxiv.org/html/2502.14786v1)。|
|V-JEPA2-g|视频表示先验，可作离线表示上界|约1B，时域合同/细节/成本待核；目标塔可以离线重，在线塔不能凭名称获得低延迟。首轮不加载AC预测器。|
|V-JEPA2.1-B/L|La-JEPA附近的表示候选，小模型蒸馏有价值|E78记录本地未确认独立权重；本轮不下载。以后具备资产和明确预算才加入，不能阻塞此次统一架构。|

SigLIP备选用原生192×320矩形patch16（12×20）和明确的位置嵌入插值；实现不支持就退出此备选，不静默方形resize。原P0224路径仅用于R0。R1比较的是“编码器＋相同空间/时序接口”的整体配方，不声称单独归因到预训练算法。

目标定义为

`W*_k = Norm_train(Pool(E*(I[t+k]), boxes_t))`。

E*、归一化与pool几何全部固定，**固定投影先取identity，不先压768→128**；输入到core的768→256是可训投影，输出仍回768维。这样不让未验证PCA丢掉低方差接触线索。不同camera/ROI统计只用训练parent，尺度下限固定为同组正标准差中位数的0.1倍并设数值epsilon，避免近常数维被极端放大。该尺度只用于训练，不作测试选型标准。

首轮绝对目标，不额外叠差分头、方差正则或像素loss。差分表示是可逆重参数化而非天然更“物理”，相机运动/压缩噪声也会被放大；当前用ROI分组平衡先控制背景。未来某端点无真实帧就无该目标，不复制末帧。首轮满窗口完全避开此问题；扩展短尾时按§4.2区分监督mask和运行条件。

若以后使用视频编码器，当前clip必须结束于t，目标clip结束于t+k，并锁定覆盖范围；禁止把整条含未来clip编码后截当前token。静态重复帧也应如实称静态编码，不声称获得真实运动历史。目标可离线缓存，LoRA/增强后的当前特征不能当固定缓存长期复用。

## 5. 训练配方：不为四种模式而增加四套系统

### 5.1 两个时钟、明确的模式比例

统一 P0 方向：`X_m(τ)=(1−τ)ε_m+τY_m`，目标速度 `Y_m−ε_m`；τ=0纯噪声、1干净。A/W噪声独立，不把两个流用同一随机向量。所有W端点共用τW，物理时距分别编码。基础时钟分布 `D=sigmoid(N(0,1))`，沿用P0而非无理由改Uniform；不宣称此分布最优。

首轮建议固定如下比例，在样本级采样；这是工程选择，不是UWM/La-JEPA原配方：

|模式|比例|时钟/输入|监督|
|---|---:|---|---|
|联合、同步时钟|30%|τA=τW~D，A/W各自加噪|LA+LW，覆盖部署对角线|
|联合、独立时钟|30%|τA、τW独立~D|LA+LW，学习不同信噪比条件|
|纯策略、未来缺失|30%|τA~D；W token完全删除/等效硬屏蔽|LA；必须与 action_only 部署图相同|
|动作干净、事实轨迹预测|10%|τA=1，A为记录动作；τW~D|该调用只算LW；**同一机器人样本额外一次纯策略调用算LA**|
|未来干净、逆动力学|**0%**|接口理论可表达τW=1；首轮不训练/不验收该能力|不纳入主线|

因此每个有动作样本每次暴露恰有一次主要动作FM监督，其中60%joint、40%action_only；没有因为前向模式而少训10%动作。世界监督覆盖70%样本；分母按实际有效样本归一，λ不隐含乘0.7。额外10%的纯策略调用成本单列，BC对照保持相同动作样本/τ/噪声，而不是强行多一次LA。

为什么不保留干净未来：它在本任务既无部署用途又容易让动作依赖特权未来，增加一个很难归因的辅助目标。若将来明确需要inverse查询，再单独研究；“可表达四种模式”不等于首轮必须分25%训练每种。独立连续采样不能代替端点训练；纯噪声W也不能代替删除W。本文明确选择训练硬缺失模式，取消“边缘策略=把未来全遮住但仍保留未知含义token”的模糊实现。

无动作视频不在首轮。以后加入时A缺失、LA=0，不伪造零动作或将噪声当真实动作标签；LW仍更新同一共享核心和视觉LoRA。**全共享网络不存在可以单独预训且不影响动作参数的‘世界部分’。** 预训共享核心后，BC和WAM对照必须继承相同预训，再检验额外联合监督。

### 5.2 损失、λ与优化

天机动作保持P0目标和训练统计，`LA=mean_batch [Σ_j w_j mean_dim((vA−(u−εA))²)/Σ_j w_j]`，`w=[4×8,2×8,1×16]`。保持每动作维平均，不因手/臂维数不同暗改成四组等权。新core的q/dq输入显式按fit64统计标准化；这是新BC和WAM共有变更，旧P0 oracle保留原样。

世界LW先对通道均值，再对有效token均值；天机全图61token组权重0.5，四ROI各0.125，缺ROI时按有效组重归一；时距权重[0.5,0.3,0.2]。Piper先每相机等权，再每腕的全图/ROI各半，避免顶图面积或腕自运动独占。所有valid分母明确，空监督返回无损失而非NaN。目标是固定特征FM，不加教师评分、物理成功伪标签。

`L=LA+λ LW`。**不按token数简单求和、不因768>54就把世界loss除以14、不把某论文λ=1抄成合理平衡。** MSE值相近也不表示共享参数梯度相近。

建议：从共用BC warm-start分叉后，取训练集固定16个microbatch，无optimizer更新地测共享核心上 `gA=||∇LA||`、`gW=||∇LW||` 的中位数；用 `λ*=clip(0.2 gA/(gW+ε),0.01,0.3)` 一次定值，前500更新线性升到λ*。若梯度退化/非有限，先判实现失败，不能靠clip掩盖。没有这项标定时预注册λ=0.1。数值0.2、上下限都是风险预算，**不能保证非劣**。不得查看holdout后再改λ。

每200更新在固定训练小批记录LA/LW及共享层梯度余弦/范数、LoRA梯度。一次反传相加、全体可训参数共同clip=1；诊断分开求梯度不是训练时隔离。冲突余弦只提示问题，不能仅靠余弦宣布负迁移机制成立。首轮不加PCGrad、GradNorm、trust蒸馏、第三项特征锚定loss。长期世界主导、动作开发指标恶化则停止；不在同一实验无限动态追λ。

AdamW：共用BC warm-start核心lr=3e−4；分叉BC继续/WAM核心同为1e−4，新W I/O同1e−4，视觉末2block LoRA=3e−6；weight decay核心1e−4、LoRA0；warmup5%后cosine，共同clip1。有效batch16、bf16仅为未来运行配置，梯度审计用FP32。首轮仅轻微颜色/亮度增强，禁止左右翻转、会裁掉箱口/锁孔的随机crop；未来目标不增强。几何增强要同步变换ROI/FK，否则不用。

这些参数是可执行起点；最重要的是BC/WAM共享数据顺序、动作噪声流、动作时钟边缘分布、更新数、增强和模型选择规则。额外W计算使用独立RNG，不推进动作RNG。

### 5.3 P0如何初始化：不能同时兑现三个互斥承诺

“把原3层causal flow无损塞进一个标准拼接self-attention网络、改双向、删reader，还零步等价”做不到一般性的权重映射。原层有两次不同attention及归一化，拼接softmax改变分母；双向mask改变依赖；删NULL视觉读取器改变条件。width都256只是shape兼容，不是函数兼容。

最终选择：

1. **R0仅建立P0兼容oracle与数据回归，不把它作为最终架构。** 保留全部有效原运算和噪声row_index，目标是新数据接口喂旧模型仍复现旧结果；不训练。
2. 新6层共享core随机初始化，视觉从原始预训练权重开始，先训同架构BC。天机预算起点2700更新，若仍欠拟合且预算允许可到5400，但必须在分叉前固定计划；不把未达P0的短训BC作为容易击败的靶子。
3. 从**同一个新BC checkpoint**复制共享core/在线LoRA/动作投影到BC继续训练与WAM；W头新建。两条线共用warm-start，动作监督暴露相同。W关闭时初始化前向可以严格相同；W打开改变attention后，不要求与BC或P0零差，也不伪称无损。
4. 首轮不做P0速度场KD，也不拷贝半套旧attention“碰运气”。以后若需要节省BC预热，可把KD作为独立问题，不混入此次世界价值验证。

R0的FP32逐元素速度/动作等价是兼容层验收；对原bf16评估数值另设合理精度容差。原E74已复现dev primary=.470357131，263窗口逐窗最大差0；本轮只核对报告，不声称再次运行成功。新网络不需要在第0步达到这数值。

同一份代码通过adapter输出相同hidden宽度；I/O head、统计、时间合同独立。Piper条件世界模型学的是记录轨迹相关性，不能把反馈标签解释为干预命令的因果动力学。demo4压缩静止拼缝禁止跨越世界窗口，BC/WAM使用相同连续window manifest。状态插值的可用时刻问题必须在部署合同核实；不以挪动作标签解决。首轮不移植天机训练权重到Piper，迁移的是架构与协议。

## 6. 部署生成未来有没有用，能否只是开关

### 6.1 作用来自计算图，不来自是否显示输出

joint中 `vA=f(C,Aτ,Wτ)`，W的中间隐藏状态和数值影响后续动作；外部不读取最终W，不代表内部没有读取。W可能作为意图/轨迹的隐变量，帮助有限数据下消歧；也可能成为噪声放大器。它没有带来新传感信息：C和随机数已决定所有生成量，收益只能来自训练先验、优化与归纳偏置。

另一方面，最终Euler更新得到的W(1)通常不会再被已结束的动作积分读取；不能把最终W输出可视化当作它对动作有贡献的证据。相同A噪声下更换W噪声只测依赖，不测有效性；joint与经过训练的action_only真实动作/任务对比才能判价值。

### 6.2 两种部署路径

|项目|joint|action_only|
|---|---|---|
|生成|独立εA/εW，τA=τW=s/10，同时算vA/vW，再同时更新|删W及其head，τA=s/10只算vA|
|条件|相同真实O，每层O K/V缓存|相同O，不读任何真实未来|
|收益可能|生成内部变量帮助动作|保留共同训练塑造的参数/表征，减少推理成本|
|风险|错误未来、额外噪声、时延，均值动作未必对应任何单个W|有限模型的缺失模式可能弱；不能声称数学上精确边缘化joint|
|本案选择|保留为主研究能力，必须赢得部署资格|默认部署候选；同等真实质量时选它|

**同一checkpoint可以提供开关，因为本文训练了硬缺失W模式并保证O不受W污染。** 但两种输出不会逐元素等价，统计上也无保证。UWM式“W固定纯噪声但留token”、硬删除W、先生成W再出动作是三种不同推理，不能混称一个操作；首轮只实现表中两种。

若训练时采用La-JEPA/Fast-WAM型永远 `A←W=0`、`O←W=0` 掩码，且O时间条件固定，删W可以在计算图上保持动作不变。本文joint允许跨模态读取，所以不能无训练直接获得那种等价性。要彻底比较“永久屏蔽未来”与“耦合联合”需要一个额外训练对照，见§7；不是临时关attention就完成因果归因。

沿用四个固定动作噪声、10步Euler、动作均值作为天机离线主口径；W噪声用另一个固定流，采样时每条A/W成对去噪，不先平均W后生成A。均值不是候选打分，也不是联合分布的一条样本；其W均值**不代表均值动作执行后果**。E74表明均值对当前RMSE有利，但绕障/夹持多模态动作均值可能不具可执行性。未来实机同时检验单样本与四均值，P0和BC同口径；不按测试结果悄悄更换采样协议。

15Hz/30Hz是动作下发频率，不是完整策略调用频率。建议初期天机执行8步，截止约533ms；Piper执行10步，约333ms，穿入阶段未来可考虑5步≈167ms。全pipeline记录P50/P95/P99、观测年龄、deadline miss和共享负载；提前执行队列不能假装无延迟。均值/批量四采样、视觉5crop、10步去噪都计入。当前没有E79实测，不能承诺单H20逐帧66.7/33.3ms。

## 7. 最少实验、验收和评估污染

### 7.1 两个基线够不够：够筛整体，原λ=0定义不够干净

最少保留三个对象：旧P0；**新架构BC**；新架构联合WAM。只需新训练BC/WAM一对，warm-start共用。新BC与WAM相同encoder/LoRA、tokenizer、视觉历史、core、动作头、真实动作样本和优化日程，BC训练与推理均无W。

Claude字面“同一网络λ=0”有陷阱：若A仍读加噪真实未来，BC训练也获得特权未来；W输出头没有世界监督却在部署联合积分，可能根本没学会世界速度场，成为人为削弱的基线。只改λ，不改模式不够。**本报告的BC配置是λ=0且W缺失/不计算；保留同核心动作路径，不声称总训练参数/算力完全一致。** 若保留W I/O占位参数，它们是inactive，须如实计数。

最少追加无需重训的检查：

1. WAM同checkpoint的joint / action_only，都用同A噪声、同Euler；评估哪条真正可部署。
2. hold-last-command / hold-q零训练参考，移动/静止、早/晚期分别报告，避免靠静止片段占比获胜。
3. 因果输入审计：改未来帧不能改变O；W缺失时改任何W缓存不能改变A；两项loss均能到共享层和LoRA；目标塔无梯度；缺失/跨episode/拼缝不漏读。

如果三对象结果足够好，只能宣布“联合训练整体配方优于匹配BC”。若要进一步声称“收益来自正确未来信息，而非额外训练/正则化”或“在线A↔W必要”，**只在首轮成功后追加一个训练对照**：同一共享core/LA/LW/模式数量，永久禁止A读W且O不读W（训练时预测未来，部署删W）。这不是梯度隔离：LW照样更新共享核心和LoRA。它回答耦合生成是否必要，不回答未来语义是否唯一原因；若仍要识别时序信息，才追加当前重建/打乱未来对照，明确这已是下一研究问题。

该永久屏蔽版本与新BC的动作前向路径相同，二者再比较才更接近“只增加世界训练监督”的受控问题；WAM joint与它比较则检验跨模态耦合的净影响。不把三项问题压成一个含糊的λ开关。

不需要首轮重跑E66、IDM、像素、隔离、多编码器×多λ矩阵。若整体失败，最少对照已经足够停止，不欠一套大消融来证明“所有WAM都失败”。

世界loss仅用于训练/数值诊断。真实未来经E*编码仍是模型产生的特征，**不作测试真值、阈值或选型依据**。不沿用E76对latent-copy提升10%/5%的通关线。要研究物理后果，需人工点位/框/可见接触事件或实测对象信息；简单读出器只在train人工标签拟合，测试真值为独立人工。没有这类证据则只称“带未来表征监督的动作策略”，不能宣布学到了可靠物体因果动力学。记录动作条件预测正确也不保证未执行动作反事实正确。

- 旧全93/全173微调教师即使只向训练集导出特征，也不洗掉其见过测试的事实。首轮使用通用视觉先验，不引入这些教师。

## 8. R0–R3里程碑、工程量与止损

### 8.1 应先做什么

**先做R0数据合同＋小范围可见性/表示筛选，同时规划新隔离数据；不先造大世界模型，也不先做大蒸馏。** 不必等补齐几百集才允许小型可行性实验；但若原图无法辨别抓住/滑脱或扎带入口，模型架构试验应该暂停。天机仅顶视，不能用腕相机补违反约束；Piper可在后续改善腕视和主动注视。

R1限两种已有encoder配方（默认DINO、备选SigLIP），同一新BC、同token预算/LoRA/动作数据；有限训练人工样本检查可见性，开发用真实动作选型。目标特征variance/reconstruction不作模型胜负标准。V-JEPA2-g/2.1不默认组成第三套大网格；有明确失败理由才另立预算。

数据优先补的是独立接触变化、失败前后与恢复、相近状态不同真实动作的后果，不是更多同一摆放成功视频。Piper先人工复核E77已识别的存量rollout/接管parent再补采；失败轨迹可以做世界训练，不能不加区分全当正确动作BC。新增数据需同时有发送日志/时钟/反馈/视频/人工结果；不改旧标签定义。

### 8.3 H20预算是上限，不是未经测量的速度承诺

GPUh按卡数×占用墙钟累计，包含加载、缓存、评估、失败、重试；排队未占卡另报。共享GPU吞吐减少已经体现在墙钟内，不再乘一个“共享折扣”重复计费。未来每阶段100更新profile，估算 `(编码秒数+更新数×秒/更新+评估秒数)×1.25/3600`。本轮不查卡、不占卡。

未来每条线默认单卡串行，BC/WAM不同时争用同卡；以同样microbatch/累积设置比较，并把负载时段记入profile。Piper十个观察crop（两时刻×五crop）可能由视觉激活主导，先降microbatch、保持有效batch，不把CPU缓存速度当在线LoRA速度。资源不满足时排队，只保存/停止自己的新run，不清理、抢占或终止他人作业。

|---|---:|---:|
|R0/接口复现或Piper适配profile|0.5|1|
|R1/目标缓存＋有限表示/BC预热|6|10|
|R2/R3第一seed BC继续＋WAM|10（各≤5）|20（各≤10）|

首次决定是否值得继续不必用完第二seed桶：天机首轮约12–20h占卡上限量级，Piper约25–40h量级；若profile快可更少。原P0记录训练1906秒≈0.53GPUh、末段.267s/update，但其视觉塔冻结、单帧和短动作网络，不能把这个速度线性套给在线LoRA、多视图及世界token。

天机分叉先固定5400更新×batch16；R1选中BC预热成本不得再重复记为新任务。Piper可从共用BC预热≤10k更新、分叉各≤10k、有效batch32起步；profile预计超预算时，在正式比较前统一缩短两臂并记“预算截断可能欠拟合”，不能只让快BC多看数据或只给WAM追加时长。**预算内不收敛是未决/工程不合算，不是世界模型理论失败。**

缓存方面：天机按2159 anchor×3端点×77token×768×2字节，单future目标约0.77GB（不含索引、框、双观测和其他集合）；按anchor固定框缓存可行。Piper即便359,178帧粗按stride8取约45k anchor，三端点91×768 FP16也约19GB上界量级，真实连续窗口/划分后再算；不缓存全部大塔全patch到内存。目标可缓存，在线LoRA仍需观察图像前向/后向。统计/缓存隔离且只写自己新目录。

工程量（熟悉现有代码、单工程师、共享卡排队另计）：R0约1–2人日，R1约1–2人日，R2共享core/mask/两模式/损失/验收约3–5人日，Piper额外2–4人日；合计约7–13人日，人工数据复核/新采集另计。不能把“一个Transformer”理解为几小时可靠重写：主要工作是数据合同和公平验证，不是网络层数。

### 8.4 明确停止条件

1. R0索引、历史有效位、归一化、来源或因果输入不对：停止模型工作，先修自己的adapter，旧文件不动。
2. 人工看不清任务决定性事件：先解决采集/视角/照明或补可见数据；不靠潜变量loss制造证据。
3. 新BC在预算内明显劣于P0：不继续用WAM补偿失败的重构。允许保留P0部署，下一轮单独解决BC。
4. λ升满且经过至少1000联合更新后，连续两个固定开发检查WAM前缀较匹配BC恶化>5%，或raw动作/抖动出现明显异常：停止该分支。较小差异按预注册终点判，避免频繁窥视后早停偏差。
5. joint不优于action_only或超deadline：选已训练且达标的action_only；这仍是端到端世界监督训练，不能宣称在线世界推理必要。
6. WAM两种推理均不胜BC：停止本轮世界主线，明确负结果。保留正确的代码/数据合同，继续用已验证策略；不默认恢复隔离，也不因用户偏好强留无效W。
7. 第二seed/新独立测试不复现：收缩结论为探索性，停止扩大预算。不得回旧holdout重新挑λ或encoder。
8. 外部无动作视频仅在本域可见性成立、BC可工作、世界目标有真实后果信号但覆盖不足时另立先导（例如5–10h相关真实视频、额外8–16GPUh上限）。先验不匹配、缺发送命令、孔口不可见都不是加视频必能解决的问题。未执行反事实不能用教师想象补作测试真值。

## 一页摘要

**结论。** 统一架构成立，采用一个6层×256共享Transformer，动作/未来特征两头、两流时钟、在线视觉末层LoRA，LA/LW全程联合反传；固定未来目标不构成动作/世界梯度隔离。E66并非这个结构的精确复现，但共享多任务负迁移风险仍在，不能靠改名摆脱。天机取得≥5%匹配BC前缀增益且跨seed保方向的主观先验约30%，不是成功保证。

**与旧方案的取舍。** 取消E76隔离、E77 B/I/J/S矩阵、E78 F命名；保留旧结果供审计。不采用巨型视频骨干、IDM、像素/mask头、候选评分、规划或部署教师。无需为“动作潜空间”额外做PCA。UWM支持统一时钟接口；DreamZero/Cosmos依赖很大先验；La-JEPA/Fast-WAM支持训练预测未来、部署不生成，但不能证明所有核心参数共享最优。

**P0事实。** 存储帧是源640×480裁顶部96行后LANCZOS缩到192×320，再被P0双线性拉伸到224×224。440=8×(54历史命令残差+1有效位)。geo66=两手各(掌心2+ROI4+旋转6+手关节20+valid1)。训练stride8、2159窗口、5400更新、86400暴露；动作训练统计来自fit64的E71 previous.json，评估用E66固定共同尺度。主动作q/dq输入实际原始单位。NULL reader仍读取视觉，不能删掉后声称P0等价。

**最终规格。** 天机仅顶视两帧，DINO默认196×322小补边矩形输入，每帧77token；O158/A32/W231，总421。Piper独立三相机和腕细节，每时刻91token，O186/A50/W273，总509。固定E*原生768维目标，不先压128；未来缺失不复制。观测只读观测，生成块双向，动作和世界共同塑造同一核心与LoRA。保留物理时间/相机/ROI/valid，Piper反馈标签不冒充已发命令。

**训练与部署。** 30%同步联合+30%独立联合+30%未来硬缺失+10%干净动作世界预测（另补同样本纯策略LA）；干净未来逆动力学首轮0%。λ按训练梯度一次标定、500更新升入，不用holdout调。10步Euler、四固定动作噪声均值保持旧离线口径。joint内部会读W，因此最终W被丢弃不代表无作用；action_only只有训练过缺失模式才能可靠提供。默认选择真实质量相当且更快的action_only，联合生成必须证明部署增益。

**实验与初始化。** R0复现旧P0数据/运算，绝不要求新标准Transformer零步等价。R1最多两种已有表示，先建可工作的同架构BC；R2共用BC warm-start后仅做BC继续/WAM一对。字面λ=0仍读加噪真实未来会产生不干净对照，必须定义BC无W。成功后才第二seed和一个永久屏蔽A读W的训练对照。R3迁移代码/合同到Piper，不混用权重、统计或动作语义。

**验收与止损。** 前缀相对匹配BC目标−5%、对P0前缀/全块非劣界+2%，统计区间和分组护栏同时报告；最终以新session真实任务和P99时延确认。旧dev/holdout/冻结9均是探索回归，模型特征/标注不作测试真值、阈值或选型。新BC不达P0先停重构；WAM持续退化或无收益就停止本轮，不自动加模型/无动作视频，不强留隔离或世界模块。优先补可见接触、失败恢复、发送日志与新独立评估。
