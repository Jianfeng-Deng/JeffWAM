# E128 盲策略优势瀑布拆解（A）与纯视觉残差可学性检验（B）

完成时间：2026-11-19 BRT。代码：`code_e128/e128_ablation_a.py`、`code_e128/e128_pure_vis_b.py`；结果：`results/e128_ablation_20261119_01/`。评估集：锁定 211 窗 / 27 parent（parent bootstrap 2000，seed 90）。资源：GPU1 耗时约 12.9 分钟（`0.215 GPUh`）。

---

## 1. 实验目的

针对 `E126-D`（盲策略优于默认 WAM）与 `E127-R`（冻结主干的残差头 `R_L1` 未超过盲策略），做两项决定性分离检验：
- **E128-A（瀑布拆解）**：固定同一 3×1024 盲策略 MLP 结构，逐步切换训练日程/抽样量、损失函数（`[4,2,1]` 加权 MSE vs 等权 L1）、历史偏移（WAM 的 `(6,12,18,24)` vs `(3,6,12,24)` vs `(1,3,6,12,24)`）与多模型集成（单种子 vs 3 种子平均），定位盲策略赢过 WAM 的真实来源。
- **E128-B（切断本体的纯视觉残差检验）**：修正 `E127-R` 冻结视觉层、保留本体层及底座错位的问题——彻底屏蔽残差分支的关节/本体输入（置零并冻结 `state_proj/proprio_proj`），放开视觉投影与 6 层 Transformer（`WAM_PV`）及训练五折袋外空间视觉残差网（`SpatialPV`，含训练侧袋外拟合逐时刻收缩系数 `α_t`），在同一 `blind_fold5` 底座上检验“纯视觉能否独立预测盲策略残差 `y − B_oof(q)`”。

---

配对因子贡献（95% bootstrap CI）：
- **同历史 `(6,12,18,24)` 单种子下，盲策略（`0.00855 / 0.04283`）其实输给带视觉的 WAM（`C_L1` `0.00754 / 0.04192`、`J_clean` `0.04170`）**！所谓“不看图的小网络比大模型更准”是特征与集成不对等造成的假象。
- **加入 `t−3`（前 100 ms 近期速度，`3→4`）**：`Δl8 = −0.00196 [−0.00268, −0.00134]`，`Δl50 = −0.00325 [−0.00503, −0.00160]`（单此一项贡献了过半提升！）。
- **再加入 `t−1`（前 33 ms 瞬时速度，`4→5`）**：`Δl8 = −0.00098 [−0.00134, −0.00065]`，3 种子下 `l8` 进一步降至 **`0.00512`（`6.37 mm`）**。
- **3 种子集成效应（`4→7`）**：`Δl8 = −0.00047 [−0.00068, −0.00029]`，`Δl50 = −0.00235 [−0.00355, −0.00131]`。
- **等权 L1 相对加权 MSE（`2→3`）**：`Δl8 = −0.00183`，`Δl50 = −0.00754`（大训练量下 MSE 明显过拟合异常值，L1 更稳）。

## 3. E128-B 结果：纯视觉残差可学性与跨场景泛化（同底座 `blind_fold5`）

### 3.1 训练拟合 vs 留出 Parent 泛化（彻底否定“视觉得不到梯度”，证实“脱离本体的加性视觉残差跨场景不泛化”）
- **训练侧梯度正常、残差显著下降**：
  - `WAM_PV`（解冻 6 层视觉主干、屏蔽本体）：训练残差 L1 从前 100 步 `0.3173` 降至末 200 步 **`0.2658`（−16.2%）**；
  - `SpatialPV`（五折纯视觉空间网格网络）：五折训练残差 L1 均由 `0.0316` 降至 **`0.0263`（−16.8%）**。
  - **结论：“视觉部分得不到梯度”不成立**，梯度完全畅通。
- **留出训练 Parent（五折袋外 OOF）上信号为零**：
  - 五折留出 parent 的残差 L1 反而全部微升（均值 `0.0318 → 0.0334`），袋外预测与真实残差在 `t=1..50` 的相关系数为 **`−0.009 ~ −0.004`（≈ 0）**，袋外最优收缩系数在全部 50 步均为 **`α_t = 0.0`**！

## 4. 核心机理总结（为什么 `blend25_E106C` 显著赢盲策略，而独立残差头 `g(V)` 全军覆没？）

1. **为什么 WAM 之前表面上输给盲策略？**【强】
   100% 来自工程输入与集成不对等：WAM 缺了 `t−1` / `t−3` 近期关节速度、用了加权 MSE、且是单模型。同历史 `(6,12,18,24)` 单种子下，带视觉的 WAM 本来就优于盲策略（`0.00754 / 0.04192` vs `0.00855 / 0.04283`）。
2. **为什么“盲策略 + 纯视觉残差 `g(V)`”在物理上行不通？**【强】
   机器人运动修正量 `r = Δq_true − B_oof(q, dq) ≈ J(q)⁻¹ [x_target(V) − x_blind(q, dq)]` 是 **视觉目标 `V` 与当前构型/速度 `(q, dq)` 的强耦合函数**。切断 `(q, dq)` 只给 `V` 时，网络根本不知道 `B_oof(q, dq)` 已经减掉了多少惯性位移，只能在 145 个训练场景里靠背诵背景来拟合残差（训练降 17%，跨 parent 相关为 0）；而同时给 `(V, q)` 去训残差又会被 `(q, dq)` 拟合折间噪声（`E127-R`）。
3. **正确的架构方向已经水落石出**：
   不要拆成加性“盲策略 + 视觉残差头”，而是**直接在端到端联合 WAM（如 `J_clean`，保留世界头视觉正则以防过拟合场景）里，把本体特征升级为包含 `(1, 3, 6, 12, 24)` 的近期速度 + 动作项改用等权 L1**（推理时如需极致精度可做 3 种子集成）。
