## 机器人方向 ↔ demo4 顶视画面方向

右始终指机器人自身右侧（right arm数组槽7..13），不是以画面左右重新命名。以下是旧demo4相机拟合、有效工作区投影雅可比与20组实图运动对照支持的近似映射。每臂仍用自己的base_link，不建立精确共同世界系。

| 机器人基座系运动分量 | 顶视画面近似方向 | 限制 |
|---|---|---|
| 前 +X | 上；右臂常稍向画面左偏 | 透视随位置改变，不是固定像素角 |
| 后 −X | 下；右臂常稍向画面右偏 | 同上 |
| 左 +Y | 左 | 两臂相近；不能凭夹爪当时屏幕位置命名手臂 |
| 右 −Y | 右 | 左臂右移的两组起点部分出画 |
| 左前 +X,+Y | 左上，或以左移为主 | 同时下移时，画面上移可被抵消 |
| 右前 +X,−Y | 右上 | 20组大位移审阅未直接覆盖此扇区 |
| 左后 −X,+Y | 左下 | 右臂10组大位移实图支持 |
| 右后 −X,−Y | 右下 | 20组大位移审阅未直接覆盖此扇区 |
| 上 +Z | 也主要向画面上，含小水平透视分量 | 与“向前”投影退化，不能由单顶视箭头唯一分辨 |
| 下 −Z | 也主要向画面下 | 可抵消“向前”的画面上移 |

20组来自20个不同demo4 train parent，左右臂各10。15组两端可见、5组边界部分可见；均未发现数组左右互换或主要方向反号。采样按大水平位移选取，实际主要覆盖左臂左前/右移、右臂左后，**不声称八向均已独立实证**。这些对照检查的是方向/身份，不是精确标定；详细D01..D20文字记录和图像见gt/audit。

### 使用与未完成项

FK规范语言可直接用于E84-P的train/probe-val实验，遵守parent边界与类别不平衡。颜色mask可作固定HSV颜色监督，不能默认是目标扎带身份/实例mask。demo4旧顶视只有粗几何诊断资格，**未认证为精确像素GT**；demo3/demo6不提供投影GT，右腕手眼未开放；遮挡、尖端/锁孔/已穿入、物体成功与双臂世界距离均无真值。需精确像素误差结论时，仍需独立点击标注/重标定，不能用本次投影自己验证自己。

不需要用户为FK/颜色交付新增决策。若E84-P要用精确夹爪定位或demo6投影来决定LoRA方案，需要另立标定/人工像素真值任务；当前应仅作明确受限的粗探针。
