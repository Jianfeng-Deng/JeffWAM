# 任务 E45：以"机械臂-目标物体交互状态"为核心的候选动作评分器——调研与探索性设计（sol high；调研+小规模离线探针，不训练正式模型）

## 用户的要求（必须遵守）
1. 评分器的最终目的：评估候选动作的价值。设想：由"当前观测 + 候选动作"预测的未来表示，与"成功完成某子任务（如成功抓握、搬到箱上方、放入、松手）"的真值表示进行比对；该度量应**尽可能只关注机械臂/手与目标物体的交互**，抑制背景、无关关节姿态、物体/机械臂的绝对位置等混杂因素。潜变量对齐不是必须的，可以提出其它设计。
2. URDF/FK 提供精确的机器人空间信息，必须作为输入信号保留（例如手部关键点、手指几何、末端位姿、手坐标系）。
3. Tianji 与 Piper 视为两个独立任务、各自独立训练（不共享权重），评分器设计需对两者都适用，但分别实例化。
4. 背景：notes/2026-11-04-e36-design.md、2026-11-04-e38-design.md（子目标 G1–G8 与标注流水线）、2026-11-04-e34-design.md（瓶子 2D 状态、held/in-bin 弱标签）、notes/2026-11-04-e44-litsurvey-brief.md（若 e44-litsurvey.md 已生成也请读）。已知教训：time-to-go 回归排序失败（demo 优于其它 48–56%）；真实潜变量上训练的头在预测潜变量上误差大增（E23a 43→133–144 步）；单一路径成功示教导致动作-后果混淆；天机顶视相机-机器人外参标定差（手部 FK 投影 vs mask IoU 0.069、质心中位误差约 145 px，见 runs/e35vis_20261104/REPORT.md 与 E22/E22b 结果）；Piper 有 94 DAgger+136 策略回放（含失败）可用于真实后果监督。

## 请完成
A. 文献/开源调研（联网，只读）：交互/接触为中心的表示与奖励——手-物体关系表示（hand-object interaction, contact maps, affordance, relational/graph state）、以手或物体为参照系的表示（object-centric / ego-centric / end-effector frame crops、SE(3) 等变）、物体槽（slot attention, SAVi, object-centric world models）、目标/子任务成功判别（success detectors, goal-conditioned value, contrastive goal matching, VIP/LIV/R3M 类奖励、GVL/VLAC/ReWiND 进度）、机器人中以 FK 关键点引导的 ROI 裁剪或注意力；说明各自如何去除背景/位置混杂。表格：名称/年份/链接/做法/开源/可借鉴点；只列核实存在的。
B. 提出 2–3 个候选评分器设计（每个写清：输入〔预测未来表示、FK 几何、mask/ROI〕、交互表示如何构造〔例如以 FK 手掌坐标系为原点的局部 token 裁剪/重采样、手-物体相对几何、接触/包络特征〕、"成功原型"如何得到〔子目标标注帧的原型库、分类器、对比学习〕、训练标签与负例〔shuffled/hold/扰动动作在预测表示上；Piper 失败回放的真实后果〕、如何在预测表示上训练以避免分布偏移、如何做背景/位置不变性〔数据增强、坐标系归一、对抗去相关〕、与 URDF 输入的耦合方式、计算时延）。必须讨论天机外参不准时的影响与对策（例如 3D FK 只在机器人坐标系使用、或先做外参重标定、或用 mask 自监督学习 FK→图像映射）。
C. 小规模离线探针（只读加载 runs/e33_20261104/B/run/ep80.pt，CPU 或单卡≤0.5 GPU 小时，空闲卡显存≥16GiB 且利用率≤10%）：用现有 E34 held proxy/E38 自动规则候选作弱标签，比较"全图潜变量 vs 手附近局部 token（以手 mask 或 FK 选取）vs 手-瓶相对几何"三种表示对"抓握/未抓握"等交互状态的可分性（线性探针、留出 episode），以及对背景/位置扰动的敏感度（如同一交互状态、不同桌面位置的样本距离）。只作探索，不下结论为正式门槛。
D. 推荐方案与最小验证计划（≤2 GPU 小时），预注册门槛（动作敏感性、对 shuffled/hold 的配对排序≥70%且 episode bootstrap 下界>0.5、背景/位置不变性指标），失败退路。
