# 任务 E33-A：E33 模型与训练代码（配置 sol-code，gpt-6.1-sol medium）
先读接口契约 notes/2026-11-04-e33-contract.md（必须遵守），再读 tools/e32_model.py、tools/e32_train.py、tools/e32_data.py 了解可复用部分。

## 目标
实现 tools/e33_model.py、tools/e33_train.py（及必要的小辅助文件），支持 --variant B|C|D，按契约的损失、接口、检查点格式工作；通过 smoke 测试；**不要启动正式的 80 epoch 训练**（Claude 审核报告后再启动）。

## 完成标准
- [ ] 三个变体各跑 20 步 smoke（一张空闲 GPU，batch 8，accumulation 2），损失有限，各项损失值与各项对编码器/预测器的梯度占比（每 50 步，同 E32）写入 metrics；报告表格。
- [ ] 单元检查：①B 无任何 dyn/app 拆分与正交项；②前景权重 w 均值为 1、范围合理（打印统计）；③IDM 的输入使用 stop-grad 目标、梯度进入 z_t 编码器；④掩码目标通道与 slot 对应正确（打印各通道平均占比，应手/瓶子/箱子占比各自小于 50%）；⑤C 无 EMA 目标拷贝、无方差项，SIGReg 来自 upstream 实现，报告其权重和超参出处；⑥D 的 flow memory 不含未来 token（用梯度或输出差异验证：改变预测器权重不影响 D 的 pred_actions，而 B 会变）；⑦infer() 路径不含解码器/掩码头/IDM（独立加载验证，同 E32 的 inference_verification）。
- [ ] 续跑与暂停：同 E32，--resume 后参数与优化器完全一致（CPU 或 GPU 小测）；PAUSE 文件生效；每 10 epoch 存 ep{N}.pt（fp16 model state_dict，验证可由 e33_model.load_run 加载）。
- [ ] eval_forward / load_run 接口按契约实现，并给出调用示例（T-E 并行在写评测，会依赖它；**先把接口签名和 smoke 产生的一个 ep 检查点在开工 30 分钟内放好**，其余实现可继续完善，但不得改动接口）。
- [ ] 估算每变体 80 epoch 的耗时（按 smoke 步速，给出 GPU 小时），写 runs/e33_20261104/t_a/REPORT.md（≤60 行，含疑问和与契约不一致之处）。
- [ ] 额外交付：runs/e33_20261104/launch_e33.sh（用法 launch_e33.sh B|C|D <GPU索引>），在宿主机 H20 上用 setsid nohup 启动对应变体 80 epoch 训练，日志写 runs/e33_20261104/<V>/train.log，不要自己运行它。
