# Piper 穿扎带：语言与细粒度标注独立评估
日期：2026-11-10。结论：**暂不需要全面增加语言模态；需要优先补齐结构化事件／结果标注。语言只做有退出条件的小规模先导。**

范围：直接改善 Piper 穿扎带任务；Piper 可用顶视、双腕视和主动注视。不沿用“Piper 作为天机验证基准”的目标，不把本报告结论外推到天机。此次通过 BatchMode SSH 只读检查代码、JSON/JSONL 元数据，并直接阅读论文 v1 正文和附录 A–C（含第 7 节末尾）；没有训练、模型推理、GPU 作业或进程操作，没有修改数据／代码／划分。唯一写入为本报告。以下“核实”指本次直接读取；历史审计中的数值未重新扫描视频／Parquet验证，会单独注明。

## 1. 论文到底支持什么

原文：[Balestriero 与 LeCun，arXiv:2610.39302v1](https://arxiv.org/html/2610.39302v1)。论文提出的是有条件的充分条件，不是现实机器人表征必然相同的定律。

| 摘要代理的说法 | 原文核对与修正 |
|---|---|
| 同类 JEPA 独立训练，嵌入只差旋转 | **有条件正确**：有限世界、单射观测、相同世界正样本分布和边缘分布、旋转不变目标、总体最优解，且最优解仅差正交变换。二阶防坍塌＋谱间隙可证明唯一性；LeJEPA 完整分布约束下的唯一性仍是假设，有限世界甚至不能精确实现连续高斯目标。§2.1、A.1–A.3、§7。严格说 O(k) 包含反射，不只几何旋转。 |
| 好视图就是同一状态的两次观测；裁剪、遮挡、next-token 都不能对齐 | **过度简化**：理论允许由共同核 π 关联的 z、z′，不局限完全同一状态；关键是观测的干扰因素及正样本关系。坏视图占用干扰维度需要相应谱条件，不是所有裁剪必然失败。实验的好文本视图仍对“不同描述”裁短并轻度遮挡；无裁短反而变差。next-token 可重写为 JEPA 形式，但将干扰定理套到它上面，作者明说是启发式预测，并非推论。§2.3–2.4、§3.2、A.4–A.5。 |
| LeJEPA＝不变性＋SIGReg，λ=.02 | 主实验正确；附录 B 说明实现。**最大规模并非统一有效 λ=.02**：附录 C 披露 GPU 批量改变 SIGReg 有效权重，最终最大规模选有效 .01，选择曾参考 WIT。不能把所有结果看作严格同超参数对照。 |
| 正交 Procrustes；不同维度用线性映射；mutual 10-NN 与检索 | 基本正确。不同维度使用**行正交线性映射**，不是任意线性回归，理论不覆盖。mutual 10-NN 是两空间近邻索引集合重合率，不是跨空间互为最近邻配对；不拟合参数，但需要已知样本对应来评分。随机约 10/N，.01 仅适合 N≈1000；R@1 随机 1/N，R@5 为 5/N。§2.2、§3、附录 B。 |
| Flickr30k、MSR-VTT、Recap/WIT；没有动作／机器人实验 | 确认；还包括 COCO、零样本分类评估。Flickr 29k 训练图、每图五描述；MSR-VTT 实验用视频帧和描述。**数值动作向量、控制、机器人成功率均没有验证**。动作作为扩展方向，不构成实验支持。 |
| 互近邻约 .04–.23 / WIT .11–.18；图像大多坏视图 | 趋势对，但不是完整数值范围：Flickr 表 1 好／坏／next-token 为 .062/.047/.042；冻结 DINOv2 表 2 好视图可到 .257。WIT 最大模型与 DINOv2-B 均值 .184，不同视觉型号到 .197。绝对对齐远非完美。正文承认图像多数仍来自单图裁剪；附录 C 也显示高对齐不必然对应最佳字幕结果。 |
| 约 30 对能训练出可用字幕解码器 | **需纠正**：编码器与文本解码器已在大量数据上训练；30 对仅拟合欠定映射，再用 1,014 个验证图／文本的无配对池精炼。Flickr CIDEr=.169（表 9），不是“30 对从头训练”。 |
| 无配对在约 1.5 万图池上有效但方差大 | 需补条件：Flickr 是两个不相交池，各 15,007 图或另一半图的描述；主要有效模型预先学过大规模 web 文本。109M 模型 R@1=.164±.104。小型、只学 Flickr 描述的 JEPA 无配对 R@1 仅约 .012；1,014 小池的几何匹配可停留随机。§5.2、附录 C。 |

额外限制：Recap 三条文本中的两条由图文训练过的 captioner 生成，包含蒸馏信息；不是完全没有跨模态监督来源。只用 alt-text 的文字改写效果弱于看图重新描述。附录 C 还披露少量评测语料重合、WIT 选超参、部分测试集先行诊断；不推翻同数据下好／坏视图的排序，但降低将规模优势视为完全受控因果结论的力度。上述数字只说明论文图文实验，不预测 Piper 收益。[§7](https://arxiv.org/html/2610.39302v1#S7)、[附录 C](https://arxiv.org/html/2610.39302v1#A3)。

| 证据等级 | 能说什么 | 不能说什么 |
|---|---|---|
| 论文已证明（理想条件） | 相同正样本世界核＋唯一性等条件下，只差正交变换；谱模型中核不匹配和干扰影响误差。 | 有限机器人数据、遮挡视角或动作世界模型必然满足条件。 |
| 论文实验支持（图文／帧文） | 相同数据下，不同观测组成的好视图通常改善近邻、检索和部分组合应用。 | 加文本一定提升机器人策略；对齐越强控制越好。 |
| 作者推测 | 可扩展到动作等模态；将 next-token 的干扰解释用于非谱模型。 | 已有动作／机器人因果验证。 |
| 对 Piper 的外推（未验证） | 同步多视角诊断、事件辅助目标值得低成本检验。 | 详细文字→旋转对齐→策略改善这整条因果链已成立。 |

**与本地模型逐项对照：**

- **E47**：代码确有动作条件 OutcomePredictor 与 EMA target；**E32**：Predictor 输入 z/q/action/FK，target 按 EMA 更新。不是论文的恒等预测器、独立模态 LeJEPA；原文 §2.1 明确不覆盖这类世界模型。
- **E28 有一处需纠正**：当前 Piper port 的 `USE_EMA=True` 是训练器对整模型的平均／评估；未来潜变量监督来自 A2 `target_latents`，用**当前编码器 stop-gradient**；另有冻结 DINO teacher 锚定。不能把 E28 的潜变量目标也一概叫 EMA teacher。它仍是动作条件动态预测，仍不在该定理覆盖内。
- 173 条是处理后片段数，非 173 个完全独立任务试验。视角有遮挡、文字有损、动作依赖控制策略和历史，均不满足单射渲染直觉；有限数据／SGD 也不是总体最优。
- 动作尤其不是静态状态的可逆“另一种描述”：同状态可选多动作，同动作可产生不同结果。适合验证的是 (当前观测、候选动作、历史)→后果；强行把动作和当前画面旋转成一个表示可能抹去控制必需信息。

## 2. Piper 已有的“好视图”，以及语言的增量

| 候选 | 判断及应用边界 |
|---|---|
| 同时刻顶视＋双腕视 | **现成、优先的多观测候选，不需要先加语言。**能比较冻结表示的近邻结构、拟合旋转并做留出检索／探针。腕相机位置随手运动，遮挡和可见内容不同，干扰不独立于状态；同步索引也不保证曝光完全同步。因此这是机制诊断，非满足定理的复现。 |
| 主动注视裁剪 | 若只是同一图的确定性裁剪，是信息重分配，不是独立世界观测；若选择另一腕相机或另一次采样，需按实际来源区分。它可能通过放大尾端／锁头改善控制，不能因论文称“坏视图”而舍弃。对比同尺寸随机／固定裁剪，记录视角和裁剪来源。 |
| 语言描述 | 只看这些画面所写文字不会凭空增加传感信息；可提供人类的关系抽象、遮挡不确定性、事件边界和跨样本语义。若作者另看未来／触觉／操作者意图，这是额外信息源，必须记录，不能伪装成当前可见状态。重复任务指令几乎没有区分阶段的增量。 |
| 每事件两条独立描述 | 若要研究论文的“不同观测描述”机制，值得做，但不是必须每帧多人标。两人独立看同一因果片段各写一句；不能只是改写同一句，不能互看答案。长而详细的一句不等价于两个独立视图，也未必更好。论文没有证明两位人工标注者是必要条件或最优成本方案。 |

两个容易忽略的问题（本报告判断）：

1. 同一编码器的顶／腕表示、或顶视与其裁剪，本来就共享权重／像素。高对齐不能证明“独立训练产生同一世界表示”；需报告权重共享，比较原始 DINO 特征与任务编码器、去除 camera embedding 前后。已有多视角融合只能用于下游对照，不能拿融合后的同一个 token 自证对齐。
2. 仅令每个精确状态与自身配对，世界核可能是单位阵，多个特征值相同，缺少唯一子空间的谱间隙。“多机同刻”本身不保证低维唯一性。也不能随意把整个穿带阶段都当同一状态，否则“接近孔／已穿过孔”等控制差异会被消掉。

目标应是**保留共享任务状态，同时保留视角特有的精细几何**。辅助对齐最多先作用于小的语义分支，保留未对齐视觉、q/FK 和动作分支；避免迫使全部表征语言化。

## 3. 哪些收益真的需要自然语言

| 用途 | 更便宜的结构化替代 | 语言的可能增量／优先级 |
|---|---|---|
| (a) 子任务／阶段条件 | phase、arm、object、attempt，在线由观测预测；允许双手并发和回退 | 单任务下预计小。先用阶段 ID；不得部署时喂人工真值阶段再宣称自主策略改善。 |
| (b) 失败／重试／换手与动作结果对齐 | 事件时间区间、失败类型、接触关系、局部 attempt 结果、可见性 | **细标很有价值，但不必语言化**。简短 note 适合补异常机制、开放类别；先判断能否转为关系字段。 |
| (c) 训练辅助对齐 | 多相机一致性、事件分类、阶段／关系预测 | 语言可能以语义先验改善小样本泛化，未验证。必须与同标签 one-hot、模板文本及同容量非语言辅助头比较。 |
| (d) 部署输入 | 固定任务提示＋因果观测＋预测阶段 | 当前单任务不需要新增动态语言输入。只有未来确需用户指定左右手、不同扎带／目标或恢复意图时才重新评估。训练期文字可以只做 teacher。 |
| (e) 数据审查／管理 | 标签筛选、时间轴、parent/attempt/结果字段 | 自由 note 和自然语言检索有实用价值；其收益不能算作策略或 PRH 得证。可保留，没必要全量写长描述。 |

判断：单任务中优先级是**事件与关系结构化标签 > 少量异常 note > 双人独立短描述 > 部署语言模态**。语言增量是否很小，应由“同信息标签”的对照决定，不能预先宣判。

## 5. 最便宜的先导：方案而非此次执行结果

**共同门槛：**先在新的版本中确定 parent-group 划分、测试封存及源时间合同；重算训练统计。旧8条可作为探索集做 leave-one-parent-out，必须宣布不再是该新实验的独立测试；或者保留它们只评估，在新训练组标8条。任何新旧模型对比都用同一干净测试集，不能只把新模型重划分后与旧污染分数相减。

| 步骤 | 方法与对照 | 判据／放弃条件 | 建议成本上限（规划估计，未计时） |
|---|---|---|---|
| (i) 无语言，冻结多视角 | 先取约1,000–2,000个稀疏同步锚点、跨20–30个训练／开发父轨迹，按事件和普通时段分层。顶↔左腕、顶↔右腕；同源 gaze 另报。比较原特征、正交Q、等维低秩Q、ridge线性映射；全部映射只拟合训练组。 | 真配对优于跨episode打乱、episode内大幅时间偏移和同阶段异状态难负例；去相邻帧近重复后仍有信号。若只认场景／时间进度或只有高容量映射成功，不能支持“仅差旋转”。 | 有合适特征缓存时0 GPU，CPU线代通常可小时内完成；无缓存先用CPU小样本或申请以后独立排期，单次冻结提取设置≤2 GPU小时预算，超出先缩样。工程0.5–1人日。此次0 GPU。 |
| (ii) 小规模语言诊断 | 旧8条100事件，每事件两个独立短描述（约200句）；补约40–80个普通／过渡／歧义窗口，避免只评事件中心。视频→文本、文本→视频检索及近邻重合；同事件两句为多正例。对照：one-hot结构标签、确定性模板文本、单句、两独立句、同阶段打乱文本。 | 除优于随机外，独立描述须提供超过结构标签／模板的留出增量；同阶段难负例须能区分手、尾端／锁头关系，且不依赖作者或结果词。若只能读出阶段名称，停止扩写文字。8个父组只能是探索，不能宣称可靠策略增益。 | 人工约6–10小时含双人描述、抽查与规范；0 GPU的TF-IDF/已有CPU文本编码器先筛查。若后续有获准现成编码器，冻结特征预算≤2 GPU小时；不从8条训练文本JEPA。 |
| (iii) 小模型辅助目标 | 仅诊断有信号后，固定视觉/动作数据和训练预算，比较：无辅助、结构化辅助、多相机辅助、模板文本辅助、独立语言辅助；再加打乱语言负对照。先冻结 backbone，只训练小头／adapter，3个种子。 | 独立父组事件macro-F1、阶段balanced accuracy、边界F1（预设容差如±0.2s）或校准误差；最后才能看策略。语言优于同信息结构标签才有扩标理由。若只改善检索、不改善任何任务指标，停止语言主线。 | CPU小探针可0 GPU；adapter试验建议总预算≤12 GPU小时、1–2工程人日，不含后续实机。数字是止损预算，取决于模型与缓存，不是硬件测速承诺。 |

**指标实现与防伪信号：**

- mutual k-NN 使用每空间内部邻居索引重合，排除自身；小样本取 k=min(10,N−1)，随机参考约 k/(N−1)，以保持候选结构的置换零分布为准。不要把0.01照搬到100事件。对齐后双向 R@1/5 与平均余弦／归一化残差一起报；重复或语义等价描述采用多正例，否则“检索错另一条等价描述”不是真错。
- 正交拟合：对训练特征中心化，XᵀY=UΣVᵀ，Q=UVᵀ；测试不再拟合。不同维度先在训练组独立PCA至8/16/32维（由内层验证选），再Q。明确这已加入降维，不能声称原始空间只差旋转；样本数应明显多于有效维度并检查秩。另报无白化和训练白化敏感性。
- 用父轨迹为单位 bootstrap／置换，不能把连续视频帧当独立样本；层、维度、损失权重不能在最终test上挑。随机相机ID、episodeID、归一化进度、q-only均应做便宜对照。
- 对齐残差可以作为阶段探针的**一个特征**，比较残差单独、原视觉/q/进度、原特征＋残差；阶段标签必须独立人工。高残差也可能只是遮挡、相机运动或无共同视野，不是“失败”真值。
- 建议预注册实用门槛（本报告工程判断，非论文定值）：检索提升超过置换95%分位数，且配对增益的父组95%区间下界>0；任务辅助达到macro-F1/平衡准确率至少+5个百分点且父组区间支持正增益，至少3/4开发折方向一致。小样本区间过宽时只扩大独立评估组，不扩大语言长文。
- (i)失败时先查同步／遮挡／表征，(ii)失败时先查文本保真与同义正例。两者并非逻辑上互为必要条件；但预算上，在没有稳定语言特异信号前，不升级到语言策略训练。
- 真正的策略指标：穿入成功、整任务成功、局部恢复成功、完成时间／人工干预。离线关节误差和事件F1不能替代闭环成功；以后由Piper负责会话在相同起始条件、随机试验顺序和预定试验数下验证。此次未运行。

## 6. 最小可行标注方案

**结构化优先，按事件和歧义处标，避免全帧长字幕。**

| 内容 | 最小字段／粒度 |
|---|---|
| 身份与时间 | parent_trajectory/session、processed_episode、source_frame/time、片段起止、attempt_id；事件给 onset/offset 或边界不确定区间，保留原frame。静态删帧接缝与真实录制断点分开。 |
| 任务语义 | event、arm/from_arm/to_arm、object（tie/tail/locking_head）、阶段及允许回退；握持／接触／尾端相对入口关系（未接近/接近未穿/已穿/不可见）。支持双手并发，别强塞单调单阶段。 |
| 结果 | attempt结果、片段结果、父轨迹最终结果分别记录；区分失败、重试、人工介入、未完成／不可判断。事后结果可以作监督标签，但不得放进当前观测描述或部署输入。 |
| 可信度 | camera证据、occluded/unknown、标注者ID、置信／争议标志、数据版本与是否模型辅助。未观察到≠没有发生。 |
| 可选语言 | 仅选中的事件／困难窗口，每人一句约15–40中文字，写“看得到的当前状态／刚发生事件”；例如“右夹爪夹持尾端，尾端靠近锁头入口，尚看不清是否穿过”。不要写“即将成功／下一步会滑脱”。 |

执行顺序与数量（均为预算建议，不是收益保证）：

1. **先复核现有8条100事件**：规范other/tighten、局部failure/retry、时间映射与可见性；可先不加语言。其稀有失败事件不足以评估失败类型。
2. 语言探索只做上述8条或新训练组8条；按两人独立、先盲描述后对照结构标签。看完全片做结果审查和只看到窗口截止时刻做因果描述，分两轮／不同人员，避免事后记忆渗入。
3. 若通过先导门槛，扩大到**约24–40个独立父轨迹**的结构化训练／开发标注，覆盖正常穿入、滑脱、换手、重试、遮挡、人工纠正；只给其中约12–16个代表性／困难父组加双描述。另留**12–20个独立父组**作为确认评估；最终成功率仍可能需要更多实机试验。此规模只是探测较大事件／阶段收益的合理起点，不足以保证检测小策略收益。按8→16→32父组学习曲线决定是否继续。
4. 扩样避免只挑“漂亮成功”或模型高分片段；先按来源/父结果/阶段预分层，再组内随机。困难样本可加，但另报自然频率测试分数。标注者看不到模型输出、建议框、检索结果或另一人答案；裁剪只来自部署可获得观测，不用未来定位。20%–25%双标、盲仲裁；报告边界差与一致率，不要求刻意同义换词。
5. 现有8条约11分钟：复核结构事件预算2–4人时；100事件×2人×约1–2分钟≈3.3–6.7人时，连同普通窗口、规范和仲裁，语言先导约6–10人时。24–40父组若每组20–40分钟细标，再加20%–25%复标及设置，约12–36人时；其中12–16组双语言另约8–16人时。原始长轨迹、严重遮挡可能显著更慢，先计时2条再重估。

如果语言不胜结构标签，保留少量异常note用于管理，停止扩标。若未来引入多任务指令、开放对象关系、真正需要语言指定意图，或严格控制后语言能改善困难恢复，才升级语言模态。没有可靠样本量公式能从这篇论文推导“标多少Piper必定有收益”。

## 7. Piper 数据直接改善 Piper 的路线

**先修合同和评估，再判断模型缺什么。**

| 优先项 | 核实证据／风险 | Piper内直接用途 |
|---|---|---|
| P0 父轨迹隔离 | 已核实3组跨集合；历史模型还可能已看过将要成为新test的父组。 | 按parent优先、无parent则raw hash分组，必要时按session外推测试；新manifest、训练统计与缓存版本化。验证旧checkpoint训练清单：新test不得被其训练／初始化适配看过；否则需后续干净重训或新采集测试。此次不改。 |
| P0 动作／时间语义 | 目标是下一源帧反馈q，不是command；处理帧删静态后 t+48不一定等于1.6秒源时间。E39索引按处理行取窗口。 | 数据用于未来关节轨迹模仿；保留q锚定、左右关节/夹爪单位、负夹爪语义、真实时间和有效步mask。不要凭模型变量名commands就当控制量；若要反事实物理预测，先查可用发送命令、延迟和干预日志。 |
| P0 结果分层／负例 | 173条片段成功全真；7条父轨迹失败；失败/重试人工覆盖少。 | 将局部纠正成功与整任务失败分开；获得成功前后、失败、恢复、人工介入的事件边界。基于结果评估恢复，而非把所有窗口都当正例。 |
| P1 覆盖与精细可见性 | 单任务、相关片段，细尾端/锁头操作；三相机和gaze已具备，真实覆盖未逐视频审计。 | 优先测是否看清入口、相对位姿、遮挡与夹持状态；再决定补采姿态/材料/恢复案例。语言不能补回没拍到的接触信息或缺失失败分布。 |

**最有价值的三个无语言实验（均为下一步建议，未执行）：**

1. **动作与时间合同基线**：干净父组上，固定小型BC/现有策略结构和预算，比较当前下一帧目标、正确q锚定残差及有效时域/接缝处理；与hold、q/dq-only对照。不要把关节目标直接改成未记录的command。报告按阶段、来源、预测时距分层的误差，随后用一致控制接口验证闭环。这能识别“状态复制／时间错配”造成的虚高。
2. **观测消融**：同训练数据、参数/输入token预算近似匹配，top-only、raw3、raw3＋因果gaze（另对固定／随机crop）比较；同时做第5节(i)冻结几何诊断。重点看对齐/穿入、手遮挡和滑脱恢复。同步、分辨率与延迟同时计入。若多视角融合有效，未必需要显式旋转损失。
3. **结构化事件与恢复辅助**：无语言策略＋少量阶段/关系/attempt监督、事件均衡采样，与无辅助及等预算随机采样对照；仅训练组真值，部署用预测事件。单独衡量“进入穿带→穿过”“滑脱→重新夹持→重试”，避免成功长轨迹占满训练。可按事件检索成功恢复片段作训练采样，而非喂未来动作。

语言先导可在1的评估合同修好、2的冻结特征准备后并行进行少量人工工作；**语言训练应排在3的结构化对照建立之后**。如果三项尚未澄清动作、观测和恢复瓶颈，不值得先支付全量语言标注成本。
