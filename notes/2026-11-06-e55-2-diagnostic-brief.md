# E55-2 简报：精细动作区分能力诊断（预言机 jitter + 候选内选择后悔）

日期 2026-11-06。承接 E55-1（W/runs/e55_v2/REPORT.md）。只用 CPU，不训练任何模型，不改已有文件和数据包，新文件放 W/scorer/scorer_v2/ 与 W/runs/e55_v2b/。

## 背景
E55-1 的免训练目标距离评分器：demo>hold 0.92、demo>reverse 0.81、demo>shuffled 0.71，但 jitter 0.05 仅 0.49（随机），分数与事件进度 Spearman 中位数 -0.2。需要判断：小差异分不开，瓶颈在预测器/表示，还是在评分器（目标选择与距离）。

## 任务
1. 预言机 jitter：对 8 个评估集，h32 为主、h16 为辅，用“预测未来 vs 真实未来 token 距离”（预言机，沿用 E54 与 E55-1 的 oracle 实现），报告 demo > jitter_05/10/20 的胜率（正式 G_rank 口径：平局边界 0.02、NaN 留分母、按集重采样 10000 次、seed 45）。同时报告 R0 与 R1 两种表示下的预言机值，并给出 E55-1 主评分器同一口径的 jitter 值作并排对照。
2. 差距分解：对每个窗口计算 demo 与 jitter_05 的预测未来之间的距离幅度，与“预测器噪声下限”（同一窗口 E33 集成 B/B_s2/C/D 之间预测未来的差异，若包中有则用，没有则说明缺失，不要自行训练）比较，回答：jitter_05 造成的预测差异是否小于模型自身的随机差异。
3. 候选内选择后悔：在每个评估窗口的 11 个候选内，评分器选第一名，报告 (a) 选中候选的“预测未来到真实未来”距离相对 demo 的比值，(b) 选中候选是 demo 的比例，(c) 对比随机选、对比永远选 demo 的差距。注意：候选集是人造的，只用来看趋势，报告里写明这一点。
4. 检查是否存在“策略采样候选”（run E / E33 对每个窗口采样的多个动作及其预测未来）。先在 T/data、W/runs 下查找；若已有缓存，则对其重复第 3 项；若没有，不要自己起 GPU 任务，改为在 REPORT 里写明缺口，并给出生成这些候选所需的最小方案（需要的模型文件、采样数、预计显存和时间），由 Claude 与用户决定。
5. 结论只写描述性结果和区间，不下“通过”结论，不推断“优于示教”。所有评估集标签与真实未来不得进入目标构建；评估只跑一次正式口径，调试输出标明作废原因。
