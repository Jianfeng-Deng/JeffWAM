# 天机双臂＋Wuji 世界动作模型独立架构评估

报告文件标识：20261110；实际审阅日期：2026-11-09（America/Sao_Paulo）。

审阅对象为用户指定的 E47 及 E55/E61/E63/E64 证据链。通过 `ssh -o BatchMode=yes <gpu-server>` 阅读项目代码和报告；没有运行模型、训练、GPU 评估或仿真，没有操作他人进程。唯一项目写入为本报告的新文件。以下实验均为建议，未执行。

## 判断

**E47 目前是“带未来预测辅助任务的行为克隆策略”，还不是能靠预测后果改善决策的世界动作模型。最关键的两个问题是：反事实后果缺少可识别的数据支持；预测目标与决策目标没有建立可验证的联系。**

93 条示教可以支持专门化的模仿策略，也可能支持示教邻域内的短时预测。但从这些成功轨迹学到可靠的“任意候选会造成什么、哪个更好”，证据远远不足。约 27,281 帧、30.3 分钟视频、80 条训练 episode，以及大量重叠窗口，不能当作 27,281 个独立的接触实验。

我赞成继续研究潜变量预测、运动预训练和交互区域建模；不赞成现在就把“保留 JEPA 为核心”和“端到端自我评分”设为不可撤销的架构约束。应先证明 JEPA 对策略有增量价值，再证明预测对选择有增量价值。当前最有依据的策略改进来源仍是任务适配后的视觉表征和模仿学习，不是世界模型已经学会了任务价值。

## 二、最关键的两个缺陷

### 1. 示教轨迹上的条件预测，不等于反事实动力学

训练中通常只观察到某个状态下示教者选择的一条动作序列。动作、阶段、手的位置、瓶子初始位置和最终结果高度相关。一个模型可能靠 q、画面和动作轨迹的阶段特征预测成功，却没有学会在相同接触状态下换动作的真实效果。

形式上，拟合 `E[z_future | observation, demonstrated_action]`，不足以识别分布外动作干预后的后果。没有接触力、物体完整 3D 状态和视觉历史时，示教者根据未观测因素选择动作还可能产生额外混淆。多个在示教上同样准确的模型，可以对未执行动作给出完全相反的预测。

这解释了：训练集很好、新 episode 下降；大幅 shuffle 容易分辨、细小扰动不稳定；直接用模型梯度改策略可能沿着错误的梯度前进。**这是数据覆盖与状态可观测性问题，不能靠给更多候选、加损失或端到端连接自行补足。**

不过，“没有反事实标签”不意味着任何泛化都不可能。运动学、局部平滑性、对象持续性和外部机器人预训练可以带来有用先验；应该验证的是这些先验在哪个动作邻域、哪个阶段成立，而不是笼统要求 54 维全空间判断。

### 2. JEPA 相似度没有定义任务价值，策略也没有必须使用世界模型的理由

JEPA 优化表征预测的一致性；RGB/mask 约束可重建性；IDM 约束动作可读出性。这些都不自动定义“抓稳、避碰、搬运、释放后留在箱内”的偏好。

终点潜变量距离尤其容易混入机器人姿态、背景、遮挡和拍摄风格。正确抓取有时需要先远离终态外观；释放后手应撤离，瓶子被遮挡也会改变图像距离。时间进度与成功概率不是同一个量，终态相似度也未必沿成功轨迹单调。

当前动作头不经过预测后果，自然可以完全绕开动力学。E61 的预测终点又是当前视觉的确定性函数 `g=f(z_t)`，在给定同样的 z 后并没有新增观测信息；它只能提供有利的计算分解或训练归纳偏置。单任务、近似固定终点下，动作头忽略它并不奇怪。强迫网络使用终点，并不等于给它一个真正有信息的目标。

**决策缺少选择环节是代码事实；“只要补上选择就有收益”则没有证据。** 评分器和后果模型的分辨率未达到候选之间的相关差异时，增加 K 还可能放大对预测误差的择优利用。

## 三、对六类现象的因果判断

### 1. 泛化差与静止漂移：同意主因是泛化，反对单因解释

强 fit/test 差距和两 seed 重现支持过拟合/有效事件覆盖不足。小物体运动占有限监督质量、任务阶段强相关、960×256 潜变量与可训练视觉后四层提供较大记忆容量，都是合理解释。但现有证据不能区分初始摆放变化、身份混淆、时延、遮挡还是接触状态变化分别贡献多少。

不能仅凭静止瓶子 IoU 差就断言“JEPA 不会物理恒常性”。诊断报告指出输出概率较尖，主要是位置、面积和外溢误差；fit 的 native/common 结论还相反。应分别比较真实当前帧重建、真实未来帧重建、预测未来解码、当前帧复制，并查看质心和面积，定位编码器/解码器误差与动力学误差。

残差只提供“容易复制”的优化起点，不保证模型按接触条件决定保持或移动；损失权重也不能创造新覆盖。E54 失败削弱了“只调这两个旋钮即可修好”的解释，没有否定对象持续性和区域结构化建模。

### 2. 后果不参与决策、评分器失败：同意，但“预言机上限”需改名

E36b 候选输入无收益，只能说明那个接法和训练目标未产生收益。把候选作为输入，并不等价于显式比较候选后果。

E55 的 .527 是“示教未来匹配诊断”，不是任务质量的预言机上限。小扰动可以产生相同结果，也可能存在多个成功动作；demo 未必严格优于每个 jitter。反过来，模型把一个坏动作预测成好结果，也会获得好的预测距离。应同时报告平局比例、连续分差、扰动方向、预测噪声和真实执行证据是否存在。

已有 .32 是特定全任务目标的轨迹内时间相关性，不能推广为所有价值函数的能力上限；E55-4 甚至记录 h32 越过“下一事件”导致阶段目标距离反向。这是目标与时距定义问题，不一定是运动预测问题。

### 3. 终点被忽略、子目标疑似塌缩：符合预期，但不是“规划无用”

除了目标信息冗余，还可能有：单个目标 token 与 960 个视觉 token 的竞争、目标分支学习速度较慢、归一化尺度不匹配，以及纯动作损失不奖励使用目标。注意力 token 数量只是一种可能因素，不是忽略目标的充分证明。

若训练集中没有相似状态对应不同目标/不同意图，目标条件控制本身就很难被识别。真实终点替换无效说明当前模型没有利用该通道，不能说明一个正确训练的目标条件策略也无效。

隐式子目标由可训练投影产生，又缺少外部锚定时，常量或只编码阶段即可成为捷径；联合去噪还改变了优化任务。保留对“塌缩”的疑问是对的，应先看跨 episode 方差、有效秩、条件打乱和策略响应，再定性。当前移除它是合理的工程选择。

### 4. 换编码器无收益：否定的是特定冻结适配方案，不是预训练本身

E63 支持“更好的静态分割特征，不自动带来更好的动作”。但冻结 backbone＋浅适配层、表征坐标变化、继承的下游权重和训练预算，都与微调 E47 不同。跨编码器 native 潜变量距离更不能直接当作公共尺子；表征缩放和几何改变即可降低距离。

合理结论是：任务适配目前很重要，盲目扩大/更换冻结特征的收益不足。不能推出 DINOv2 内在优于其他编码器，也不能推出视频预训练没用。

V-JEPA 静态分割探针不佳不能代替运动/终点检验。反过来，视频运动先验也不能直接迁移成这台双臂 54 维关节机器人的接触模型。已有 E29-S4 采用 7 维单臂动作接口并存在坐标、频率、手指表达等差异，迁移失败不能全部归因于视频表征。

### 5. 想象训练：目前只证明可优化代理，没有证明策略改善

E64 同时出现模仿误差变差、真实未来潜变量匹配更差、终点进度代理略好。这既可能是策略牺牲示教时序去更快接近终态，也可能是利用两个世界模型共有的终态偏好；无真实环境结果时无法区分。

seed48 世界模型复核很有价值，但它与训练模型共享数据、架构和目标，不能排除共同偏差。所谓“独立”是训练随机种子独立，不是独立物理证据。缺等步数纯模仿控制，还无法排除继续训练本身。关节 RMSE 上升也不等价于任务成功率下降；当前只是没有足够依据接受这种代价。

### 6. 候选尺度、IDM、URDF 与闭环：需要更具体的解释

0.04–0.05 rad 的全关节 RMS 与 jitter 数值相近，只是量级警告。40 个手指关节会影响平均值，机械臂方向、雅可比、时序和接触阶段决定实际后果；同样 RMS 可以几乎无效，也可以导致错过接触。候选多样性应在腕部位姿、手指协同、手物距离和抓放时序上度量，不能只靠加大噪声。

IDM 确实约束表征，但可能主要通过可见的机器人运动完成任务。它不保证瓶子的接触后果被编码。URDF geo66 是可用的几何先验，代码中有效性处理不等价于关节限位投影、速度约束或碰撞约束；命令 FK 也不是实际执行后的物体状态。

没有闭环环境不是单一网络模块的 bug，却限制了最终结论。重复读示教真实帧的开环回放，不能测到策略偏离后能否恢复。现在不能声称完成“观察—选择—执行—再观察”。

## 四、静态代码中另外值得重视的结构问题

1. **观测不是充分状态。** 输入只有当前图像与机器人 q/dq，没有显式物体速度、抓持/释放历史或遮挡状态。相同顶视图和关节角可能对应不同瓶高度、速度、滑移和接触状态。+32 帧约 2.13 秒，单一确定性潜变量预测可能掩盖这种多解性。增加短因果历史值得优先验证，但顶视历史也无法恢复所有隐藏变量。

2. **预测器的跨空间交互较弱。** 动作 temporal blocks 只读取状态 token，不读取视觉；`SpatialReadBlock` 让每个视觉 query 读取动作 token，没有在预测阶段显式做视觉 token 之间的消息传递。DINO 初始 token 已有全局上下文，所以并非完全没有空间信息；但滚动时缺少显式的手—瓶—箱关系更新，不利于把局部接触转化为物体位移。不能把这条结构判断直接当作性能根因，需消融。

3. **直接预测与 rollout 的 reader 索引不同。** `OutcomePredictor.forward()` 第 257 行按 horizon 选 embedding，第 259 行却按调用中局部索引 i 选 reader。一次调用四个 horizon 时分别走 reader 0/1/2/3；rollout 每次单 horizon 调用，全部走 reader 0。因此不是同一个时距头的简单递归使用。它可能是有意区分 direct/rollout，也可能是实现偏差；本次没有改代码，亦不能据此判历史 checkpoint 全部错误。后续比较必须固定并解释此语义。

4. **当前源代码的 direct/delta 命名不能直接还原历史实验。** 当前第 261 行始终输出 `ctx.z + out(...)`；`forecast_parameterization=delta` 在构造器中改变的是末层零初始化。需要比对当时源快照才能知道 E54 的精确参数化对照，不能仅看当前配置名断言 direct 是绝对值预测。

5. **方差正则不是完整的跨样本防塌缩。** `e47_train.py:328–336` 在每个样本内部对当前与预测的空间 token 求方差。一个几乎固定但空间位置不同的模板也能有较高方差；该正则不保证跨 episode 的信息量、动作敏感性或通道去相关。RGB、mask、IDM 提供其他约束，所以这不是“E47 已经塌缩”的证据。

6. **所谓滚动仍固定初始实测机器人状态。** rollout 更新 z，但保留起点 q/dq/状态 token，后续 action tokens 主要看当前分段。保留真实 q 锚点可避免伪造观测，是正确约束；同时也意味着它不是完整的递归状态转移模型。若发展更长想象，必须将实测锚点和预测的机器人/物体隐状态明确区分。

## 五、我会怎样改设计方向

### 保留潜变量预测作为可检验部件，不预设它必须居于决策中心

用一个强、简单、相同视觉适配预算的行为克隆策略作为正式基线。JEPA 可以作为辅助学习和短时后果预测部件；是否保留、保留多大权重，由它对留出 episode 的策略与物体预测是否提供增量价值决定。像素重建在当前阶段有锚定和诊断价值，不建议同时删除像素约束、改编码器和加规划头。

### 从“关注前景”改成“跟踪对象及关系，同时保留全局”

保留低分辨率全局上下文；另设两手、目标瓶、箱子及交互邻域的稳定 token/ROI，输入短因果视频历史。用对象身份、相对位移、可见性、手物关系和预测不确定性组织局部输出。关注区域由当前/过去观测产生，不能用未来 mask 选择推理 ROI；遮挡或定位不可靠时保留全局通路。

优先加入具有单位的监督锚点：可见瓶中心/运动、手腕相对瓶位置、释放后持续可见等。只有图像证据时称其为视觉代理，不能命名为真实接触力、抓稳概率或 3D 入箱成功。伪掩码应有置信度与人工抽查，不能把标签错误用更大权重放大。

机器人自身运动与物体接触响应应分开处理：FK 提供可解释的机器人几何；学习模型负责执行误差与对象响应。对不可观测接触使用有限的多假设/不确定性表达，避免立即扩大成一个更难验证的大型生成模型。

### 视频预训练值得做小规模、任务对齐的验证

官方 V-JEPA 2 工作并非仅凭无动作视频直接得到机器人控制：其动作条件模型还使用机器人交互数据后训练。这支持视频先验的价值，也说明动作接口和接触域适配不能省略。[V-JEPA 2 原论文](https://arxiv.org/abs/2506.09985)

对这里的可行路径是：先用截至当前时刻的短 clip 测运动信息，再决定是否替换/融合视觉编码器；避免把未来帧混入“当前观测”。对照必须包含相同历史长度的 DINO，而非只比较视频编码器与单张 DINO。只有 93 条示教时，直接迁移原生 7D 动作 predictor 到双臂灵巧手、或训练通用接触物理，大概率不成立。

### 自身评分需要外部锚定、支持域和弃权

可学习的 scorer 可以共享视觉骨干，但其偏好必须由真实可观察的事件/结果或明确约束锚定，并在留出 episode 上检验。没有环境奖励并不禁止从示教标注事件；这些是新引入的监督/代理，不应包装成模型“自发理解任务”。只有成功示教时，阶段识别能力不等于成功概率估计。

我建议的部署目标是：模仿先验产生少量有结构的候选 → 运动学/速度可行性检查 → 短时后果预测 → 经独立检验的任务代理排序 → 分差不足或支持域外时退回基线 → 有环境后只执行短前缀并再观测。现阶段可以研究其中的离线模块，不能宣称闭环已形成。

训练早期先固定/隔离评分目标，避免策略、世界模型和评分器共同改变潜变量几何而互相“证明”更好。端到端微调应是验证完成后的工程选择，不是解决缺标签和缺覆盖的手段。ensemble 分歧可作为拒绝信号，但低分歧不保证分布外正确。

**在现有数据条件下大概率走不通的目标：** 自举出通用任务价值；对任意分布外 54D 候选可靠排序；用同一世界模型产生奖励再用它验证自身改进；仅凭更多随机候选获得规划能力；用开环动作误差或潜变量进度替代成功率。

## 六、如果只能做三个下一步实验

以下按优先级排列。每项先登记指标和停止规则，再看结果；它们不是当前执行请求。共同要求：按 episode 而非窗口统计；至少两个训练 seed；fit 内分组验证选型，外层 episode 留出检验；固定动作噪声和候选集作配对比较。4 个 val episode 不能支撑大规模超参搜索；9 个 test 已被多个实验反复查看，后续应标注为既有探索测试，不能假装仍是全新确认集。

### 实验 1：JEPA 是否真正给动作策略带来价值？

**问题。** E47 的收益到底来自微调视觉、当前帧辅助学习，还是未来动力学？

**设计。** 在同一 DINO 初始化、可训练层、状态输入、flow、数据顺序、更新步数和早停预算下比较三个臂：A 纯行为克隆；B 行为克隆＋当前帧 RGB/mask 重建；C 完整 E47。A/B 保留同样策略容量；去掉不使用的预测辅助模块不会增加策略可用信息。以 B 对 C 为主要对照，区分当前视觉锚定与未来任务的额外价值。先固定 reader/direct-delta 语义并记录源码；若修正实现，所有相关臂使用同一版本，不能夹带不同代码比较。

**判据。** 主指标为 episode 等权动作 RMSE 与腕部位置误差，另外单列前 1–8 步、手指/双臂和抓放邻域。建议预登记实用门槛为 C 相对 B 至少 2% RMSE 改善，配对 95% 区间排除无改善，两 seed 同向且关键分层不退化；2% 是本报告建议的工程阈值，不是已有科学结论。同时报告 C 的物体预测，不能用预测提升替代策略提升。

**结果如何改变决策。** C 无增益则 JEPA 降为研究/诊断分支，策略用 A/B；C 有增益只证明辅助学习有效，仍不证明规划有效。若各臂精度相近，优先较简单且推理更省的方案。

**最大风险。** 单样本 RMSE 偏好条件均值，可能漏掉多模态策略的实际价值；因此该实验决定当前开环证据下的架构取舍，不决定真实成功率。不同任务早停目标需统一策略选择口径，不能用各自总 loss 横比。

### 实验 2：瓶颈是缺运动状态，还是换更强编码器就能解决？

**问题。** 短因果历史能否提高物体运动预测及对动作的有效依赖；视频预训练是否在相同信息条件下额外有用？

**设计。** 用小型、等容量的局部运动/后果读出器比较：A 单帧 DINO；B 过去约 0.5–1 秒的 DINO 特征＋轻量时序聚合；C 同时长、严格因果 clip 的 V-JEPA 特征。先冻结特征，统一 readout、训练预算与 ROI 来源，预测可见瓶位移/可见性及对象中心潜变量；保留全局特征与 q/dq。每臂加同预算的“不输入动作”预测对照，并比较复制当前与恒速外推基线。先核对 E29/E61 既有缓存是否符合因果、分辨率、身份协议，不合格的历史结果不混作本实验数据。

**判据。** 主要看留出 episode 的 moving 瓶位移误差在 h4/8/16 上是否优于恒速和无动作对照，配对区间排除零收益；静止位置误差不退化，并报告 native mask IoU、可见性分层和伪标签抽查误差。B>A 才支持观测状态不足；C>B 才支持这一视频预训练在此任务的增量价值。动作打乱敏感性只作诊断，不能单独充当正确性指标。

**结果如何改变决策。** B 有效而 C 无增益，就先采用轻量历史，不投入大模型替换；三者都不超过简单基线，优先处理时延、身份和事件覆盖，停止堆网络。只有读出测试通过，才值得把对象/关系状态接入更完整 JEPA。

**最大风险。** 遮挡与顶视几何造成不可约多解，局部伪标签误差可能压过运动收益；冻结探针不佳不能彻底否定可微调编码器。历史提升也可能只是运动外推，因此必须有恒速和无动作对照。

### 实验 3：在改策略前，检验“任务评分＋候选选择”是否有可用信号

**问题。** 是任务价值定义失败、预测误差破坏排序，还是候选集合本身没有值得选择的差异？

**设计。** 固定策略与世界模型，建立小规模盲标的真实视频事件评估集：只标可见的接近、随手搬运、释放/离手、瓶与箱关系及不确定项，不把投影重叠直接标为成功。评分器仅在 fit 标注上训练/定标，先用**真实未来观测**检验它是否识别预先定义的事件关系，再用同一批示教动作的**预测未来**替换输入，量化动力学带来的损失。测试时 scorer 只能使用因果当前信息与预测后果，真实未来只供离线评估。

随后在固定的策略 K 候选缓存上比较：单样本、动作 medoid、模型评分选择、按示教动作误差选出的 oracle-best-of-K。最后一项只能叫“模仿误差 oracle”。同时报告腕部/手指/时序多样性、分差与 episode 留出预测残差的尺度，以及弃权覆盖率。无合格现存缓存则把生成缓存明确列为以后实验执行的一部分，本次不运行。

**判据。** 第一关：真实未来上的事件排序必须显著优于阶段/时间与当前帧基线，建议预登记 pair accuracy≥.70 且 episode CI 下界>.50，仅在人工确认有可见差异的配对上计算。该阈值只是启动后续研究的工程门槛。第二关：预测未来输入保留足够排序能力。第三关：选择相对 medoid 在预登记模仿指标和有标签的事件代理上提供稳定增益，并报告 oracle 可达空间。任一前置关失败，就不做端到端想象优化；分差不足时弃权，不靠增大 K 制造表面收益。

**结果如何改变决策。** 真实未来都评不好，修任务定义/评分；真实未来好、预测未来差，修动力学；oracle 模仿增益很小，修候选生成或取消选择；所有离线关通过，只能批准后续闭环验证，不能宣布策略成功率提升。

**最大风险与硬边界。** 数据没有同一起点下每个候选的真实执行结果，以上仍不能证明候选任务优劣，更不能确认分布外动作判断。若这个缺口不能通过未来安全的真实干预数据或经验证的环境补足，结论必须停在“离线代理通过”。不把合成 jitter 自动标成失败，不用 MuJoCo 给训练或评分造标签。

E64 的等步数纯模仿控制是将来复跑想象训练的必需项，但我不会在这三个实验之前优先投入一次新的想象策略训练：首先需要知道辅助学习、运动状态和评分这三个前提是否成立。

## 七、最终立场

当前证据足以支持“E47 学到部分示教条件下的未来视觉变化”，不足以支持“E47 已具备可供规划的精细接触动力学”。最值得保留的是任务适配视觉、因果实测状态、动作序列条件和可检查的辅助头；最应放弃的假设是“潜变量可预测，就天然可用它自我评估任务价值”。

在 93 条示教和纯开环条件下，合理目标是示教邻域内、短时、对象相关、可拒绝判断的后果模型，以及强行为克隆基线。若目标坚持为可靠的分布外候选选择，最终缺的不是一个评分网络，而是能区分反事实后果的证据。
