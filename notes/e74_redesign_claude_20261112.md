# E74 重设计要求（Claude 与用户讨论结果，2026-11-12）

用户对 notes/e74_plan_astra_20261111.md 的四点意见与结论：

1. **SigLIP 可否微调**：可以，但 P0 的 reader 是针对冻结 SigLIP 特征训练的，微调后 P0 不能再整体冻结。若微调，按 π0.5 / Knowledge Insulation（arXiv 2505.23705）：动作专家梯度不进入 backbone，backbone 由自己的损失训练（FAST 离散动作损失的替代：由 backbone 特征回归前 8 步动作残差的辅助头）；SigLIP 末 2–4 block 或 LoRA，lr 约 1e-6–2e-6；加锚定损失（回到初始 pooled 图文特征）以保留图文配对。E70-S（两塔末 2 block 微调）对 E68-A 前 8 步 -1.6%（CI -6.5%~+3.2%）、32 步更差，且同时改了多项，证据不足。
2. **先不考虑 MuJoCo**：删除 5.4 节及成功率+10pp 判据；最终证据仅离线（前 8 步误差、实际选择 vs 同池均值、后果预测指标）；预算相应扣除。
3. **打分器重新设计，不要独立模块**：参考 π0.5 动作专家训练损失，以及 Unified World Models（arXiv 2504.02792，动作与未来观测在一个 transformer 内，各模态独立扩散时间步；动作时间步固定 0 为前向动力学，图像时间步固定为策略）。
4. **DINO 分支接入方式需讲清**：现方案是 DINOv2-B 前 8 block 冻结、末 4 block+norm 微调，两帧 336×560→24×40=960 token×768→线性 256；共享细节记忆 S = 每帧 12×20 池化 240 token + 双手 4×4 ROI 32 token（框来自 FK 掌心投影）=272，两帧 544 + 3 状态 token = 547。策略侧不拼进 P0 attention memory，而是在 P0 每个 flow block 后加新 cross-attention reader（query=该 block 的 32 个动作隐状态，K/V=当前帧 960 DINO token+32 ROI+2 语言 query），输出经零初始化线性层残差加入。世界头：2 层 decoder cross-attend S+动作前缀。SigLIP 仍冻结，只供 P0 原 reader。弱点：零初始化使初期几乎无梯度到 DINO；世界梯度被限为策略步长 10%。

## Claude 提出的新架构（供 astra 细化、批判、修改）

一个 π0.5 / UWM 式的联合动作专家：

```
backbone（SigLIP + DINO，部分微调）→ 观测 token
一个专家 transformer，三类 token：
  动作 token [32]（权重由 P0 初始化，损失权重 4/2/1 不变）
  后果 token（未来 DINO 全局 + 手 ROI + 关节残差，+8/+16 帧）
  进度 token（每个时域一个标量，目标来自 SOP 标注）
```

训练：全部损失均为 flow matching；每类 token 独立噪声时间步；部分样本动作干净（前向动力学模式），其余动作带噪（策略模式）。L = L_FM(动作) + λo L_FM(后果) + λp L_FM(进度)；进度目标是由 SOP 标注（place/release/failure 等）导出的标量，仅作训练目标。

梯度规则（E66 教训）：动作 token 不能读后果 token；后果 token 读动作 token 的 K/V 时 stop-gradient；后果/进度 token 使用独立权重（类似 π0 分专家）；专家梯度不进 backbone，backbone 由辅助动作回归 + SigLIP 锚定 + 小权重后果损失（受保护梯度规则）训练。

选择在同一前向内完成：(1) 采样 K=4 联合（动作、未来、进度）候选；(2) 对每个候选，把其动作钳为干净，重新去噪后果与进度 token，得到该候选自己的预测未来；(3) 分数 = 预测进度增益 − 多次噪声采样下预测未来的离散度（不需要额外头）；(4) 选最高分；分差不显著则回退均值。可选更简版：π*0.6 式 advantage 条件——加 "improving" 指示 token，训练时 20–30% 丢弃，推理时条件为 1。

## 已知风险（请正视）
- 没有反事实：进度与前向动力学模式只从示教学习，只对接近示教的候选可靠；D0（P0 上单样本 / 4 均值 / 事后最优候选）仍是前置门槛。
- 共享专家权重可能重蹈 E66，故分权重并阻断梯度。
- KI、UWM 的证据来自其他机器人设定，不保证 64 集规模下成立。
- 标注为模型生成，仅作训练目标；dev 32 段仍需独立人工标注用于评估。
- 原 640×480 高分辨率源路径已不存在，DINO 336×560 只是 192×320 的放大。
