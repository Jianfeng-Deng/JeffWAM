### 1.2 文献参照与不照搬的地方

Knowledge Insulation 的关键是：连续动作专家经 attention 读取 backbone，但其梯度不回传；backbone 另有离散动作等表征学习目标。仅 stop-gradient 而不给 backbone 监督并不是完整方案。E74 借用这个梯度结构，以短动作残差辅助回归替代 FAST；这是适配性假设，并非复现论文的离散动作/通用 VLM 共训收益。[KI 原论文 §5.1–5.2](https://arxiv.org/html/2505.23705v1)

UWM 使用动作与未来观测独立噪声时间步，以固定某一模态为干净值或纯噪声切换条件分布；论文并未提供天机候选的真实反事实奖励保证。E74 借鉴模态时间步与联合 token，采用流匹配、单向注意力和按类型分权重，主动舍弃逆动力学与完全双向共享。[UWM 原论文 §III](https://arxiv.org/html/2504.02792v2)

π0.5 的连续专家仍可用速度场平方误差和多步积分；官方 openpi 代码的时间方向/采样分布不等于 P0。本轮保持 P0 的 `x_tau=(1-tau)eps+tau*y`，tau=0噪声、tau=1干净，绝不机械照抄“动作时间步0是干净”。[官方连续动作实现](https://github.com/Physical-Intelligence/openpi/blob/main/src/openpi/models/pi0.py)

上述文献提供动机；下面的层数、损失系数、模式比例、进度定义和选择规则均是 E74 的预注册设计，不是论文已验证结论。

## 2. 最终架构、token 与梯度

### 2.1 模块图与统一接口

```text
顶视 I[t-4], I[t]；实测 q/dq；已发8条命令；因果 FK；固定操作者 L0
       │
       ├─SigLIP视觉（末2层微调）─────┬─辅助短动作头＋初始特征锚定
       ├─DINOv2-B（末4层微调）──────┤
       └─SigLIP文本（冻结）──────────┘
                 │ sg(编码器输出)，专家自己的投影仍可训练
                 ▼
   JointExpert：3个按类型路由的联合层，width256/head8/FFN1024
   ┌───────────────────────────────────────────────────────────┐
   │ A动作32token：P0原层＋零输出细节cross-attention               │
   │   只读当前观测/状态/历史；因果自注意力；不读O或P               │
   │          │ sg(A输入token前缀)，h=8仅读前8，h=16仅读前16          │
   │ O后果：每h 272视觉＋1伺服残差＋2手Cartesian token             │
   │   读观测及A前缀；不同h隔开；不读P或L0                        │
   │          │ sg(O视觉数值token)，不经进度改变世界             │
   │ P进度：当前、+8、+16，各1标量token                           │
   │   读当前视觉、L0和对应O视觉；不读原动作/q/候选ID/绝对时间       │
   └───────────────────────────────────────────────────────────┘
       │  同一step(xA,xO,xP,tauA,tauO,tauP,mode)返回三组速度
       ▼
   agent.plan(obs)：K=4动作 → 加同池均值 → 钳住动作重采O/P
                    → 内部分数/有效性 → 返回一条候选或明确弃权
```

一个 checkpoint、一个 optimizer step 的联合循环、一个 `JointExpert.layers[l]` 内注册 A/O/P 的 QKV、norm、FFN 和输出投影。类型间参数不共享；没有独立 `SemanticScore`、奖励网络、score 预训练阶段或部署外接打分 API。P 的标量是待生成的数据模态，读出仅为该 token 的速度投影。attention 可按块高效计算，无须建立全长稠密矩阵。

其推理分布按 `p(A|obs,L0) × ∏h p(O_h|obs,A[:h]) × p(P_h|obs_visual,O_h_visual,L0)` 因子化，并另生成共享的当前P_0。按h隔离是有意的近似：不宣称h8/h16生成完整、严格一致的联合轨迹。内部一致性与离散度只作保守拒绝依据。该设计是带单向读取的联合生成接口，不是原UWM完整双向联合score，也不是可由观察数据识别的 `p(O|do(A))`。收益仍需整体实验验证。

“同一前向完成”在这里准确解释为**同一模型的一次 plan 调用**；每个速度场调用内可共同计算多模态。10步动作积分、钳住动作的条件推演和最终 argmax 不可能被诚实地称为一次 Transformer 调用。为节省计算，动作阶段只计算 A；无须生成随后会丢弃的 O/P。选择阶段仍用同一个联合专家。

### 2.3 DINO 接入和 ROI/FK 修正

A在每个原P0 `ConditionalBlock` 完成后增加：

`x_l <- x_l + Z_l(Attn(Q_l LN(x_l), K_l D_A, V_l D_A))`。

Q为`[B,8,32,32]`，K/V为`[B,8,994,32]`，attention为`[B,8,32,994]`。`Z_l` 的weight/bias全零；其前级QKV正常初始化。旧201token cross-attention完全原样，不能直接把DINO拼进旧softmax，否则即使新V为零也会改变归一化，破坏第0步等价。DINO确实作为**新增专家attention的K/V**，不是只做末端动作MLP，也不与SigLIP文本直接算余弦。

DINO冻结patch embedding、前8block；微调后4block和norm。冻层可no_grad，末层不可no_grad。编码器输出在进入所有专家前detach；各专家投影和QKV仍可训练。DINO从第1步收到自己辅助动作头与特征锚定的梯度，因此零初始化只暂时阻断A新reader内部的前级梯度，**不会再让DINO等着动作门打开才学习**。不能再沿用“世界梯度最多策略梯度10%”：KI隔离后，backbone的专家动作梯度本来就是0，这个分母不成立。

ROI沿用E46低分辨率掌心框及因果历史lag=1。每帧都用该帧可得的历史实测q计算框；invalid ROI key-padding mask，invalid数值置零但不得把零当有效观测。框到DINO网格用完整像素中心变换：先复用E46裁剪/缩放链，再由192×320映射336×560，`u'=(u+0.5)*560/320-0.5`，v同理，再按patch中心映射24×40。不自行叠加lag或直接除2。

未来O视觉target的ROI始终使用**时刻t的当前框**去采未来教师网格；不使用未来真实q定位输入。全局240token补充大位移。候选FK采用candidate_command模式、无观测lag；它是理想命令几何，不等于真实执行位置。O预测实测q残差及Cartesian位移后才得到预测执行几何。FK用于状态、ROI、笛卡尔目标/一致性和关节限位；不作未标定自碰撞硬判断，不生成单目物体3D真值。

E46标定可能继承fit80与inner holdout重叠，必须保留这一历史污染说明；本轮不重标定。已有掌心投影不代表所有手指和机器人碰撞体都已校准。

### 2.4 注意力掩码与 stop-gradient

下表行是query，列是可读key/value；“sg”是数据读取保留、反向阻断。B表示编码器原始输出；状态由各专家自己的投影产生。

|Query|当前/过去B|A前缀|O_8|O_16|P|L0|
|---|---|---|---|---|---|---|
|backbone/其辅助头|自身输入；不见未来|不读|不读|不读|不读|固定文本仅锚定参照|
|A_j|sg，P0当前路线＋新细节路线|A_0…A_j，原因果mask|禁|禁|禁|仅新零输出接口；原NULL路线不改|
|O_8各token|sg，含当前/过去数值状态|sg(A_0…A_7)|同一h内全互读|禁|禁|禁|
|O_16各token|sg|sg(A_0…A_15)|禁|同一h内全互读|禁|禁|
|P_0|sg当前视觉|禁|禁|禁|仅自身|冻结文本＋P私有投影|
|P_8|sg当前视觉|禁|sg视觉272token；不得通过这些token回传O|禁|仅自身|同上|
|P_16|sg当前视觉|禁|禁|sg视觉272token|仅自身|同上|

P同样能看到对应O的tau_O，避免把高度加噪输入当确定未来；O看到tau_A。不同模态时间嵌入独立，不用一个tau覆盖全部token。P只读对应O视觉数值经自己投影的token，不读O内部hidden state、关节/Cartesian token；生成的视觉数值仍可能包含伪相关，结构不能保证因果正确。P也不读episode号、绝对帧号、SOP skill/attempt/result、候选索引或未来目标mask。

每个联合层按A→O→P计算，类型间读取在明确边界detach。**O的A键值来源固定为融合任何观测/语言之前的输入token**：`sg(W_A,in x_A + pos_A + time_A(tau_A))`，再经O自己的K/V投影；不读取A层输出。原因是A层输出已读L0，即便detach也会把语言信息带入物理推演。F/R的A_cond仅用同一输入投影/位置/时间生成干净副本，no_grad，不重跑A三层，也没有新增动作参数。O自己的K/V投影更新，A输入投影仅由L_A/trust更新。所有h仍按前缀遮罩。禁止参数别名：共享tensor storage或norm参数会绕过激活detach。

所有h之间，包括共同池化、全局norm统计、进度token和register，均不得引入跨h信息路径。无共享register。这样修改a[8:]必须不影响O_8/P_8；A本身因果也不能泄露后缀。

## 3. 数据、事实目标和 SOP 进度导出

### 3.1 数据边界

fit严格使用E66 manifest的chain A N64清单，2159个原stride8窗口；动作统计来自E71 `stats/previous.json`；H2历史尺度单独来自E71 `stats/q.json` 的第一时域sigma。评估尺度固定E66 `common_eval_stats.json`。不要把E73 history的sigma替换错误带入。

`a[t:t+32]` 对应真实记录命令，未来q/RGB在`t+h`；O关节残差以`a[t+h-1]`为锚。previous-command锚为`t-1`实际发出的命令，t=0回退实测q。history dropout不删除锚点。所有索引原样，无动作、q或标签平移。

语言仅为部署也可得的固定L0：`Put the bottles and cups into the box.`。不是每窗SOP片段文本，也不读未来阶段。冻结9不加载任何语言标注；固定操作者L0不是为评估集新增标签。

### 3.2 后果 token 的具体训练目标

只有真实tuple `(obs_t,a_demo[t:t+h],obs_[t+h])` 有监督资格。未执行候选没有未来真值；不把原示教未来绑定给扰动动作、均值或其他候选。

视觉target用**固定官方DINOv2**，取未来全图池化和当前框ROI；768→256用seed7401固定正交投影，fit64帧统计逐通道均值/方差，std下限0.01。教师及投影永不随online模型更新。O预测绝对固定空间特征，因此不要求online DINO投影与teacher天然同坐标，也不需要一个可漂移的“当前latent＋delta”接口。

q目标为实测伺服残差；Cartesian目标由同一固定FK应用于实测q生成。有效位分别按数据存在、数值有限、几何valid设置。各模态缺失独立mask，不因一个手ROI无效丢掉整个动作样本。Cartesian是机器人自身运动学衍生目标，不是物体接触或环境动力学真值。

固定视觉编码器在真实图像上的特征只是表示空间评价参照；不能把模型生成语言或预测图像当外部测试真值。最终视觉结论须与真实q/FK及独立人工进度一起解读。

### 3.3 SOP 导出：可执行的确定性规则

输入仅指定 reviewed JSON；先以episode整型join原始元数据，并检查frame_count、fps=15及`[start_frame,end_frame)`。只导出fit64；全文件有dev/holdout标注不意味着可训练它们。源hash、原segment_id、原边界、原result/failure/unknown标记必须随target追溯。

定义**记录内任务潜势代理**，不是完成概率或真实奖励。按每个episode中的同一object ID跨左右手合并对象账本；attempt只用于审计，不因重抓新建对象。最多4个固定任务对象槽位，未出现槽位贡献0，分母始终4，禁止用预测对象数或当前可见数作分母。B1/B2/B3/C1是该文件已有ID类别，U1不作确定绑定。

每对象取值v∈{0,1/3,2/3,1}，初始为“本记录尚未确认进展”0；它不声称物理世界中所有物体初始都在箱外。潜势 `p(s)=sum_j v_j(s)/4`。训练和独立人工评估都明确采用“自记录开始可确认的进展”口径；无法从记录确认初始状态时对应事实语义mask，不补想象。

事件只在原段结束边界b=`end_frame`生效：

|SOP事件|对象账本更新|不能推导什么|
|---|---|---|
|grasp/regrasp/lift/transport，result=success，known对象|若v<1，置max(v,1/3)|单凭approach或合指无进度；不因transport开始/时间增长连续加分|
|place成功|若v<1，置max(v,2/3)|place不等于释放后仍在箱中|
|release成功，且同对象最近未被失败打断的链里有place成功|置1|没有place支持的release不能当放入箱；该事件目标mask|
|result=failure、对象明确、unknown_flag=false|置0；已有其他对象积分不变|failure.type=unknown仅是不知机理，不等于结果未知；不得伪造dropped类别|
|approach、idle、retreat、adjust|不增加积分；仅继承未失效账本|这些段的result=unknown一般不代表整段视觉状态不可判断|
|unknown_flag=true；任务段result=unknown；U1；身份冲突/跨手同时矛盾|相关对象状态标unknown，相关p目标mask；直到下一条明确事件可重建该对象状态|unknown不能置失败0，也不能跨不确定区间插值补标签|

这里使用b是“段结束后才记入已完成事件”的目标语义，不改任何原始边界。b=n在episode之外，不生成越界帧，也不复制到n-1。成功对象在retreat/idle中保留；后续明确失败可扣回；已记入1的对象再抓/再释放不重复累计。一次失败后的再次成功可以增加，这是恢复进展，不是累加成功次数。

示例（文件ep0，仅用来解释导出，**ep0是dev，不进入训练**）：左手B2 grasp=[190,195)成功后，195起该对象记1/3；place=[216,228)后228起记2/3；release=[228,237)后237起记1。不能把success从190帧起贴满整个grasp段，也不能按帧号线性插值。独立人工评估绝不看这份派生值。

实现为逐episode按边界排序事件扫描；每个目标帧s只读取截至s的账本更新。但SOP本身可能用后文确认result，它仍只是离线弱监督，不是因果输入或视觉真值。`evidence_frames`与自然语言证据不直接喂模型，不再让模型重新解读文本补标签。

为训练导出每窗口：`p[3]`、`p_valid[3]`、`delta_valid[2]`、`source_segment_ids`、`mask_reason`。P损失按每个token mask；进度增量评价须同时p(t)、p(t+h)有效。路径中出现unknown/身份冲突且不能重新确定账本时，对相关终点mask；known边界跨越正常保留，不能像E72 safe-mask那样删除所有阶段转换，否则正增量会被删光。

明确缺失规则：episode24在指定文件中缺失→P三个token均无监督；保留L_A、L_O和backbone辅助动作目标。窗口未覆盖任何可确认任务状态、未来越界、未知对象、冲突映射→P局部或整窗mask。不以模型confidence设选择阈值，不自动读取其他标签版本，不用测试标签补覆盖。

导出审计必须给出63/64覆盖、各h有效数、正/零/负增量数、失败重置数、object冲突数、不同mask原因。该统计用于说明训练数据能否支撑目标，不用于扫超参或决定测试阈值。若全部可用目标恒定，属于无可学习监督的结构缺口，不能以“训练loss下降”替代。

### 3.4 为什么这不是“像示教”的评分，以及仍然不能解决什么

A的任务就是拟合示教动作；O的目标是真实记录的视觉/实测q/FK；P的目标是上述带失败回退的对象事件潜势。**P不以动作误差、似然、到示教的距离、P0分数或时间比例为标签。** 不生成随机负动作及虚假失败标签。候选偏离支持的量只作拒绝条件，不作为任务奖励。

不过SOP阶段成功与时间、机器人姿态高度相关，P仍可能学到阶段先验；无反事实数据无法证明它知道“换这个动作会怎样”。attention隔离、失败样本、固定teacher、候选条件重推演只能降低捷径风险，不能补出因果证据。若事实进度会读但同池选择不胜均值，结论必须是选择机制未成立。

## 4. 单次联合训练配方

### 4.1 三类生成损失全部为 flow matching

对任何有监督连续数据模态m：

`x_m=(1-tau_m)*eps_m+tau_m*y_m`，`u_m=y_m-eps_m`，`L_m=masked_mean ||v_m(x,tau,obs)-u_m||²`。

目标空间：A用原P0残差标准化；O视觉用固定teacher投影/fit白化；O关节用sigma_q；O Cartesian用fit实测位移尺度；P用固定有界读出参数化：`y_p=logit(0.01+0.98*p)`，推理`p_hat=sigmoid(y_hat_p)`；0.01是预注册端点平滑常数，不由标签分位或测试拟合。这样零进度/满进度仍有有限FM目标，避免线性标量在0附近数值越界就大量误回退。不根据标签频率标准化；人工评价对原始p报告MAE并说明最大0.01的端点平滑偏差。所有teacher/label/尺度均detach。

- `L_A`严格用P0逐54维均值，再时域w=[4×8,2×8,1×16]加权，除以64；**不要擅自改为训练时四组等权**。四组等权是评估primary的定义。
- `L_O = 0.5 L_global + 0.5 L_ROI + 1.0 L_servo + 0.1 L_cart`。每项先按有效token/维度均值，h权重(2/3,1/3)；q按A7/B7/L20/R20四组等权，Cartesian按左右手等权。无ROI有效项时该项为0并报告有效覆盖，不把global系数翻倍。
- `L_P`对当前、+8、+16三个有效标量token的FM误差分别归一后等权；分母为有效样本数，完全无标注时为0。它不向O/A/B传梯度。不额外加成功分类、排序、奖励或advantage损失。
- `L_trust=mean_{w,54} ||v_A-v_P0_frozen||²`，同一obs、历史扰动、x_A/tau_A；P0参照始终使用初始冻结SigLIP和NULL路线。只作训练正则，不作候选分数或测试真值。

**专家目标**：`L_expert = L_A + 0.05 L_trust + 0.5 L_O + 0.2 L_P`。

P0的原优化目标、噪声和采样保留；新增0.05 trust及旧参数低学习率是明示的迁移保护，不声称与P0继续训练完全同轨迹。O/P系数不影响A，因为参数和梯度隔离。各组独立clip norm=1，不能以全模型clip让巨大O损失缩小A更新。

### 4.2 Backbone 的独立监督

B有两套仅训练用的短动作辅助头：各自用8个学习query cross-attend该视觉塔的当前patch/ROI（SigLIP用原patch、DINO用当前池化/ROI），加自己投影的q/dq/geo66/H2，以小2层decoder输出`[B,8,54]`。辅助头不与A reader共享权重，target为同一P0标准化真实前8步残差。

`L_aux,S=MSE(head_S(B_S,state), y_A[:8])`；DINO同理；每维均值，权重各1。辅助头不能读noisy action、O、P、未来图或SOP。DINO历史帧仅作O条件；辅助动作头固定当前帧，避免另改P0历史路线。

SigLIP初始特征为g0/patch0，在线为g/patch：

`L_anchor,S = E||normalize(g)-normalize(g0)||² + 0.25 E_patch||normalize(patch)-normalize(patch0)||² + 0.25 E_j(cos(g,text_j)-cos(g0,text_j))²`。

text_j为冻结配对文本塔对固定L0及fit训练规范文本的编码；集合在训练前冻结，不包含评估集语言标签。冻结文本塔本身无需“文本漂移损失”，它恒为0。原生pooling head权重冻结但保留到视觉末层的梯度。patch锚定是必要补充：仅pool相似并不能保护P0读的196patch。

`L_anchor,D = MSE(normalize(R^T D_online), normalize(R^T D_initial))`，在当前图固定投影空间计算；R是视觉target的固定正交矩阵，不是可训练投影。先各token归一，再均值；ROI和全图各半。

**B目标**：`L_B = L_aux,S + L_aux,D + 1.0 L_anchor,S + 0.1 L_anchor,D`。每个辅助头只连自己的塔；状态输入是实测固定值。所有专家损失到B为0；L_B到A/O/P为0。没有world→B的小权重旁路。

“三模态全FM”指A/O/P三个生成任务；backbone的辅助回归和预训练锚定是独立表征损失，确实不是FM。不能为了字面“所有loss都FM”取消KI必须的backbone监督，也不能把辅助回归冒称FAST原配方。

### 4.3 时间步与模式比例：不减少 P0 的动作更新

每个有效batch16均保留**16条原P0 noised A_FM**，噪声采样顺序和logit-normal tau逐样本沿用E72。O/P在同16条记录上分配8/4/4，共3模式：

|模式|比例|给O看的A|O数据/tau_O|P数据/tau_P|训练项|
|---|---:|---|---|---|---|
|J 联合带噪|50%=8条|同条A_FM输入token（融合语言前），sg|真实O各h独立加噪；tau_O~U(0,1)|各标量独立加噪；tau_P~U(0,1)|A、O、有效P|
|F 前向动力学|25%=4条|A_cond：真实动作钳干净，tau_A=1，sg|同上；h8/h16独立采样|同上|A_FM仍训练；另算O、有效P|
|R 后果语义读取|25%=4条|同F；需要时可省掉不被读取的A_cond计算|真实O视觉钳干净，tau_O=1；O loss=0|独立tau_P~U(0,1)|A_FM仍训练；有效P|

所有tau取样只用自身RNG；模态间、h之间、P当前与未来之间均独立（模式要求的干净钳制除外）。eps均独立标准高斯。P的输入K/V取**对应O视觉数值token经P自己的投影**，不取混入动作信息的O内部hidden state；R模式因此可以直接用固定真实teacher token。P读取tau_O的条件嵌入；O读取tau_A。这样在干净O条件下，P只能从可见后果表征判断进度，不能偷读动作隐状态。

F/R中只是在同一次联合调用内增加A_cond读路径；A_FM输出仍对全部16条样本产生L_A，不能把25%或50%的记录换成干净动作后，让A训练量少一截。O损失按J/F的有效样本数归一，不乘重复A样本数；P按全batch有效标签归一。mode在每个update按专用seed打乱8/4/4，与标签/结果无关；不按成功或高进度重采样动作数据。

未来target的valid仅控制loss；不将由未来遮挡/标签决定的mask交给当前策略。目标缺失时相应token填独立噪声、无该项loss；固定mask只来自当下可知的ROI有效性和结构因果约束。不存在把unknown标成0成功率的分支。

### 4.4 优化器、样本与缓存

- 一个seed6601；一个训练运行；5400联合optimizer updates；effective batch16=micro4×accum4，86400条动作曝光，原2159窗口约40轮。使用原PairedSampler、fixed stride8，不引入R2随机起点。
- 沿用history dropout0.1、0.003rad噪声，锚点保留；原训练模式/无图像随机裁剪不变。固定L0，不新增阶段预测条件；不保留无作用的subtask CE头优化。
- AdamW，betas=(0.9,0.999)、eps=1e-8、weight_decay=1e-4；所有峰值lr见参数表，统一`0.5*(1+cos(pi*s/5400))`；无单独world预训练，无另一个score优化阶段，无学习率/系数搜索。
- A/B/O/P各自梯度clip=1。所有parameter-id只属于一个参数组；loss可同一反向累积，显式detach保证隔离。最后update才step一次，不每micro各step。
- BF16 autocast，速度场误差/积分/标准化/损失累积FP32。原冻结层eval，trainable塔末层可用gradient checkpointing；不修改已验证预处理。
- 固定SigLIP初始patch/global、固定DINO target投影可以缓存。不能缓存可训练末层输出跨update复用。需要teacher的ROI从完整固定网格按当前框采样，不能缓存成“未来自己的手框”。
- 原始全库27281帧的DINO 960×256 FP16约13.41GB十进制；SigLIP 197×768 FP16约8.25GB；全库上界合计约21.7GB，实际只缓存fit和所需dev，评估按需即时算。目标白化统计仅fit。缓存key含图像、预处理、teacher权重、固定投影及split hash。
- 每100步及信号原子保存model、optimizer、scheduler、所有RNG、sampler位置、各模式计数、累积GPU秒、协议/代码/输入hash。恢复不得重置预算或改变P0动作噪声流。

### 4.5 第0步等价与迁移验收

必须在任何optimizer.step前用真实P0路径检查：

1. 载入 `runs/e72_transition_jepa_20261111/units/P0/step5400.pt`；旧有效参数逐键完整映射，dtype/shape/norm/位置/NULL手reader/AdaLN一致；允许缺失的只有预注册新增参数。不要用`strict=False`掩盖旧参数漏载。
2. SigLIP末层虽requires_grad=True，初值必须与原塔一致；不能保留E72 `set_phase()`强制冻结塔，也不能保留包裹整个vision的no_grad。旧文本/子任务组件的非持久buffer需按原vocab恢复，不让新增语言表改变NULL路线。
3. 所有新增A残差Z严格0；不向旧memory拼token；O/P无路径回到A。相同图、q/dq/geo、history/anchor、四个固定noise，逐层比较velocity、10步结果、绝对rad命令、四均值。
4. 首帧、历史不足、常规帧、ROI invalid、history dropout、含明显运动的真实窗口都覆盖。FP32要求max绝对命令差≤1e-6 rad；BF16逐样本路径优先bitwise相同，批量kernel差异仅允许max≤1e-3 rad且dev primary相对差≤0.2%。若超过，修数值/迁移路径，不能扩大容差放行。
5. 第0步`plan`强制评分未训练状态→同池均值，输出与P0四均值相同；不声称随机初始化O/P等价P0。900步之后评估实际固定规则选择，不能根据性能手动打开/关闭选择。
6. teacher固定权重hash与原P0一致；online和teacher无storage别名。单独对L_A、L_O、L_P、L_B反向，验证参数路由：L_A不到B/O/P，L_O不到A/B/P，L_P不到A/B/O，L_B不到专家。独立实验式性能消融不需要，梯度验收必须做。
7. 初始冻结塔/teacher参数buffer不变；允许训练的旧P0参数从第1步起变化属预期，不能沿用旧“P0 hash永久不变”的错误断言。

## 5. 推理、内部分数与回退

### 5.1 一次 plan 的真实计算路径

**步骤A：** 当前观测只编码一次。固定四独立动作噪声，原10步Euler从tau_A=0到1得到4条32×54候选。加入逐元素动作均值a_mean，得到5条；均值合法性独立检查。没有先16次选再平均、没有roll noise充当独立噪声、没有对候选再优化。

**步骤O：** 把5条完整候选钳为干净A（tau_A=1），生成并缓存干净A_cond输入token的O私有前缀K/V（无L0）。每条候选以3套O噪声、10步Euler分别生成h8/h16的视觉、伺服残差和Cartesian后果。5×3并行；h8仅看前8，h16仅看前16。不用步骤A中随动作演化的草稿未来作最终评分。

**步骤P：** 对每份生成后果钳住O视觉（tau_O=1），再用P自身10步Euler条件采样P_8/P_16。P_0在当前观测上生成3份，所有候选共用同一组；不能候选各自编一个更低的当前进度抬高增益。不同候选使用相同的O/P噪声编号作为common random numbers，减少比较随机性；不同重复m仍独立。

采用O→P的条件顺序是有意的：P在最后真正读取已生成的干净未来，而不是与O同时结束时仍在评分过时的噪声状态。训练R模式正对应此接口。不增加第二个网络，只多一段同模型的P积分。

总计：10个A速度场调用＋10个O调用＋10个P调用；A_cond输入投影及O前缀K/V在候选钳住后一次计算、复用，无额外A三层调用；编码器一次。F/R训练与此条件接口一致。任何“单forward时延”都必须写清指速度场step还是完整plan；本方案只以完整plan时延验收。

返回`chosen_index`、所选原候选命令、raw4/mean及分数、预测后果统计、有效性/回退原因、每阶段耗时。返回的动作必须精确等于5条中的一条；不裁剪、平移、事后平滑或拼接四肢后沿用旧预测分数。

### 5.2 具体分数公式

生成标量以`p_hat=sigmoid(y_hat_p)`读出，下文p均指此有界估计。检查原始y_hat和关节重构均finite；非有限候选不可参与任务选择。读出无硬截断、始终在[0,1]；高logit仍可能错误饱和，因此记录饱和分布且不能把有界误当校准。这里没有可由模型预测的对象数分母。训练端点平滑使理想Δp缩放0.98，所有候选与mean同口径比较，不按测试数据补偿。

对候选k、重复m：

`G[k,m]=(2/3)*(p[k,m,8]-p0[m])+(1/3)*(p[k,m,16]-p0[m])`。

定义 `muG_k=mean_m G[k,m]`，`sdG_k=sample_std_m G[k,m]`。

`sdZ_k`：在fit白化的预测O视觉空间，计算3份样本的逐维标准差，先各ROI/global均值，再以各半、h权重(2/3,1/3)汇总，最后截到[0,1]。这是输出分散程度，不是已校准的epistemic置信区间。

`C_k`：O直接生成的掌心/指尖位移与`FK(qhat_h)-FK(q_t)`的归一化均方根差；尺度同训练Cartesian尺度，均值后截到[0,1]。它只检查内部几何一致性，不冒充与真实未执行结果一致。

`R_k`：前16条命令的二阶差分RMS，按fit真实命令同口径的95%分位归一并截到[0,1]；跨chunk首两项使用真实历史命令。分位只来自真实命令，不来自语言标签。

固定不搜索：

`U_k = sdG_k + 0.02*sdZ_k + 0.02*C_k`

`S_k = muG_k - U_k - 0.02*R_k`。

候选mean也必须完整计算同样的S/U，不能用四个raw分数均值冒充均值动作的预测。内部选择：

`k*=argmax_{k in eligible} S_k`；只有

`k*!=mean` 且 `S_k* - S_mean > 0.05 + U_k* + U_mean`

时选择k*，否则输出合法mean。并列按固定最低索引，不能看真实动作打破平局。0.05及各系数是本方案预先固定的工程保守常数，**不是SOP预测标签的分位数、最佳分类阈值或dev调参结果**。它可能过于保守，本轮不调宽求显著。

### 5.3 支持检查与回退顺序

1. 5条动作先检查全32步finite与配置中的关节限位（仅1e-5 rad数值容差）；不做自碰撞判断。生成q后也检查finite/限位。
2. fit真实数据固定99.5%分位定义每组的q标准化范数、dq范数、相对实测q的前16命令增量范数、命令一阶差分范数；仅用真实数据及既有尺度。超任一支持界的raw候选不参与任务argmax；只拒绝明显外推，绝不称为覆盖保证。动作支持得分不加到S里。
3. 当输入超支持、ROI全失效、O/P原始输出非有限、无可信分差、输出高度分散（`sdG>0.10`，固定工程界）时回退**数值和限位合法的同池均值**。均值回退表示放弃新选择机制，不表示获得了安全认证。ROI局部失效只遮该手；两手全无效才禁用语义选择。
4. mean本身非法或非有限时，离线记录为规划无效/弃权；不擅自替换成某个高分raw、实测q保持或旧chunk并当正常输出。所有这些异常进入失败率分母，不能删窗口。发生硬异常立即触发实验止损与审查。
5. 不在每窗临时运行P0救分。整体非劣门槛不通过时，最终决策退回已验证P0模型并报告E74失败；E74所报离线指标仍包含它自身全部回退/异常。

### 5.4 防奖励投机的明确边界

- P不能改A/O/backbone；O不能改A/backbone；没有score-gradient搜索、best-of-K反传、强化学习或用自身预测自举标签。
- P读的是O的**视觉数值token**，不读O内部隐藏的动作编码、q残差、候选编号；O不读L0/P，不能因目标文字直接生成“完成”未来。
- 固定teacher阻止在线后果目标与P共同塌缩；当前P在候选间共享；固定分母阻止预测少对象提高进度。
- 有界进度、分散度、支持域、内部FK一致性和均值回退只能防部分漏洞。同一模型可能一致且自信地预测错误，M=3噪声离散度不能检测共同偏差，不能标为可靠置信下界。
- 固定L0且所有任务相近，不能凭该实验宣称一般语言理解。未来SOP确认还可能造成“看不见却能学标签”的目标噪声；独立人工unknown率必须报告。

### 5.5 时延预算

仅离线计时，不运行控制器。预算目标为单观测B=1完整plan p95≤200ms、p99≤266.7ms，参考未来4帧/15Hz前缀所需的规划周期；这不是本次已测速度，也不是闭环验证要求。

预分配的p95工程预算：两帧DINO＋当前SigLIP/ROI 65ms；4候选A10步30ms；5×3候选O10步70ms；P10步20ms；FK/拷贝/选择/同步15ms，共200ms。目标偏紧，必须真实profile。文本固定可缓存；实际观测视觉不得用评估特征缓存替代在线编码计时。上一个真实历史图的可复用编码只能在明确时间戳匹配时缓存，同时报告冷/热两种延迟。

计入CUDA同步、所有候选、全部重复和回退路径；分别报p50/p95/p99、峰值显存及冷启动。超时可判当前实现不具备拟定实时预算，不能删除O/P步骤、减K/M/Euler或改prefix后仍称原协议通过；离线科学指标可单独报告，不能冒充已具备部署能力。

### 6.3 唯一主实验 E74-v2-Joint

全部配置、输入/权重hash、人工32段清单、损失及阈值在开训前锁定。一个seed6601，从P0第0步迁移，5400更新。冒烟权重丢弃，正式从同一迁移初值重新起步；冒烟不作为可选checkpoint。

固定检查：0步等价；900、1800、3600、5400步用同一dev列表评价A四均值、一次实际selected、同池oracle、真实记录动作后果。它们是同模型同bank统计，不是新训练对照臂。最终只评价5400 checkpoint；提前停止的中间checkpoint仅标partial/failed，不选dev最好一步当正式结果。

**A. 动作性能底线（必须先过）**

E74 raw4均值相对P0 raw4均值，dense holdout前8步退化点估计≤2%；宣称非劣要求相对退化95%CI上界也≤2%。仅“差异不显著”不够。以旧汇总数作阅读参考，绝对上限约0.479056，正式计算仍以配对窗口原始记录为准。

四组前8步及32步rad RMSE分别报告，点估计均不得退化>2%；其中区间跨非劣界则标该项未决。抖动、关节限位、FK误差完整列出，不能仅以综合primary遮住一只手退化。frozen9同样报告相对P0的非劣区间，若明显反向则不能称整体稳健。

**B. 实际内部选择收益**

最终selected（含mean回退）相对P0均值前8步下降≥5%且配对95%CI上界<0，参考值约0.446180；同时相对**本模型同一候选池均值**下降≥3%且CI上界<0，才能称离线选择收益成立。P0基线与本模型均值分别列出，分清策略适配和内部选择的贡献。

实际偏离mean比例须≥5%才能称选择机制被有效使用；不足则报告模型主要靠mean。所有窗口一起算主指标，不只算被接受子集；另报选择率、每种fallback率、实际选中raw索引、分差、oracle gap、约束异常率。更像示教只能称离线动作误差改善，不能推导任务完成率提高。

**C. 真实记录动作的后果预测**

用a_demo钳干净，O/P推理路径与候选完全相同；评价固定3样本的预测均值及分散度。O的多样本均值是后果预测估计，不改变动作selected口径。

- h8为主要后果时域，h16次要。分别报告全局与当前手ROI固定DINO特征误差；ROI目标相对复制当前下降≥10%，配对区间支持方向，h16不明显恶化。复制基线用同一固定target空间/当前固定框，不能在线特征空间错配。
- 实测q的rad RMSE要优于直接末条命令`a[t+h-1]`和状态保持；直接命令是强基线，不能只赢copy q就称理解动力学。
- Cartesian预测对`FK(q_real_future)-FK(q_real_now)`报米误差，另报与自身qhat的几何一致性；它们都不是物体接触成功指标。
- P见6.4独立人工结果；frozen9和holdout不评价SOP预测准确率。未来预测只与记录动作的真实未来比，不拿生成候选与同一条示教未来算“候选预测正确率”。
- 不用模型生成的对象mask、语言result或模型自评分作最终真值；可展示真实顶视与对应固定框。固定视觉特征指标是辅助表示指标，不替代独立事实评价。

**总判定**：A过而B不过=守住动作但选择未证实；B过而A不过=整体失败；A/B过但C不支持=离线动作收益有迹象、后果机制未证实；全部支持才称“单种子离线联合模型证据支持”。预算未完成、人工变化太少、CI太宽均标未决。没有任何仿真或成功率补充判据。

### 6.4 dev 32段独立人工标注如何用

开训前固定每dev episode 8个anchor：在可用dense窗口中按时间等距取8个，重复位置去重后按固定顺序补齐；查看t-4至t+16顶视片段，必要时看该记录前缀确认对象身份和先前进展。清单仅由时间/原始可用帧决定，不按SOP结果、模型分数、成功预测或D0误差选“有趣片段”。32段来自4个episode，不能称32个独立轨迹样本。

标注者只看真实顶视及固定任务说明，**不看SOP、模型预测、候选动作、分数或旧评审备注**。逐对象标当前/+8/+16可见关系：尚无明确共动、明确随手移动、明确放到箱区域但未确认释放、释放后可见留在箱中；身份不明/遮挡/仅2D重叠而不能确认则unknown。另记录明确失败/回退。按3.3同一固定对象潜势规则转换，但事实与时间来自独立观看，不从SOP端点复制。保留人工原始事实，不能只留下转换后的标量。

建议两人盲标或一人标注、一人独立复核全部32段；分歧只回看真实视频裁定，无法裁定保持unknown。预计总计2–4人工小时；若需要更长前缀则如实记录，不挤进GPU时间。用户未提供标注时，未来实施需准备这项数据，不能由模型代做人类标注。

## 9. 一页摘要

**最终方案。** SigLIP视觉末2block＋post-LN以1e-6微调，文本塔和其余视觉冻结；DINOv2前8层冻、后4层＋norm以1e-5微调。编码器由各自前8步动作辅助回归和初始特征锚定学习，所有专家梯度严格止于backbone输出。不是彻底冻结P0，也不是让连续动作损失直接更新视觉塔。

**P0保护。** 从现成E72 P0 step5400逐键初始化全部有效动作组件，旧参数以3e-5适配；原H2/previous锚、stride8、440维历史、NULL reader/AdaLN、3层causal Flow、logit-normal tau、4/2/1、10步Euler不变。新DINO cross-attention读992视觉＋2语言K/V，零输出残差确保第0步精确等价；固定P0教师加0.05速度一致性正则。训练后仍必须用非劣检验守住底线。

**统一模型。** 3个联合层内按类型分权重：A32动作token，O每h=272视觉＋1伺服残差＋2手Cartesian token（h8/16），P当前/+8/+16共3标量token。三类生成损失均FM，时间步独立。A不读O/P，O读融合语言前的sg(A输入前缀)，P只读sg(O视觉数值)和当前视觉/L0；没有独立scorer、奖励网络或score训练阶段。backbone辅助回归/锚定是明确的非FM表征损失。

**训练。** 一个seed6601、一次5400更新、batch16=4×4；每条记录保留原动作FM，O/P模式比例50%联合带噪、25%干净动作动力学、25%干净后果语义读取。专家总损失`L_A+.05L_trust+.5L_O+.2L_P`。只用fit64；指定SOP覆盖63集，ep24进度全mask但仍训练动作/后果。SOP由对象事件账本导出可增可减的潜势，不按时间插值，不用示教距离，不给未执行候选贴未来标签。

**选择。** 一次plan内10步生成4条动作＋同池均值，干净钳住5候选后用3套噪声10步生成O，再10步条件生成P。共30次分模态速度场调用，不虚称一次Transformer前向。分数为加权预测进度增量减采样离散度、FK内部不一致和小平滑惩罚；仅合法、在支持域且胜mean超过固定保守门槛才选择raw，否则合法mean回退。mean非法明确弃权。无候选优化、无奖励反传、无自碰撞硬判。

**数据可信度。** SOP虽accepted仍是模型生成，只用于训练；不用于测试真值、阈值或选型。dev32段在原始顶视上独立人工盲标，训练中密封，最终只评价真实记录动作的进度预测。holdout16/frozen9无新增语言标签；冻结视觉特征只是表示指标，实测q/FK和独立人工事实另列。无反事实就不声称已校准的真实候选奖励或任务成功率。
