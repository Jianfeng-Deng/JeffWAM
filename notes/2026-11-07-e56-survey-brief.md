## 我们的现状（必须先读）
- 目标：propose → predict → score → select → replan。天机双臂，瓶子放入箱，无腕部相机，93 条示教；最终在真机验证；MuJoCo 只做最终验证；评分器在模型内部。
- 策略：run E（DINOv2-B 微调 + flow 动作头 + 1 s 关节历史），可采样多个动作。
- 世界模型：E33-B，动作条件的 latent 预测器（token 网格，h16/h32）。
- 已有结论（读 W/runs/e53_head_diag/REPORT.md、W/runs/e55_v2/REPORT.md、W/runs/e55_v2b/REPORT.md）：
  1. 只用示教标签训练的事件分类评分头（B1）失败，退化为阶段检测器。
  2. 免训练目标距离评分（最近邻示教未来）：demo>hold 0.92、>reverse 0.81、>shuffled 0.71；分数与任务进度不单调。
  3. 预言机（预测未来对真实未来）对 jitter 0.05/0.10/0.20 只有 0.53/0.74/0.96；评分器为 0.49/0.52/0.64。小动作差异低于预测器分辨率；较大差异评分器损失明显。
  4. 物体中心表示（手 ROI + 目标瓶 mask 池化）比全局池化更差，缺失多。
  5. 没有失败/成功的闭环数据；数据只有示教。
- 用户偏好：只针对本任务本机器人，不直接用别家权重（可借鉴框架思想并复现）；正运动学手部几何可作输入；SAM3 可用；喜欢预训练动力学先验、潜动作方向；不希望持续人工标注。

## 调研问题
1. 只有示教数据（无奖励、无失败样本）时，世界模型规划/候选选择的评分方式有哪些？例如：目标图像/latent 距离（DINO-WM、V-JEPA 2-AC、PlaNet/Dreamer 类）、学习价值/进度函数（时间对比、TCN、VIP、LIV、GVL、Rank2Reward 等）、基于示教的能量/密度模型（IBC、Diffusion/flow 策略似然）、逆强化学习、对比式能量、离线 RL（IQL 等只用示教时的退化问题）。
2. 策略采样 + 价值重排序 / 验证器的方法（V-GPS、Policy-as-verifier、best-of-N、RoboMonkey、world-model-in-the-loop 重排序、Generative value learning 等），它们的评估口径和真实收益。
3. 如何获得“反事实负例”：合成扰动、时间打乱、自主 rollouts、失败恢复数据、DAgger、少量真机自评。
4. 当世界模型分辨率不足以区分细小动作差异时，文献怎么处理：分层（世界模型只做粗选，策略做细节）、短时域 + 重规划、几何/关键点代价、物体中心（slot、关键点、粒子）表示、潜动作空间规划。
5. 2024–2026 年具身世界模型做动作选择的最新工作（含视频生成世界模型 + 验证器、WAM / world-action model），以及它们在真机上是否确实优于纯策略。
