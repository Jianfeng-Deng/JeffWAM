## 1. A2 与 flow 实现差异（代码审阅）

- A2 的输入为同一视觉/文本 observation tokens、当前 `q_normalized` state token，以及额外 164D 因果本体特征（当前 q、−24/−18/−12/−6 的 q 差、FK18 历史差、valid flags）；`proprio_proj(164→256→256)` 加到 state token。action chunk 为 50×14；A2 从 t=0、零噪声 action token 做一次前向，输出 12 维规范化 Δq，经逐维 `action_std` 还原并加 `q_current`。两夹爪用同一次前向的 2-logit BCE 状态头，最后按冻结训练集阈值/开合值离散化。
- A2 联合目标保留 12 关节 flow 辅助损失，时间权重前10步×4、中15步×2、后25步×1，权重1；Δq MSE 同权重1；gripper BCE 权重1，不做切换重加权。世界项为 `.1*(world + .1*cos + .1*adapter + chain_weight*chain)`，对比对齐项 `.01`。本轮 D/F 预注册只重训动作路径参数，目标层只保留确定性 Δq 或 flow Δq，加共同 gripper BCE；不训练世界目标，也不改变夹爪监督。
- 旧 E99-W2 flow 将 50×14 噪声与目标在归一化坐标直线插值，以 `y−eps` 作速度目标，Euler 从 t=0 积分到1；本轮 F 限定为 12 关节，复用 A2 `proprio_proj/state/action` 条件接口和 delta 输出层。两组的模型、数据路径、视觉 tokens、状态历史和 BCE 目标相同；部署主读法锁定为 F 单样本、4 Euler 步。
- 指定 E106C 检查点 CPU 审计：`step=20000`，权重185项，含 `state_proj/action_proj/action_head/grip_head/proprio_proj/delta_head`，与旧代码当前文件呈现的 A2 结构有历史版本差异；未改动原代码或检查点。检查点后续必须用 A2 原模型严格加载审计作为启动门槛。
