# 完整策略组装方案（设计稿，未实施）— 2026-11-17
## 现有零件（均已单独评估）
- 视觉：冻结 SigLIP2，3相机，2×4 token，历史偏移 -24/-18/-12/-6/0。
- 世界头 W：+10/+25/+50/+100 未来 token，可选条件 gt_action / pred / no_traj；默认 E106-C 20000步。
- 动作头 A：确定性 Δq 50步 + 夹爪开合 BCE，输入因果 q/FK 历史（A2 路径）。
- 阶段控制器 S：谓词头(H0/H1, CF标签, 宏AUROC≈.91) → 校准 → softmax发射 → 在线 HMM（合法转移+最短停留）；边界召回@±90帧 ≈ .73。
## 目标结构（每个控制步 t，全部因果）
1) 观测 → token 与本体历史；2) S 输出阶段后验 s_t（10维）与谓词概率；3) A 读 token+本体历史+s_t → 50步动作块；4) W 读动作块 → 预测未来 token；5) 评分器（模型内部）把谓词探针作用在预测 token 上，得“进展分”（下一阶段谓词是否趋于成立），用于诊断/可选择候选；6) 阶段滤波器用真实新观测更新。
## 分期（先便宜后昂贵，每期有预注册判据）
P0 接口审计（CPU）：确认各模块输入输出张量、时间对齐、因果性（扰动测试），S 的 OOF 滤波后验可用于训练（五折袋外，避免泄漏）。
P1 阶段条件动作头：A2(无阶段) vs +阶段后验(OOF滤波，训练即用带噪声的真实滤波输出) vs +oracle阶段(上界)。指标：关节L1(前8/H50)、夹爪F1@±90帧/状态准确率；27 parent，parent配对bootstrap。通过：关节L1改善CI>0 或夹爪事件改善CI>0，且另一项非劣。约1–2 GPUh。
P2 进展评分器检验（CPU/小GPU）：谓词探针在“预测 token”上的AUROC vs 在“真实未来 token”上的AUROC（用E98-C因果标签训练、dev因果标签评估），+25/+50；并检验进展分是否随真实阶段推进单调上升。
P3 语言对齐探针（用户要求必需）：阶段/谓词的文本描述（SigLIP文本塔）与图像 token 的对齐，零样本阶段识别准确率与线性探针对比；通过后才把阶段文本/子目标文本作为条件。
P4 离线闭环回放：在 dev parent 上按时间回放，逐步“阶段→动作→世界预测→评分→阶段更新”，报告动作误差、阶段一致性(±90帧)、进展分单调性、两跳预测漂移；不接任何仿真。
P5 最终验证：MuJoCo 仅用于最终策略验证（项目约定，不用于训练，不用仿真数据）；是否具备仿真资产与接口待确认。真机不在范围。
## 关键设计选择与建议
- 阶段输入用软后验(10维)而非argmax：边界±3秒不确定，软后验更稳；训练用OOF滤波输出以匹配部署噪声。
- 候选生成：flow/多样本均已塌缩，故首版不做候选选择，评分器只做诊断与可选重排；等有可用的多样性来源再启用。
- 夹爪事件弱项（F1≈.25@±10）：评估口径改为±90帧并保留±10诊断；阶段条件可能改善，由P1检验。
- 数据：dev阶段真值仍是模型回顾式标签；人工4片段仅作口径校准；不得用模型语言做dev真值。
## 风险
阶段滤波在边界附近抖动传入动作头；预测 token 收缩(方差比.72–.86)使探针AUROC下降；两跳预测漂移7–8%；dev事件与parent太少，多数差异CI跨0；Codex周额度受限（本轮实验尽量自己跑）。
## 预算（估）
P0 约0.5h人工；P1 1–2 GPUh；P2 ≤0.3 GPUh；P3 ≤0.3 GPUh；P4 CPU为主。

## P2 结果（2026-11-17，Claude 直接执行）进展评分器：谓词探针/阶段发射作用在世界头预测 token 上
方法：E106-C 20000 世界头预测未来特征（预测残差×尺度+当前=原始特征），按相机池化(3×8均值，2304维)；已验证池化后真实未来特征与 E102-S 逐帧 b 特征相关1.0000、最大差≤0.007（帧对齐 anchor+h 正确）。探针=CF H0 谓词头+CF发射(逐帧argmax，无HMM)。160窗/20 parent，h∈{10,25,50,100}；条件：real(真实未来token，上限)、cur(复制当前)、gt(真实动作)、n1(预测动作)、no(无轨迹)、sh(错配动作=批内roll)。parent配对bootstrap 2000, seed90。
结果：①谓词概率与真实未来token的相关(+25/+50/+100)：cur .796/.720/.621；gt .844/.801/.748；n1 .835/.787/.728；no .822/.776/.713；sh .781/.703/.605。gt−cur +.048/+.081/+.127（CI>0）；sh−cur ≤0。②与真实未来token的阶段一致率(+50)：cur .644，gt .731，n1 .731，no .719，sh .581。③阶段准确率(对原回顾式真值)：+50 cur .375→gt .487(+.112 [.044,.175])；+100 cur .294→gt .487(+.194 [.112,.281])；real(上限)仅 .45–.51（逐帧、无HMM、真值带噪）。④阶段发生变化的窗口(n=9/21/28/63，CI宽)：+100 gt .381 vs cur .127。
结论：世界头预测的未来特征确实携带“任务进展”信息，长时域(+50/+100)显著优于复制当前；真实动作>预测动作>无轨迹>错配动作，错配动作使进展信息降到复制基线以下 → 评分器对动作有区分力（能分辨对/错动作；细微候选间区分未检验）。局限：真值为模型回顾式标签；逐帧阶段上限仅≈.5；变化窗口很少；单种子。
