# E117-D：学习式语言对齐方案
- 日期：2026-11-17 BRT。设计完成，未训练，GPUh=0；仅使用 Piper 和本地 SigLIP2，不下载模型。
- 目标路径开工前确认不存在：`/mnt/workspace/dengjianfeng/code/lewm_tianji_cpu/notes/e117_learned_alignment_design_2026-11-17.md`。

## 1. 目标和检验定义
E116-P3 原始 SigLIP2 阶段 top-1=.036 [.030,.041]（随机=.10）、谓词宏 AUROC=.520 [.486,.584]；监督参照 CF H0 阶段 top-1=.621、AUROC=.908。原图文空间不适配，需在任务数据上学习；训练标签是模型生成，不能据此宣称自然语言真值。

|级别|目标|对齐成立定义|
|---|---|---|
|L1 语言—图像/进展|SigLIP2 多视角 token、池化/预测进展特征 ↔ 阶段/谓词文字|parent 持出且整句改写持出时，阶段 top-1、macro-F1、谓词 macro AUROC 优于随机和原始 P3；跨语言、持出谓词、组合描述有迁移，不能只记模板/ID。|
|L2 语言—动作|阶段/子目标文字 ↔ 50 步动作块/轨迹片段|未见 parent 检索匹配片段 R@K/MRR 优于均衡随机、频率先验、置乱配对；持出描述仍有效。时间索引伪配对只能称伪配对检索。|
|L3 语言条件|文本向量/token 条件化世界头；动作头另议|正确条件改善持出描述下未来 token/进展预测，错配条件无同样收益，世界指标非劣。|

**策略限制：**E115-P1 阶段信息进入动作头无可测收益，P1 要求阶段信息不进动作头。L3 首轮只条件化世界头；L2 只离线检索。阶段文字进动作头需用户先修改 P1。

## 2. 方法候选与推荐
|方法|输入输出/损失|可训练参数估计|数据/复杂度|
|---|---|---:|---|
|A 冻结双塔+视觉投影（推荐）|冻结 SigLIP2 文本塔阶段/谓词嵌入；视觉池化或进展向量投影至 d=256。多正例 InfoNCE/sigmoid 对比。阶段同义描述为多正例；谓词只对有效 yes/no 对比，unknown 不作负例。|视觉线性/两层 MLP 约0.2–0.6M，学习温度|E102-S 五折 train parents，E98-C 最多4410时刻×21谓词，31条中英锚点。低复杂度，先 CPU/小GPU。|
|B 文本侧小适配器|A 的空间，文本塔末层 LoRA/低秩 adapter；对比损失+正则。|约0.1–1M，rank4–8；不解冻全塔|同 A，文本极少，须整句族持出。中复杂度，仅当 A 改写泛化不足时试。|
|C 语言—动作块|文字向量与50步54D关节残差/夹爪序列编码后双向对比。边界忽略；同阶段异parent/异attempt难负例。|小投影/时序编码器约0.5–2M|无人工语言—动作配对，只能以稀疏因果标签时刻伪配对。中高复杂度，不能声称真实语言动作对齐。|
|D 文本条件世界头|文本条件token、当前视觉token、动作输入→未来token；未来预测损失+正确条件优于错配/空条件的排序损失，文本dropout。|冻结干路，仅 adapter/cross-attn 约0.5–2M|train parents，仅读 E106-C 20000 步权重/隐藏表示。高复杂度，A/B泛化通过后才做。|

推荐顺序：A 固定语料/步数小投影；A 无信号不靠扩模型补救，优先补人工语言。A 原句有效而改写弱才试 B；C 仅探索伪配对；D 只在世界头加可拔除条件支路。

## 3. 防止退化为阶段 ID 分类
输入不含 S01/P021、文件名、one-hot 或模板序号。语料/改写/split 在看 dev 前锁哈希，优先人工改写。模型生成改写只能作增强/鲁棒性探针，不作真值或 checkpoint 选择。图像、动作块、描述族按 parent 整体切分。

|检验|正负样本|基线/解释|
|---|---|---|
|整句改写持出（主）|改写族整族留出；正=对应阶段/谓词合法时间窗；负=同parent非相邻阶段、近邻易混谓词、明确不成立且可观测谓词；unknown不作负|随机、P3原句、监督探针参照上界.621/.908。改写退回P3即模板记忆。|
|持出谓词零样本|按谓词ID分组，评估谓词文字不提供训练标签；轮换折。正负取 E98-C yes/no，unknown排除，候选含近邻谓词|随机AUROC .5、P3 .520、CF H0 .908监督参考。21谓词样本少，逐项报告，不足则不确定。|
|中英互换|中文训英文测、英文训中文测，另做双语训练|同义跨语言为正、异谓词/阶段为负；与单语和 P3 比较，报 parent bootstrap 差。|
|组合描述|训练见组件概念但不见组合句；测阶段关系+谓词 conjunction|正=spec逻辑同真/同目标；负=打乱一组件或关系冲突；未知不作负。与仅阶段分类头比，人工检查逻辑。|
|时间/身份控制|整parent持出；同parent不同episode/attempt近邻负例；同一时刻多机位同组|文本视觉配对置乱负控；阶段ID头、随机标签探针查时间位置/背景捷径。|

双向视觉↔文字检索，每 parent 均衡报告。相邻窗口、改写族不得跨 split。

## 4. 数据泄漏及标签噪声
- 沿用 E102-S 五折及固定20 dev parent；特征池80 parent，约60 train。五折只用于 train 内 OOF/诊断；dev 不训练、不选超参、不按模型标签选 checkpoint。固定训练步数或 train 内验证。
- 只读 results/e102_20261115_01/features/<parent>/b.npy（每帧3相机×768）、2×4×768 token缓存、E106-C 20000步 ckpt/隐藏表示及已有 Piper 动作。永久排除 demo3 episode142 canonical piper_4dc107335389f5711a0f65e0。禁止仿真、MuJoCo、retarget、平移动作/标签。同事目录和 /mnt/workspace/dataset 严格只读。
- E98-C 4410×21 因果标签仅训练目标；dev 阶段/谓词标签均标记“模型生成、非人工”，不作测试真值、阈值来源或 checkpoint 选择依据。人工4片段只校准边界/术语口径。
- 因果/回顾阶段约50.3%一致；以因果标签训练，回顾结果仅敏感性。可用置信度则软标签；unknown不造负；疑似模板复用/隔离时刻沿用既有排除。
- 边界主忽略带±90帧，±60/±150敏感性；过渡帧不硬分唯一阶段，不对稀疏标签作高置信插值。同一时刻多机位不算独立样本，parent等权。

## 5. 评估与预注册
统计：parent bootstrap 2000次、seed90；模型差配对重采样；最终至少3训练seed（90/91/92），先导单seed不作成功结论。逐帧bootstrap不替代parent bootstrap。20 dev parent及事件少、人工4片段不足，CI宽/跨零=证据不足，不称等价。

**L1：**阶段 top-1、macro-F1，谓词 macro AUROC（有效 yes/no；P073弃权并报有效谓词数），双向 Recall@1/5、MRR。参考：随机阶段.10，P3阶段.036 [.030,.041]/F1 .017，监督阶段.621；随机AUROC .5，P3 .520 [.486,.584]，监督.908。
- 主门槛：parent持出+整句改写，阶段top-1 95% CI下界>.20；谓词AUROC CI下界>.60；对原始P3配对差CI下界>0。原句过、改写失败不算过关。门槛沿用E116预注册/随机基线，不按dev调。
- 持出谓词支持性门槛：AUROC点估计>.60且CI下界>.50；谓词数不足则不确定，不能声称组合语义迁移。

**L2：**文本检索动作块双向R@1/5、MRR；动作阶段分类top-1/macro-F1；比较均衡随机、阶段频率先验、ID分类探针、配对置乱。门槛：未见parent+持出句R@5≥随机2倍且配对差CI下界>0，阶段F1胜频率先验及P3。伪配对只报告伪配对结果。

**L3：**未来token误差/余弦、预测token上因果谓词AUROC、E115-P2进展排序+25/+50/+100；比正确、空、错配、持出改写。总体世界指标标准化非劣界−0.02；持出正确条件较空条件改善≥0.02且配对CI下界>0；错配条件不能同样改善。阶段文字不进动作头，除非P1另行决策。

监督探针仅作可学上限参照；模型生成标签只作训练目标/训练池筛选，绝非测试真值、阈值或checkpoint依据。

## 7. 风险和用户决策
1. 约31条基础描述很容易过拟合句式/阶段，需持出描述族、谓词、跨语种、组合测试。
2. 无自然语言原始指令及人工语言—动作配对。建议用户决定是否补少量人工改写和阶段/动作对齐片段；这比加模型容量更有价值。
3. 模型因果标签与回顾阶段约50%一致，dev亦为模型标签；人工4片段仅够校准边界，不足以验语义或排序。
4. 动作时间伪配对会学习阶段频率/时序；需要同阶段难负例、错配条件和ID探针。
5. P1禁止阶段信息进动作头。建议维持；若修改请先定义意图/子目标和动作安全指标。
6. 是否允许A通过后再做B/C小pilot（GPU≤.1h）？建议先只做A。
7. 项目AGENTS禁止引入/下载Qwen或其他VLM；当前方案不下载模型。更大模型须先决定是否修改项目规则和预算。
