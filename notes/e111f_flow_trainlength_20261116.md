## 1. 初始化与训练量核对

核对 E110-F 与 E106-C 的只读报告、训练脚本、摘要及 checkpoint 元数据，比较模型 state keys、optimizer step、Piper draws、LR/weight decay 与 F05 保存内容。

- E106-C 的 `ckpt_20000.pt` 来自 Piper local step 20,000 / global step 22,000；checkpoint 元数据中 `delta_head` AdamW step=22,000。20,000 个 Piper 更新使用 batch=32（640,000 draws）。E110-F 的 D/F 两组各更新4,000次、batch=32（128,000 draws），终点 `delta_head` optimizer step 均为26,000。
- A2 checkpoint 对 E110-F 模型 strict-load 185/185 state keys。`delta_head`、`state_proj`、`action_proj`、`proprio_proj`、`grip_head` 和时间嵌入 `ta` 全部继承自 A2。没有新增独立速度网络；flow 头随机初始化参数为0个张量、0个标量。A2 构造时曾零初始化 proprio 投影末层和 `delta_head`，但 E106-C 已对其优化22,000步，因此不是 E110-F 的随机起点。
- E106-C 的 `delta_head` 每步均在零动作、t=0 条件下预测 Δq；A2 自带的 action flow loss 则通过 `action_head` 优化共享表征、`action_proj` 和 `ta`，见过噪声-目标插值及随机时间。E110-F 将已继承的 `delta_head` 用作 flow 速度输出头，但只有 E110-F 的4,000步在该输出头上使用 flow matching 条件。
- E106-C 和 E110-F 均沿用常数学习率3e-4、AdamW weight decay 1e-4；E110-F 从 E106-C optimizer state 继续，没有重置。F05 最终 checkpoint 仅保存模型，不含 AdamW、sampler 或 RNG state。

|---|---|---:|---:|---:|---|
|D 确定性 Δq|A2/E106-C，185/185 keys|22,000 + 4,000 = 26,000|确定性 Δq：26,000|832,000|常数3e-4，AdamW连续|

|F 计划追加上限（未执行）|拟从 F05 连续恢复|追加后参数 optimizer step=42,000|flow matching累计20,000|640,000|维持常数3e-4|

**判断：**按参数 optimizer step 计数，D/F 都是26,000步；按各自实际目标计数，D 的确定性 Δq 是26,000步（832,000样本），F 的 flow matching 只有4,000步（128,000样本）。因此 E110-F 参数初始化与更新数量对等，但 flow 速度输出头的目标曝光明显不足。F 的 action projection、时间嵌入及 trunk 继承了 A2 的 flow 训练，不能据此把 `delta_head` 的4,000次 flow 目标更新误计为22,000次。

## 2. 是否追加及理由

确认 flow 目标曝光不对等后，原计划锁定追加16,000步，为许可上限；flow 目标累计将达20,000步（比 D 确定性 Δq 的26,000步少6,000步），每4,000步存一个固定 checkpoint，不按 dev 选点。这样 F 的 `delta_head` 参数 AdamW step 会到42,000，高于 D 的26,000；此差异来自复用继承的 optimizer 历史和额外 flow 更新，报告时会分开列出参数步数与目标曝光。

**实际未追加。**恢复门槛要求从 E106-C 确定性重放 E110-F 的前4,000步，恢复 AdamW/sampler 状态，并逐位复核 F05；默认 SSH Python 无法运行该测试，详见下节。未以“测试跳过”方式开训。

### 结论与资源

- 曲线没有随追加步数单调改善：27-parent S4 的单样本 L1@8 相对差依次为 +2.38%、+1.68%、+2.14%、+1.44%；L1@50 为 +4.99%、+4.46%、+4.80%、+5.59%。最终 @8 的相对差 CI 上界 +6.25%，@50 为 +9.14%，部署读法未满足两项≤+5%的非劣条件。K8均值在终点的 @8/@50 相对差为 −7.05%/−2.31%，best-of-8也明显好于D，但单样本部署读法不满足。
