# 任务 E33_sub-设计评审：基于 flow matching 的子目标（subgoal）建模（配置 sol-deep 风格，gpt-6.1-sol high；只做设计，不写训练代码、不跑 GPU）

## 背景
- 参考论文：ID-WM《Hierarchical World Models with Implicit Dynamics》(arXiv 2610.42146)。要点：高层是扩散模型 f_hi(s_{t+Δ}|s_t,Δ)，从高斯噪声 z 经确定性 DDIM 映射生成"可达的未来状态"作为子目标，高层不看动作、不看最终目标；低层是确定性世界模型兼逆动力学求解器；规划时用两层 CEM：高层在噪声空间搜索子目标链（代价=末子目标到目标距离+噪声正则 E[max(0,|z_i|-τ)^p]，τ=2,p=1），低层搜索动作使想象末状态到达第一个子目标。子目标是完整状态（PushT 为 8 维：末端位置速度+物体位姿；视觉版为 SD-VAE 潜变量）。子目标跨度有甜点区：Δ=1 几乎失败，Δ=4–5（×frameskip 5≈20–25 步）、5–8 个子目标最好。数据增广（扩大初始/目标覆盖）带来最大收益。论文全在仿真、无真机、无小数据。
- 我们的现状（读代码：tools/e33_model.py、tools/e33_train.py、tools/e32_data.py；契约 notes/2026-11-04-e33-contract.md）：E33 = DINOv2-B 顶视编码器 → 每 token 共享潜变量 z∈R^256（12×20=240 token）；确定性 Transformer 预测器输入 z_t + 动作 token + FK 手部 token，预测原始帧 t+16、t+32 的 z；flow 动作头输出 32 步 54D 关节块；辅助：前景加权 JEPA、逆动力学（z_t,z_{t+16}→第1–16步平均动作）、掩码头、轻量解码器。变体 B（EMA+方差）、C（SIGReg）、D（策略不看预测未来）正在训练。中期结果（ep30）：B≈D（策略是否用预测未来没有差别）→ 动力学部分目前没有被策略利用；未来帧预测比 E32 明显好；瓶子/箱子掩码不如直接拷贝。
- 数据：93 条成功演示（2,812 训练窗口 / 266 留出窗口，9 个留出 episode），15 Hz，单任务（瓶子放入框），只用顶视相机，54D 关节 A7+B7+L20+R20 弧度。
- 用户要求：设计 E33_sub —— 借鉴 ID-WM 的两层结构，用 **flow matching** 建模子目标。

## 我的初稿（请评审、改进、补全细节，有更好方案可替换，但要说明理由）
1. 子目标空间 s_{t+Δ} = [q_{t+Δ}（54D 实测关节，具身状态）; 视觉紧凑潜变量 v_{t+Δ}]。v 取 stop-grad 目标编码器在真实未来帧上的 token，做 2×2 平均池化成 6×10=60 个 token×256（或其他紧凑化方式），按训练集统计做逐维标准化。Δ ∈ {8,16,32} 原始帧，用 Δ 嵌入条件化。
2. 高层子目标生成器 G：条件 flow matching（rectified flow）模型 p(s_{t+Δ} | z_t, q_t, Δ)，不看动作、不看最终目标。训练损失 L_sg = ||v_θ(x_τ,τ,c) − (x1 − x0)||²，x_τ=(1−τ)x0+τx1，x0~N(0,I)。推理：给定噪声 ε，Euler 积分若干步得到确定性映射 s=G(z_t,q_t,Δ,ε)（噪声 = 隐式高层动作）。网络：小 Transformer（条件 token 交叉注意力读 z_t 的 240 token），规模参考数据量。
3. 低层：目标条件 flow 动作头 π_lo(a_{t:t+32} | z_t, q_t, s_{t+16}, s_{t+32})，训练时用真实未来子目标（hindsight relabel）。为减小训练/测试不一致：以概率 p 用 G 生成的子目标（stop-grad、少步采样）替换真实子目标，并对子目标加噪增广。
4. 用世界模型做"轻规划"（让动力学真正进入控制回路，回应 B≈D 的发现）：推理时采样 K 个噪声 → K 个子目标 → 低层各出一个动作块 → 用确定性预测器 f(z_t, a_k, FK) 预测 z_{t+16}/z_{t+32}，打分 = 预测与子目标的一致性距离 + 噪声正则（ID-WM 式）；选最优；同时报告单样本（ε=0）版本。可选：若引入任务终点目标（训练集成功末帧潜变量的原型），在噪声空间做小规模 CEM 让子目标链朝终点推进——请评估单任务场景下是否值得。
5. 保留 E33 的 JEPA/IDM/掩码/重建损失（基座取 E33 中最终最优的变体，默认 B），从 E33 检查点初始化还是从头训，请给建议。
6. 评测（复用 tools/e33_eval.py 体系，266 留出窗口）：动作误差 vs hold 与 vs E33 基座；子目标质量（视觉部分对真实未来的余弦/LN-L2 与 copy 比、解码图像 PSNR、q 部分关节/末端误差 vs hold）；多样性/覆盖（best-of-K 误差 vs 均值）；子目标跟随性（把子目标换成另一窗口的，低层动作是否朝新子目标改变，用 FK 末端位移方向衡量）；Δ 敏感性。
7. 消融（预算紧，最多 2–3 个训练运行）：完整版；确定性子目标（回归代替 flow，检验随机建模是否必要）；无 q 的纯视觉子目标；以及推理期的 K=1 vs K>1 选择（不需训练）。
