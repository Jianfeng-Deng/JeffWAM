# Task E29-S3: matched-start evaluation windows and hand/bottle readout labels (profile luna-standard, CPU only)
## Goal
A frozen window set with five action variants per window plus tracked hand/bottle centre labels in the V-JEPA input frame, ready for the probe harness.
## Done criteria
- [ ] Windows: from the 9 E26a development episodes (eval) and the other 84 (train split for the readout; reuse the project train/val split file if one exists, else document), every window = context frame at sampled time t plus targets at t+1..t+4 sampled steps (stride k=4 raw frames, 3.75 Hz; k parameter). Select eval windows stratified by phase (reach, grasp, lift/carry, release) and moving vs static bottle, at least 400 eval windows; record episode id, raw frame indices, phase, moving flag.
- [ ] Image preprocessing helper tools/e29_frames.py: load cam_high frame, crop rows 96-479 (640x384), then two modes to 256x256: squash (resize) and center (center-crop 384x384 then resize); default squash; unit test shapes. Do not cache images unless fast; an index plus loader is enough.
- [ ] Labels per sampled frame, in 256x256 coordinates for each mode: left/right hand centroid (clean hand masks, with the E26a arm mapping A=left B=right), bottle centroid for the target bottle and for other bottles, bin centroid; visibility flags (use the clean mask cache data/object_masks_clean_20261102; hand points may also come from FK projection tools/e28_hand_geometry.py uv for a second label set). Missing mask means label invalid, never zero.
- [ ] Action variants per eval window, defined on S2-style deltas (S2 writes tools/e29_action_map.py; until it exists, define variants as functions that take a list of per-step 14-D action vectors so they can be applied later, and unit-test them on dummy data): recorded; shuffled (actions from a different episode at the same phase and similar magnitude, seeded); hold (all deltas zero); reversed (order reversed and signs flipped); scaled-0.5 (recorded times 0.5). Save the variant definitions and seeds.
- [ ] Copy baseline for each label (centre unchanged) and an oracle-motion baseline (linear extrapolation from the previous sampled step) as numbers on the eval windows.
- [ ] Output: data/e29_probe_windows_20261103/ (windows.npz/parquet, labels, variant spec) and s3/REPORT.md with counts per phase and moving/static, label coverage per object, and baseline errors.
